## 摘要
LLM智能体在长时间的任务轨迹中性能往往会下降：随着轨迹增长，它们会重新访问已探索过的状态，重复失败的动作，并丢失之前有效的策略。测试时训练（TTT）提供了一种将模型权重适应于不断变化的任务状态的方法，但现有的LLM TTT方法主要针对固定输入进行一次自适应。我们研究了多轮智能体交互中的连续TTT，其中每次更新都会改变生成后续训练文本的策略。这形成了一个自我训练循环，在新的轨迹信息出现时有所帮助，但当智能体陷入困境并反复在相似文本上训练时，可能加剧漂移。我们发现，更新文本的重复性区分了这些情况，并引入了Agentic Test-Time Training (aTTT)，一种token级重新加权方法，用于降低在先前更新的重复$n$-gram中出现的token的损失，同时保持新颖token的完整权重。为了在实时交互中执行此类更新，我们使用vLLM的运行时LoRA API构建了一个并发服务系统，将开销限制在无TTT成本的1.9倍以内。在ALFWorld上，aTTT将成功率提升了最多5.0个百分点，在SWE-bench Lite上提升了4.9个百分点。这些增益集中在模型已具备任务能力但在长轨迹中发生漂移的场景，表明aTTT主要保留了现有能力，而非教授新技能。

## Abstract
LLM agents often degrade over long episodes: as trajectories grow, they revisit explored states, repeat failed actions, and lose strategies that previously worked. Test-time training (TTT) offers a way to adapt model weights to the evolving task state, but existing LLM TTT methods largely adapt once to a fixed input. We study continuous TTT in multi-turn agent episodes, where each update changes the policy that generates later training text. This creates a self-training loop that helps when new trajectory information appears, but can amplify drift when the agent gets stuck and repeatedly trains on similar text. We find that update-text repetition distinguishes these regimes and introduce Agentic Test-Time Training (aTTT), a token-level reweighting method that downweights the loss on tokens appearing in repeated $n$-grams from prior updates while leaving novel tokens fully weighted. To run such updates inside live episodes, we build a concurrent serving system using vLLM's runtime LoRA API, limiting overhead to 1.9$\times$ the no-TTT cost. aTTT improves success by up to 5.0 points on ALFWorld and 4.9 points on SWE-bench Lite. The gains concentrate where models already have task competence but drift over long trajectories, suggesting that aTTT mainly preserves existing competence rather than teaching new abilities.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）智能体在长轨迹（multi-turn）任务中性能退化，表现为重复访问已探索状态、重复失败动作、丢失有效策略。这不是模型能力的根本缺乏，而是“能力漂移”（drift）——模型本身具有解决任务的潜力，但在长时间交互中无法保持和运用这种潜力。
- **现有方法不足**：Reflexion等方法跨trial修改提示但不改变单次trial内的行为；长上下文窗口面临“中间丢失”问题；解码时重复惩罚只抑制表面token，不改变策略。静态TTT（如qTTT、ETT、In-Place TTT）只适应一次固定输入，无法应对不断增长的轨迹。
- **本文贡献**：提出**Agentic Test-Time Training (aTTT)**，在智能体单次交互过程中**连续在线更新**模型参数，解决长轨迹中的漂移问题，且开销可控。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 在智能体与环境交互的每个回合，选取轨迹文本作为训练信号，对当前策略进行LoRA微调。由于后续回合的文本依赖于更新后的策略，形成“自我训练循环”（self-training loop）。
- 当智能体正常推进时，新文本携带新信息，更新有益；当智能体陷入重复（stuck）时，更新文本重复较早的文本，导致自我强化失败。**更新文本重复率**（update-text repetition）可作为区分好坏循环的信号。
- aTTT通过**token级损失重加权**：对出现在之前更新的重复n-gram中的token降低损失权重，保留新颖token的完整权重。

### 关键技术细节
- **训练信号来源**：
  - Self：智能体自身的推理和动作token（`mt`）。
  - Env：环境产生的观测（`ot`）。
  - Summary：用一个额外LLM调用压缩轨迹生成的总结（`g(τtk)`）。
- **更新策略**：每`K`步（默认5步）进行一次LoRA更新，只使用最新一步的文本，避免重复训练早期整个轨迹。
- **重复率定义**：计算当前更新文本与之前所有更新文本的最大Jaccard单词重叠度`ρ(xk)`，新颖度`ν(xk)=1-ρ(xk)`。
- **Token重加权**：对当前文本中每个位置j，计算其在先前更新历史中的最大n-gram出现次数`fk(j)`，设置权重`wk,j = max(w_min, 1/(1+fk(j)))`，其中`w_min`为下限（默认0.05）。重复n-gram的token权重降低，新颖token权重保持1。
- **更新公式**：损失函数为加权交叉熵，梯度更新LoRA适配器（rank 8, α=16, lr=5e-4, 2梯度步）。
- **系统实现**：基于vLLM运行时LoRA API，16个episode并发运行，训练异步进行，热切换适配器，墙钟成本为无TTT的1.9倍。

### 算法流程（文字说明）
1. 对每个更新时刻，取出当前更新文本`xk`和之前所有更新文本的token历史`Htok_k`。
2. 对`xk`中每个token位置j，计算其在`Htok_k`中的最大n-gram出现次数`fk(j)`。
3. 计算权重`wk,j`。
4. 用加权交叉熵损失更新LoRA适配器。
5. 将`xk`的token序列追加到`Htok_k`中。
