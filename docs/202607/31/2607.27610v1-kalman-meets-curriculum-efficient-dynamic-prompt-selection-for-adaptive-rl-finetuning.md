## 摘要
强化学习（RL）微调显著提升了大型语言模型（LLMs）的推理能力，但其有效性关键取决于为当前策略选择适当难度的提示。由于提示难度随训练过程不断演变，这一任务颇具挑战性。因此，现有的在线方法面临权衡：基于评估的方法准确但代价高昂，而基于预测的方法高效但通常假设难度静态不变，难以适应RL非平稳的训练动态。为解决这些问题，我们提出了一种卡尔曼引导的提示选择方法（KGPS），将提示选择重新表述为动态状态估计问题，而非静态难度预测。KGPS在逻辑空间中使用线性高斯状态空间模型对每个提示的潜在成功率建模，其中过程噪声与策略更新的幅度耦合，使得当策略变化较大时不确定性增加。随后，卡尔曼滤波器维持提示难度的校准高斯后验，并通过最大化后验期望训练效用来选择提示，该效用偏好中等难度提示，同时自然重新审视不确定的提示。所得流程对策略漂移具有适应性，且除标准策略训练外无需额外 rollout。在数学、规划和几何推理基准以及多种RL算法上的广泛实验表明，KGPS在最终准确率和 rollout 效率上均持续优于强基线，确立了在线提示选择方法中的最先进性能。例如，在DeepSeek-R1-Distill-7B上，KGPS相比DS减少了83%的rollout，同时在六个数学推理基准上的平均性能还提升了0.12个百分点。

## Abstract
Reinforcement learning (RL) finetuning significantly enhances the reasoning capabilities of large language models (LLMs), yet its effectiveness critically depends on selecting prompts of appropriate difficulty for the current policy. This is challenging because prompt difficulty evolves throughout training. Existing online methods therefore face a trade-off: evaluation-based approaches are accurate but expensive, while prediction-based approaches are efficient but typically assume stationary difficulty, making them ill-suited to RL's non-stationary training dynamics. To address these issues, we propose a Kalman-Guided Prompt Selection method (KGPS), which reformulates prompt selection as a dynamic state estimation problem rather than static difficulty prediction. KGPS models each prompt's latent success rate in logit space using a linear-Gaussian state-space model, with process noise coupled to the magnitude of policy updates so that uncertainty increases when the policy changes more substantially. A Kalman filter then maintains a calibrated Gaussian posterior over prompt difficulty, and prompts are selected by maximizing a posterior-expected training utility that favors intermediate-difficulty prompts while naturally revisiting uncertain ones. The resulting procedure is adaptive to policy drift and requires no additional rollouts beyond standard policy training. Extensive experiments across mathematics, planning, and geometry reasoning benchmarks, as well as multiple RL algorithms, show that KGPS consistently improves both final accuracy and rollout efficiency over strong baselines, establishing state-of-the-art performance among online prompt selection methods. For example, on DeepSeek-R1-Distill-7B, KGPS uses 83% fewer rollouts than DS while even improving the average performance by 0.12 point across six math reasoning benchmarks.

## 方法论

### 核心思想
KGPS（Kalman-Guided Prompt Selection）的核心是将提示难度追踪视为一个**动态状态估计问题**，而非静态难度预测。具体采用线性高斯状态空间模型（SSM）在logit空间对每个提示的潜在成功率建模，并用卡尔曼滤波器（Kalman Filter）维护高斯后验，基于后验期望训练效用进行提示选择。

### 关键技术细节

1. **状态空间建模**：
   - 在logit空间定义隐藏状态 ψ_t^τ = logit(φ_t^τ)，φ_t^τ 为提示 τ 在策略 π_θt 下的潜在成功率。
   - 状态演化假设为随机游走：ψ_t^τ = ψ_{t-1}^τ + w_t^τ，其中过程噪声 w_t^τ ~ N(0, Q_t)，且 **Q_t = γ·‖θ_t − θ_{t-1}‖²**，即过程噪声与策略更新的幅度（参数变化二范数）耦合，策略变化越大、不确定性增长越快。γ 为超参数。
   - 观察模型：基于二项采样经delta方法近似为logit空间高斯观测：logit(φ̂_t^τ) ≈ ψ_t^τ + ε_t^τ，ε_t^τ ~ N(0, R_t^τ)，其中 R_t^τ = 1/[k·φ̃_t^τ(1−φ̃_t^τ)]，φ̃ 为基于当前后验均值经clip后的plug-in估计。

2. **卡尔曼滤波递推**（算法流程）：
   - **预测步骤（对所有提示）**：P_{t|t-1}^τ = P_{t-1}^τ + Q_t。由于 Q_t > 0，所有提示（包括未被选择的）的方差都会随策略更新而增长，使长期未选提示的方差增大、不确定性累积。
   - **更新步骤（仅对上一轮被选提示）**：利用标准卡尔曼方程更新后验均值与方差，卡尔曼增益 K_t^τ 自适应权衡先验信念与新材料。
   - **未选提示**：状态均值不变，方差保留预测值。

3. **后验期望训练效用**：
   - 定义 h(ψ) = σ(ψ)(1−σ(ψ))，在中等成功率处峰值最大，两端消失，反映“中间难度最有训练价值”。
   - 为避免仅用点估计导致极端难度提示被永久排除，将h在后验高斯分布下取期望：Ã(τ,t) = E_{ψ~N(ψ̂_t^τ, P_t^τ)}[h(ψ)]。
   - 由于方差累积，未被充分采样的提示其效用分数会确定性地上升，从而自然实现“激励探索”。无需任何手工衰减调度。
   - 计算通过五点高斯-厄米特求积（Gauss–Hermite quadrature）实现，每次仅需5次标量函数评估，相比于LLM推理开销可忽略。

4. **初始化**：训练前用一轮均匀采样获得所有提示的初始经验成功率，作为数据驱动的后验均值起点。

## 主要结论与发现

- KGPS在数学、规划、几何等所有基准上持续优于Uniform、GRESO、MoPPS，并匹配或超越评估型Oracle（DS）。
- **Rollout效率提升**：以DeepSeek-R1-Distill-Qwen-7B为例，KGPS相比DS减少83%的rollout，平均性能反而提高0.12点；Qwen3-0.6B减少71%、Qwen3-4B减少87%的rollout。
- **在相同296k rollout预算下**，KGPS在DeepSeek-R1-Distill-Qwen-7B上超越MoPPS 7.36个平均点。
- 难度估计更准确：KGPS的MAE稳定在约0.15，而MoPPS约0.40；Spearman等级相关维持在0.75–0.85，表明后验均值对经验难度排序有统计显著的预测力。
- 消融显示：（1）后验期望替代点估计提升1.09点；（2）动态过程噪声（Q_t=γ‖Δθ‖²）优于固定常数1.21点；（3）warmup初始化带来0.37–0.48点增益。
- KGPS与RL算法解耦，可方便集成到任何基于rollout的RL方法中。

## 优点

1. **方法论新颖**：将提示选择从静态参数估计重构为动态状态估计，用卡尔曼滤波在理论上严谨地处理非平稳性，规避了启发式衰减调度的局限。
2. **效率突出**：零额外LLM推理，仅需极廉价的后验计算，rollout成本与Uniform相当，同时效果接近/超过高成本的Oracle方法。
3. **过程噪声的机制设计**：噪声与策略更新幅度耦合，赋予系统“政策漂移越大、不确定性越高”的正确先验直觉。
4. **自然的探索-利用平衡**：方差累积使长期未选提示的效用分数确定性上升，避免了手工设计探索策略的麻烦。
5. **通用性强**：在多模型、多任务、多RL算法上皆验证了有效性，算法无关性好。

## 不足与局限

1. **独立性假设**：KGPS独立地对每个提示建模，未利用提示之间的相关性——结构相近的提示难度轨迹可能高度相关，利用该结构可以加速后验收敛（论文在Limitations中已明确承认）。
2. **可扩展性欠账**：对提示池规模增大时的表现（如百万级提示池）未做专项分析；线性扫描所有提示Top-B选择在大规模池上可能成为瓶颈。
3. **公式推导依赖近似**：delta method观测近似、clip操作对极端成功率估计的影响、Gauss-Hermite五点求积精度等仍有理论完善空间（论文对clip已有形式化说明，但完整误差界未给出）。
4. **超参数设定**：γ（过程噪声缩放）和初始方差P0（=1.0）的敏感性未做系统消融，对实际应用中的调参指引不够充分。
5. **部分结果对比口径不统一**：DS基线使用显著更多的rollout，将其作为“平等”对比对象时需注意双方计算成本定位不同；案例研究（Case Study）为定性说明，样本量有限，存在选择性偏差的可能。
6. **RL算法验证有待扩展**：虽然测试了GRPO、PPO、Reinforce++，但尚未在离线RL、多模态更复杂场景或更大参数规模（如70B级别）上验证。
