## 摘要
协调无信号交叉口的自动驾驶车辆对于多智能体强化学习（MARL）系统仍然是一个关键挑战，这些系统通常难以应对组合动作空间、对特权信息的依赖或僵化的智能体设计。我们提出了主智能体原型规划系统（MAPS），这是一种分层深度强化学习（DRL）架构，其中集中式的主智能体生成一个紧凑的连续嵌入，称为原型规划（proto-plan），编码全局协调策略。分散的工作智能体将该嵌入与局部观测相结合，执行特定车辆的控制，将战略意图与战术执行解耦，并实现每个模块的独立优化。作为该协调机制的概念验证评估，我们在HighwayEnv中的72个交叉口配置上测试了MAPS。MAPS实现了无碰撞导航，同时显著减少了平均旅行时间，超越了最先进的基线。学习到的原型规划进一步表现出鲁棒的泛化能力：一个用三个智能体训练的系统在零样本部署到五个智能体场景时达到了94%的成功率，证实了基于原型规划的分层学习为多车辆协调提供了一个有前景的框架。

## Abstract
Coordinating autonomous vehicles at unsignalized intersections remains a critical challenge for multi-agent reinforcement learning (MARL) systems, which typically struggle with combinatorial action spaces, reliance on privileged information, or rigid agent designs. We propose Master-Agent Proto-plan System (MAPS), a hierarchical deep reinforcement learning (DRL) architecture in which a centralized Master agent generates a compact, continuous embedding, denoted as proto-plan, that encodes a global coordination strategy. Decentralized Worker agents integrate this embedding with local observations to execute vehicle-specific control, decoupling strategic intent from tactical execution and enabling independent optimization of each module.   As a proof-of-concept evaluation of this coordination mechanism, we test MAPS across 72 intersection configurations in HighwayEnv. MAPS achieves collision-free navigation while significantly reducing average travel time, outperforming state-of-the-art baselines. The learned proto-plans further exhibit robust generalization: a system trained with three agents achieves a 94% success rate when deployed zero-shot to five-agent scenarios, confirming that proto-plan-based hierarchical learning provides a promising framework for multi-vehicle coordination.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- 采用 **集中训练-分散执行（CTDE）** 框架，分为两层：
  - **Master 代理**（集中式）：观察全局交通状态，输出紧凑的连续嵌入向量 **proto-plan** \( z_t \in \mathbb{R}^d \) （实验中 d=4），编码全局协调策略。
  - **Worker 代理**（分散式，参数共享）：每个车辆结合自身局部观测 \( o_{i,t} \) 与接收到的 proto-plan \( z_t \)，选择离散动作（加速/减速）。
- 关键优势：通信开销恒定为 O(d)，不随车队规模增长；Worker 输入尺寸固定（4+d），支持零样本扩展；无需设计离散命令词汇表。

### 2.2 关键技术细节
- **状态空间**：Master 观测全局状态 \( s_M^t = [x_i, y_i, v_{x,i}, v_{y,i}]_{i=1}^N \)（零填充至固定最大数 \( N_{\max}=5 \)）；Worker 观测自身运动学状态 + proto-plan。
- **动作空间**：Master 动作 \( z_t \in (-1,1)^d \)（连续）；Worker 动作 \( a_i^t \in \{accelerate, decelerate\} \)，目标速度调整 ±5 m/s，底层控制器执行。
- **奖励函数**：
  - Worker：\( r_{W,i}^t = \begin{cases} +50 & \text{成功通过} \\ -300 & \text{碰撞} \\ -5 & \text{每步} \end{cases} \)
  - Master：\( r_M^t = \min_{i \in W_{\text{active}}(t)} r_{W,i}^t \)（**最大化最小值**，promoting 公平协调；若用 mean 聚合则性能下降 84%）。
- **网络架构**：Worker 采用 4 层全连接（64-32-16-8）PPO 策略与价值网络；Master 采用 3 层全连接（128-256-128）输出 tanh 激活的 proto-plan。
- **训练算法**（Algorithm 1）：
  - **交替优化**：每 300 回合为一个 cycle，共 3 个 cycle。
    - 初始 cycle 0：同时更新 Master 与 Worker。
    - 后续 cycle 奇/偶交替：冻结 Master → 更新 Worker；冻结 Worker → 更新 Master。
    - 这样降低非平稳性，保证梯度估计稳定。
  - **增量训练**（用于泛化）：
    - Phase 1：用 1 个学习 agent 训练至收敛。
    - Phase 2：引入 2 个额外 agent（共 3 个）继续训练。
    - 最终零样本测试 5 个 agent 场景。

## 7. 优点

### 7.1 方法创新
- **连续嵌入式协调**：用 proto-plan 替代离散命令，避免动作空间组合爆炸，通信量 O(d) 恒定。
- **解耦架构**：Master 负责战略，Worker 负责执行，可独立优化，降低非平稳性。
- **无特权信息**：仅需运动学状态（位置、速度），不依赖专家示范、未来轨迹或安全层。
- **模块化可扩展**：Worker 动作空间可替换（如连续油门、横向控制），Master 封装协调逻辑。

### 7.2 实验设计
- **场景多样性**：72 个配置通过旋转增强，防止过拟合到特定方向。
- **公平对照**：基线的选择排除了额外模块的干扰；统计显著性检验。
- **全面的消融**：从 Master 贡献到嵌入维度，从动力学到泛化，覆盖完整。

### 7.3 实践意义
- 极低算力需求（20 分钟 CPU 训练），便于复现和落地。
- 零样本泛化能力表明该框架可应对动态车队大小变化，适合实际路况。

## 8. 不足与局限

### 8.1 实验覆盖不足
- **仿真度低**：仅使用 HighwayEnv 简化运动学，未在高保真或真实环境（SUMO/CARLA）验证，无法确认感知噪声、延迟等影响。
- **动作空间受限**：仅纵向加减速，未包含横向（变道、转向）或更连续的控制，真实交叉口需要更丰富动作。
- **车队规模有限**：Master 输入固定最大 5 辆，更大规模（如 10+）需置换不变处理（如注意力机制），文中未测试。
- **未与带特权机制的 SOTA 分层方法直接对比**：如 MA-GA-DDPG、SafeR-ADAIM，虽然作者说明是为了聚焦架构，但削弱了公平性。

### 8.2 方法局限
- **固定最大 agent 数**：Master 输入拼接固定大小，超出 max 需重新设计。
- **Worker 参数共享**：虽然利于泛化，但所有车辆学习相同策略，可能无法适应异构车辆（如不同动力学）。
- **奖励稀疏性**：碰撞惩罚和成功奖励绝对值大，但步罚 -5 相对较小，可能导致训练早期探索不足（但实验显示已有效率）。
- **低维嵌入的可解释性**：PCA 显示 proto-plan 区分安全状态，但具体维度语义未分析。

### 8.3 偏差风险
- **单一种子**：结论基于单一随机种子（42），虽然可重复，但可能无法反映分布鲁棒性。
- **基线选择偏差**：排除带额外模块的基线可能使 MAPS 优势更突出（但也合理，因聚焦核心贡献）。
- **场景设计中 5 车含 2 辆匀速背景车**：背景车行为固定，未考虑不确定性，简化了协调难度。
