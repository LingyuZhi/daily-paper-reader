## 摘要
一个训练好的深度强化学习策略是一个黑盒，我们提出能否通过将其重写为一个可执行的逻辑程序来使其可解释，该程序可以复现其行为，并且人可以阅读、逻辑引擎可以运行、优化器可以编辑。我们提出了一种三阶段的事后转换方法：提取一个冻结的近端策略优化教师模型，以经典关系学习的方式从其决策中归纳出一个有序规则列表，并将结果输出为一个Prolog程序，该程序的每个决策都由现成的逻辑引擎执行；随后一个扩展阶段编辑规则库，并且只有当策略评估证明回报增加时才接受编辑。我们证明了四个保证。一个回报损失界使得蒸馏后的程序在有限马尔可夫决策过程中成为机器可检查的证书，并且扩展循环单调改进并终止。对于连续观测场景，我们回答了转换是否可能：命题阈值实例化将网络转换为任意保真度，随着分辨率B增大，不一致性为O(1/B)，回报差距以相同速率收敛，并且一个匹配的下界表明，对于倾斜决策边界，成本随观测维度指数增长。实验上，在一个具有16944个可达状态的两房间钥匙门任务中，扩展后的Prolog程序在每个种子中都达到了精确最优回报，并且在预算限制下，在十个种子中的精确回报上超过了随机教师。在三个连续控制任务中，输出的程序替代了网络，在Acrobot上用11个子句匹配了神经教师（在噪声范围内），在CartPole上恢复了约97%的回报，而在更精细控制的LunarLander上仅部分恢复，这正是指数下界预测的上限。

## Abstract
A trained deep reinforcement learning policy is a black box, and we ask whether it can be made explainable by rewriting it as an executable logic program that reproduces its behaviour and that a person can read, a logic engine can run, and an optimizer can edit. We present a three-stage post-hoc transformation that extracts a frozen proximal policy optimization teacher, induces an ordered rule list from its decisions in the manner of classical relational learning, and emits the result as a Prolog program whose every decision is executed by an off-the-shelf logic engine; a subsequent expansion stage edits the rule base and accepts an edit only when policy evaluation certifies a return increase. We prove four guarantees. A return-loss bound makes the distilled program a machine-checkable certificate in a finite Markov decision process, and the expansion loop improves monotonically and terminates. For the continuous-observation setting we answer whether the conversion is possible at all: the propositional threshold instantiation converts the network to arbitrary fidelity as the resolution B grows, with disagreement O(1/B) and a return gap that closes at the same rate, and a matching lower bound shows the cost is exponential in the observation dimension for an oblique decision boundary. Empirically, on a two-room key-and-door task with 16,944 reachable states the expanded Prolog program attains exact optimal return in every seed and, in a budget-capped regime, exceeds the stochastic teacher on exact return in ten of ten seeds. On three continuous-control tasks the emitted program substitutes the network, matching the neural teacher within noise on Acrobot with eleven clauses and recovering about 97% of its return on CartPole, while on the finer-control LunarLander it recovers only partially, exactly the ceiling the exponential lower bound predicts.

## 2. 方法论

### 核心思想
将冻结的随机PPO教师策略（πT）转换为一个**有序决策列表**（ordered decision list），即一阶Prolog子句序列，执行时采用**首匹配语义**（first-match cut）。然后通过**精确回报爬坡**对规则库进行扩展编辑，仅在策略评估（Bellman求解）验证回报增加时才接受修改，从而超越教师性能。

### 技术细节与算法流程（三阶段）

1. **提取阶段**  
   - 在有限MDP中枚举所有可达状态（16,944状态），查询教师贪婪动作 aT(s)，形成完整普查。同时通过Bellman求解得到教师折扣占用测度 dπT。
   - 当状态空间过大无法枚举时，用**DAgger循环**代替：学生策略rollout，教师重新标注学生访问的状态，混合训练，模仿在线学习（Ross et al., 2011）。

2. **归纳阶段**  
   - 仿照FOIL算法（Quinlan 1990），贪心覆盖方式生长有序决策列表。每个子句包含**体部**（谓词文字合取）和**头部**（动作）。评分使用覆盖度×精度（按占用权重）。特殊化时增加最多3个文字。
   - 输出为完全确定性的Prolog程序（带第一个匹配cut），感知层（状态谓词）和路径感知广度优先搜索表（nav/3）单独定义。列表以**默认子句**结尾，保证全状态覆盖。

3. **扩展阶段**  
   - 在规则库编辑空间上进行**爬山**：添加特化子句、重排、剪枝等。每接受一个编辑须使精确回报J(π)增加至少τ（τ > 0）。精确回报通过解线性系统 (I−γPπ)v = rπ 获得。
   - 理论保证（命题1）：回报单调递增，最多 K = 2Rmax/[(1−γ)τ] 次接受，算法终止于τ-局部最优。

### 核心公式与理论

- **性能差分引理（Lemma 1）**：J(π) − J(π') = 1/(1−γ) * E_{s~dπ} E_{a~π} A^{π'}(s,a)。
- **回报损失界（Theorem 1）**：J(π̄_T) − J(π_S) ≤ 2Rmax ε† / (1−γ)^2，其中 ε† 为π_S与贪婪教师π̄_T在dπ̄_T下的分歧率。
- **优势间隙证书（Proposition 3）**：将界收窄为 J(π̄_T) − J(π_S) ≤ (1/(1−γ)) * Σ_{s∈D} dπ̄_T(s) |A^{π_S}(s, aT(s))|，移除一个 (1−γ)因子。当学生弱支配教师时，证书精确等于真实差距。
- **分辨率理论（Theorem 2 & Proposition 4）**：在连续观测中，量化阈值列表的分歧率 ε†_B = O(1/B)，且存在下界 Ω(1/B)，边界单元数为 Ω(B^{d-1})，证明了维度诅咒。

## 6. 主要结论与发现

1. **离散任务精确最优**：在KeyDoor上，扩展Prolog程序在每个种子中达到精确最优回报0.812204（成功率1.0），在预算限制教师下超越随机教师0.100回报（Wilcoxon p=0.0001, Bonferroni校正p=0.0004）。
2. **证书有效且紧**：优势间隙证书中位数比最坏情况界紧约13,700倍，在所有种子中非平凡，且在15个收敛种子中恰好等于真实差距（优势全非正）。
3. **关系表示实现跨尺度迁移**：DoorKey上，使用关系特征（导航谓词等）的Prolog列表、CART关系树、VIPER关系树在6×6和16×16上转移性能均接近教师；而使用绝对坐标的树在远离训练尺寸时回报降为0。原因在于导航谓词泛化到任意尺寸网格，而坐标阈值对特定尺寸硬编码。
4. **命题表示的回报天花板**：在低维连续控制中（CartPole, Acrobot），Prolog列表的回报随分辨率增加恢复至教师水平，但**显著落后于CART和VIPER**（CartPole平均低78.5回报，0/15种子胜出；Holm校正p=3.7×10^-4）。这印证了理论：一阶有序列表无法复用共享拆分的树结构，在无关系可捕捉时表现更差。
5. **维度诅咒的实证**：LunarLander（8维）即使在最高分辨率B=12也未能完全恢复教师回报（差距约66），而4维CartPole和6维Acrobot可恢复。提案4的下界Ω(B^{d-1})被近似验证（边界单元数log-log斜率≈d-1）。

## 7. 优点

- **理论保证完备**：提供了从分发率到回报差距的精确界、优势间隙局部化证书、单调改进与终止的扩展循环证明、以及命题转换的O(1/B)一致性和指数下界。所有证书在有限MDP中可精确计算，无需估计。
- **工艺完整性**：提取->归纳->扩展形成闭环，扩展阶段以精确回报为导向，允许符号学生**超越**神经教师，而非仅模仿。
- **表示对比清晰**：通过DoorKey坐标树 vs 关系树的对比，明确证明了“关系表示”而非“逻辑程序本身”是跨尺度迁移的关键。连续控制中诚实报告了在命题形式下的天花板。
- **可读性**：输出Prolog程序（如Acrobot 11子句）人类可读，且逻辑引擎运行与参考评估器验证一致。提供了源码级别的可审计性。
- **与生成式AI结合**：第7节展示了用LLM（Claude）编写编辑，由精确oracle验证，4次编辑将三种子从0.5提升至最优0.812，展示了可验证的符号合成路径。

## 8. 不足与局限

- **模型访问要求**：有限MDP的精确证书和扩展需要完备模型（转移核、奖励函数、初始分布）和可达状态枚举，成本随状态数立方增长（O(n^3)）。超过数万规模时需替换为MC估计和DAgger，失去完备证书。
- **命题表示不如树**：在低维连续控制中，有序规则列表的表示能力弱于决策树，因无法共享拆分子树。论文将此归因为表示而非调参，已验证Gini最优阈值也无法弥补。这一局限性是本质的。
- **谓词语汇手工定义**：关键路径、导航等谓词为任务特定人工编码。缺乏自动谓词发明机制（如Sha et al., 2024的EXPIL），制约了方法的自动化程度。
- **统计检验边界**：LunarLander只有5种子，Wilcoxon p=0.0625无法达到传统显著水平；KeyDoor扩展阶段在某些种子接受0编辑（R1），导致扩展效果仅在R2显著。连续控制中CartPole的快速解决导致解释方差偏低，不影响蒸馏但需要说明。
- **缺乏复杂3D环境验证**：实验局限于离散网格和低维连续控制，未涉及视觉-运动控制（如DM Control、Atari）或高维连续任务。在这些任务上表示能力、数据效率、可读性尚未验证。
- **扩展阶段局部最优**：爬山法保证τ-局部最优而非全局最优。在KeyDoor上虽达到全局最优，但理论不排除局部陷阱。生成式LLM提案展示了突破局部最优的可能，但非系统性。
