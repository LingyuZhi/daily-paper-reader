## 摘要
大型语言模型智能体在部分可观测、长周期的环境中运行，获取监督信号仍是一个主要瓶颈。我们通过利用现有后训练方法中忽视的监督来源——智能体运行过程中无意中实现但实际成功的目标——来解决这一问题。具体来说，我们提出了事后监督学习（Hindsight Supervised Learning, HSL），其中辅助LLM审查每个完成的轨迹，并用智能体实际实现的所有自然语言目标重新标记该轨迹。HSL随后将轨迹与其重新标记的目标配对，并使用这些配对进行额外的微调。为了缓解重新标记数据中的次优性，我们提出了两种HSL学习技术：无关动作掩码和样本重新加权。实验表明，HSL灵活且与现有后训练流程兼容。它同时提升了SFT和DPO的性能，在具有更多样化目标空间的长周期任务上取得了更大的改进。此外，HSL具有样本高效性：在ALFWorld上，仅使用四分之一的地面真实演示，它就能超越在全数据集上训练的基线模型。

## Abstract
Large language model agents operate in partially observable, long-horizon settings where obtaining supervision remains a major bottleneck. We address this by utilizing a source of supervision overlooked in existing post-training methods: unintended yet successful goals embedded within agent rollouts. Specifically, we introduce Hindsight Supervised Learning (HSL), where an auxiliary LLM reviews each completed trajectory and relabels it with all of the natural-language goals the agent actually achieved. HSL then pairs the trajectory with its relabeled goals and uses these pairs for additional fine-tuning. To mitigate suboptimality in the relabeled data, we propose two learning techniques for HSL, irrelevant-action masking and sample reweighting. Our experiments show that HSL is flexible and compatible with existing post-training pipelines. It improves both SFT and DPO, with larger gains on long-horizon tasks with more diverse goal spaces. Moreover, HSL is sample-efficient: on ALFWorld, it surpasses baselines trained on the full dataset while using only one quarter of the ground-truth demonstrations.

### 1. 论文的核心问题与整体含义（研究动机和背景）

大型语言模型智能体（LLM agent）在部分可观测、长周期环境中运行，获取有效的监督信号是主要瓶颈。现有的后训练方法要么依赖昂贵且缺乏多样性的专家演示（如 SFT），要么在稀疏奖励和长周期下难以探索到高回报轨迹（如 RL）。本文发现一个被忽视的监督来源：智能体在执行指定任务的过程中，可能意外完成其他有效的自然语言目标（如“把杯子放进冰箱”即使指令是“冷却杯子放进橱柜”）。受 hindsight experience replay (HER) 启发，本文提出事后监督学习（HSL），将智能体生成的轨迹通过事后重标记转化为成功的演示，从而有效挖掘隐藏的监督信息，缓解监督瓶颈。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：利用辅助 LLM 在事后（hindsight）识别智能体轨迹中实际完成的所有自然语言目标，并将轨迹与这些重标记目标配对，作为额外的监督信号进行微调。
- **关键技术细节**：
  - **轨迹收集**：智能体与环境交互，在给定原始指令下滚动产生轨迹。
  - **重标记过程**：
    - **目标识别（Goal Identification）**：辅助 LLM `M` 零样本推理，基于完整轨迹和最终观测输出所有实际达成的目标指令列表 `{I'_1, ..., I'_K}`。每个目标对应其首次达成的时间步 `S(I'_k)`。
    - **动作相关性标注（Action Relevance Labeling）**：对每条重标记后的轨迹，另一个 LLM 评估每个动作 `a_u` 与重标记目标 `I'_k` 是否相关，输出标签 `z_u ∈ {0,1}`。
  - **学习技术**：
    - **无关动作掩码（Irrelevant Action Masking）**：在 SFT 损失中仅计算相关动作（z=1）的交叉熵，忽略无关动作，减少次优轨迹的影响。
    - **样本重新加权（Demonstration Reweighting）**：对重标记缓冲区 `D'` 中的样本按权重 `w_d = (n_d / T_d)^α · n_d` 采样，其中 `n_d` 是相关动作数（反映任务难度），`T_d` 是轨迹长度（`n_d/T_d` 反映最优性），`α` 平衡两者。
  - **整体损失函数**（式 4）：
    ```math
    L^{HSL}_θ = λ·L_{D'} (masked SFT on relabeled data) + (1-λ)·L_{Dtrain} (SFT on ground-truth demonstrations)
    ```

    其中 `λ` 为混合权重。

### 6. 论文的主要结论与发现

- HSL 作为后训练插件，能显著提升 SFT 和 DPO 的性能，尤其在长周期、多样目标空间的任务（ALFWorld 提升 8%-32%）。
- 样本高效：在 ALFWorld 上仅用 1/4 ground-truth 数据即可超越全量基线。
- 重标记数据质量高（准确率 90%），重标记比直接执行任务更容易。
- 改进得益于发掘中间成功目标、无关动作掩码和重加权技术，理论分析也支持其有效性。
- 在短周期、窄目标空间的任务（WebShop）上增益较小，因为每条轨迹只能达成一个目标。

### 7. 优点

- **创新性**：巧妙利用 LLM agent 运行时意外达成的隐藏成功目标，变废为宝，开辟了新的监督来源。
- **兼容性**：即插即用，可与现有 SFT、DPO 等主流后训练方法无缝结合。
- **理论支撑**：定理 1 从占用度覆盖和 KL 散度角度提供了差距上界，指导了学习技术设计。
- **样本效率**：大大减少对昂贵专家演示的依赖，实用价值高。
- **简单有效**：提出的掩码和重加权技术实现简单，消融验证其必要性。
- **鲁棒性**：评估了多种种子和不同数据量，结果稳定。

### 8. 不足与局限

- **依赖外部强大 LLM**：重标记使用 Llama-3.3-70B，计算成本高，且未联合训练重标记模型。
- **二元相关性假设**：每个动作仅标为相关或不相关，无法区分动作的最优程度（如效率不同的路径）。
- **分布不匹配**：重标记数据的目标分布与原始任务分布有偏差（如“检查”类任务被低估），可能导致 agent 在某些目标上性能偏弱。
- **仍需少量 ground-truth 数据**：HSL 不能完全脱离专家演示，仍需少量数据稳定训练（λ 保持混合）。
- **实验覆盖有限**：仅测试了 1B 的 agent，未在更大模型或更多 agent 任务（如 GUI agents、代码 agents）上验证；PlanCraft 只用了单个种子。
- **预定义目标空间**：方法假设任务有预定义的目标模板，在开放世界场景中直接应用受限。
- **未考虑意外目标的价值或安全性**：未对意外目标的有害性或低价值进行过滤或惩罚，在真实应用中可能存在风险。
