## 摘要
大语言模型智能体常常遇到相关但不同的任务，这些任务共享可重用的解决方案模式。然而，标准的智能体强化学习将任务视为独立片段，而现有的技能学习方法要么专注于重复尝试单一任务，要么使用多阶段流水线，将提取、检索和执行纠缠在一起。我们提出了SkillRise，一个用于跨任务技能学习的统一强化学习框架。SkillRise将相关实例组织成逐步具有挑战性的序列，并使用单一策略交替进行任务求解和策展一份不断演化的技能文档，该文档直接传递给下一个任务。跨任务的解耦信用分配使用当前任务结果监督求解，并使用折扣后的下游结果监督策展。在ALFWorld、WebShop和ScienceWorld上的实验表明，SkillRise在对比方法中取得了最强的Pass@1性能，相较于最强基线提升了2.3到8.5个百分点。尽管是在不同任务上训练，其学到的策展策略在相同任务的重复尝试中仍然有效。进一步分析揭示了测试时的跨任务扩展：即使每个任务只尝试一次，随着更长相关任务序列的出现，性能也会提升。这一趋势表明SkillRise跨任务重用可迁移技能，而非受益于同一任务的重复采样。SkillRise进一步保持了强大的性能，同时大幅降低了多阶段技能学习流水线的运行时开销。综上所述，这些结果为LLM智能体提供了一种简单高效的训练范式，用于跨任务提取、提炼和重用可迁移技能。

## Abstract
Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

## 1. 核心问题与整体含义（研究动机与背景）
- **问题**：标准智能体强化学习将每个任务视为独立片段，智能体无法从过往交互中积累可迁移经验，每次都从零探索。现有技能学习方法要么只关注同一任务的重复尝试（技能难以跨任务泛化），要么采用多阶段流水线（提取、存储、检索、执行相互纠缠），导致归因困难、计算开销大。
- **动机**：现实场景中智能体常遇到一系列相关但不同的任务（如同家族但实体不同的家居操作），这些任务共享可重用的交互模式。需要一个统一的端到端框架，让智能体在求解当前任务的同时提取、提炼并重用跨任务可迁移技能，从而不断提升后续任务性能。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将相关但不同的任务实例组织成有序序列，使用单一策略交替进行任务求解和技能文档策展，通过解耦的跨任务信用分配联合优化两个行为，使技能文档成为跨任务信息传递的唯一通道。
- **关键技术细节**：
  - **跨任务序列构建**：利用环境提供的任务家族元数据，从一个家族中选择不同实例，按难度（如属性数量、选项数）从简单到复杂排序，形成长度为 K 的序列。
  - **带技能进化的跨任务 rollout**：从空文档开始，对序列中第 i 个任务，策略先用当前文档 $S_{i-1}$ 求解得到轨迹 $\tau_i$ 和奖励 $r_i$；然后策略切换为策展角色，基于 $S_{i-1}$、$\tau_i$、$r_i$ 生成更新后的文档 $S_i$（只保留抽象技巧，去除实例细节）。只有 $S_i$ 传递给下一个任务，历史轨迹不保留。
  - **解耦信用分配**：
    - 求解阶段：回报 = 当前任务奖励 $r_i$。
    - 策展阶段（$i < K$）：回报 = $\sum_{j=i+1}^{K} \gamma^{j-i} r_j$，其中 $\gamma \in [0,1]$ 为跨任务折扣因子。
  - **角色感知的组相对优化**：对同一序列中相同任务位置和相同角色的 N 个试验，计算组内相对优势 $A^{(n)}_{i,z} = G^{(n)}_{i,z} - \bar{G}_{i,z}$，然后使用 PPO clip 目标优化所有 token。
- **训练算法**：采样 N 个独立试验，每个试验独立维护技能文档，使用 GRPO 风格的组内基线，但组按“任务位置+角色”划分，确保求解和策展信号不相互干扰。

## 6. 主要结论与发现
- **整体结果**：SkillRise 在三个基准上均取得最佳 Pass@1（85.9% ALFWorld, 84.4% WebShop, 54.6% ScienceWorld），比最强基线 GiGPO 分别提升 2.3、7.1、8.5 个百分点。
- **跨任务测试时扩展**：随着相关任务序列变长（K 从 2 到 6），性能单调提升（+3.9 pp），而对比方法无此趋势，说明技能文档在序列中持续改进。
- **同任务泛化**：尽管训练时使用不同任务序列，学到的策展策略在重试同一任务时仍有效（Pass@3 优于 LaMer 0.8–14.2 pp），表明获得了通用的技能抽象能力。
- **模型规模增益**：从 1.7B 到 4B，SkillRise 提升幅度（+7.8 pp）大于 GRPO（+4.7 pp）和 LaMer（+3.3 pp），表明更大模型容量对跨任务技能学习特别有益。
- **效率优势**：端到端运行时间仅为多阶段方法（RetroAgent 6×, SkillRL 4.3×）的 1/6，性能却持平或更高。
- **消融验证**：去除策展后性能下降约 3 个百分点，证明显式技能文档转换是关键；折扣因子在 0.3–0.7 范围内鲁棒。

## 7. 优点
- **统一端到端设计**：单一策略同时负责求解和策展，无需外部教师、独立记忆库或检索模块，简化了技能学习流水线。
- **解耦信用分配**：根据行为的时间角色（求解影响当前，策展影响后续）分配不同回报，避免了信号混淆，使得优化目标清晰。
- **高效训练**：计算开销远低于多阶段流水线，但性能更优，体现了简洁设计的优势。
- **跨任务泛化与扩展**：训练后不仅能在新序列中持续进步，还能泛化到同任务重试，并且测试时序列越长性能越好，展示了自我改进的可扩展性。
- **鲁棒性**：对折扣因子不敏感，表明方法对超参数选择稳健。

## 8. 不足与局限
- **依赖元数据**：当前方法需要任务家族元数据来构建序列；自动发现任务关系是未来方向。
- **模型规模有限**：受限于计算资源，实验仅在 1.7B/4B 规模上进行，更大模型的效果未知。
- **环境范围**：仅在三个文本交互基准上验证，未涉及多模态环境、真实世界复杂任务或非可验证奖励场景。
- **奖励要求**：依赖可验证的二元奖励（成功/失败），对于需要连续评分或细粒度反馈的任务可能不直接适用。
- **序列长度限制**：训练时固定 K=3，虽然测试时能扩展到 K=6，但更长序列（如数十个任务）的行为未经探索。
