## 摘要
开放智能体系统（OASYS）在现实世界中日益普遍，其中智能体和任务集合随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对多智能体强化学习（MARL）构成了根本性挑战，因为MARL通常假设固定的状态和动作空间。现有方法仅部分解决开放性问题：填充和掩码方法引入人为边界，而最近的基于图或超图的方法处理了一个维度的开放性，但仍依赖于限制性假设。在本文中，我们提出了面向智能体与任务开放性的指针学习器（PLATO），这是一种基于指针网络的actor与集中式图神经网络（GNN）critic相结合的方法，在集中式训练与分布式执行范式下使用多智能体近端策略优化进行训练。我们的基于指针的actor直接在当前任务集上输出分布。这直接支持变化动作空间，无需掩码或重新训练。我们的GNN critic将智能体-任务交互编码为一个随任务和智能体组成而改变形状的图。这些组件共同考虑了AO和TO，而没有现有方法的边界限制。我们在任务与智能体开放马尔可夫博弈（TaAgO-MG）中形式化PLATO，扩展了先前的任务开放公式，并证明其在产生的无界状态和动作空间上是良定义的。我们使用开放智能体系统评估方法倡议（MOASEI）的野火抑制领域评估PLATO，该环境专为开放多智能体系统评估设计，我们展示了比OASYS中最先进的基线更强的性能和更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

## 1. 核心问题与整体含义
- **研究动机**：开放智能体系统（OASYS）中，智能体集合（Agent Openness, AO）和任务集合（Task Openness, TO）会在线动态变化（如加入、退出、出现、消失），而传统多智能体强化学习（MARL）通常假设固定的状态和动作空间，无法直接适应这种开放性。
- **整体含义**：设计一种能同时处理AO和TO、无需重训练或人为边界（如固定尺寸填充）的MARL方法，对于实现鲁棒、可扩展的真实世界多智能体部署至关重要。

## 2. 方法论
- **核心思想**：将动作选择从固定的分类索引重构为基于内容的**指针机制**。每个智能体形成上下文查询（query），通过注意力匹配当前任务特征键（keys），直接输出一个支持当前任务集的分类策略，从而自然适应TO；同时通过置换不变统计量聚合当前智能体团队信息，适应AO。
- **关键技术细节**：
  - **指针Actor**：将局部观测分解为智能体特征矩阵和任务特征矩阵；对智能体矩阵计算均值、方差、最小、最大四个统计量得到固定长度向量，经MLP编码为查询；对每个任务（含NO-OP）独立MLP编码为键；使用加性注意力计算查询与各键的兼容性得分，softmax得到策略分布。
  - **GNN Critic**：将全局状态建模为二分图（智能体节点和任务节点），使用图卷积网络（GCN）进行消息传递，经过两层GCN后取所有节点嵌入的均值，再通过MLP映射为标量价值估计。
  - **训练框架**：CTDE（集中式训练，分布式执行），使用MAPPO（多智能体PPO）优化，critic在训练时使用中心化GNN，执行时仅使用分散式指针Actor。
- **数学基础**：
  - 定义任务-智能体开放马尔可夫博弈（TaAgO-MG），扩展自TaO-MG，显式建模AO和TO。
  - 证明Actor和Critic是置换不变的，且在可数无限的状态/动作空间上良定义。
  - 复杂度分析：每时间步训练成本O(|N|^2 + |N||X|)，其中|N|为当前智能体数，|X|为当前任务数。

## 3. 实验设计
- **领域与场景**：使用MOASEI Wildfire抑制环境（网格地图），包含三种开放性机制：
  - 内生TO：火势蔓延（概率0.6）
  - 外生TO：随机新火点（概率0.6）
  - 临时AO：灭火剂耗尽后退出再补充（概率0.6-1.0）
- **实验配置**：2×3、3×3、4×4三种网格尺寸；四个开放性设置（S0封闭基线；S1仅内生TO；S2仅外生TO；S3联合TO+AO，最复杂）。
- **基线方法**：
  - 智能基线：DGN、DICG、MOHITO（专为TO设计）
  - 启发式基线：NOOP（总是无动作）、Random（均匀随机）、Weakest（优先最小火）、Strongest（优先最大火）
- **评估指标**：平均回合回报（episode return）、每次扑火动作的平均奖励（reward per fight）、无动作比例（NOOP%）、扑灭次数、烧毁次数。150个评估回合（每方法3个checkpoint × 50种子）。

## 6. 主要结论与发现
- **原生性能**：在3×3和4×4网格的联合开放性设置（S2、S3）以及4×4网格几乎所有开放性设置（S1-S3）上，PLATO的回合回报显著优于所有基线。在封闭设置（S0）上所有智能方法持平。
- **效率**：PLATO在多数开放设置下获得了最高的每次扑火奖励，说明资源利用更高效。
- **零样本泛化**：PLATO在从较小网格训练后迁移到更大网格时，表现比基线更一致，尤其在联合开放性下优势明显。DICG在某些迁移场景与之相当，而MOHITO和DGN在强开放性下退化严重。
- **消融**：MLP + 加性注意组合在原生测试中表现稳健；在零样本联合开放设置下，LSTM + 加性注意组合获得了更好的泛化能力，表明时序记忆在分布外场景中有用；但不存在通用最优配置。

## 7. 优点
- **创新性**：首次将指针网络引入MARL，联合处理AO和TO，无需固定边界、填充或重训练；形式化TaAgO-MG并证明良定义性。
- **设计优雅**：通过置换不变统计量和基于内容的注意机制，自然地适应可变规模的智能体集和任务集；CTDE架构保持执行的高效性。
- **实验严谨**：多维度评估（回报、效率、零样本）、统计显著性检验、消融分析、超参数调优；强调可重复性（三层种子协议）。
- **理论贡献**：提供置换不变性、良定义性、复杂度分析等理论保证。

## 8. 不足与局限
- **应用限制**：仅在一个领域（Wildfire）上验证，且每个任务只对应一个动作（扑救），未支持每个任务有多个动作的更一般情况。未来需扩展到更多OASYS领域。
- **假设**：假设智能体对任务和其他智能体具有完全可观测性（局部可观测但任务和智能体信息均可见），未覆盖部分可观测场景。
- **可扩展性**：虽然复杂度是多项式级，但在极端大规模智能体/任务（如成千上万）下GNN消息传递可能成为瓶颈（O(|N|^2 + |N||X|)）。论文未讨论超大规模部署。
- **FO（帧开放性）未涉足**：论文明确指出FO（智能体内部目标/能力变化）留作未来工作，当前仅处理AO+TO。
- **时序记忆的泛化性**：消融显示LSTM在某些零样本设置下有利，但机制未深入分析；需进一步研究时序记忆与注意力的相互作用。
- **计算资源**：全实验需大量CPU时间（数千CPU-days），可能限制复现或扩展。
