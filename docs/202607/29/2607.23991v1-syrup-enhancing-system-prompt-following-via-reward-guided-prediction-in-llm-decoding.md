## 摘要
大型语言模型（LLMs）越来越多地通过指定角色、风格、格式和安全要求的系统提示进行控制。然而，模型仅通过上下文学习隐式地遵循这些提示，这对于复杂或组合性提示可能是不够的。现有方法通常需要模型微调或响应级重排序，限制了其在轻量级推理时控制中的实用性。我们引入了SyRuP，一个在保持基础语言模型冻结的同时，提高系统提示遵循的解码时框架。SyRuP从系统提示条件化的偏好对中训练一个交叉注意力奖励头，将系统提示视为独立记忆以产生令牌级遵循分数。在推理时，SyRuP通过结合基础logits、学习到的奖励信号以及可选的对比信号（捕捉系统引发的logits偏移）对基础LM的top-k候选进行重排序。在系统提示遵循基准上的实验表明，SyRuP在适度的推理开销下始终优于提示和解码时基线。这些结果表明，显式的令牌级指导是实现可靠系统提示遵循的有效且实用的机制。

## Abstract
Large Language Models (LLMs) are increasingly controlled through system prompts that specify roles, styles, formats, and safety requirements. However, models follow these prompts only implicitly through in-context learning, which can be insufficient for complex or compositional prompts. Existing approaches often require model tuning or response-level reranking, limiting their practicality for lightweight inference-time control. We introduce SyRuP, a decoding-time framework for improving system-prompt adherence while keeping the base LM frozen. SyRuP trains a cross-attention reward head from system-prompt-conditioned preference pairs, treating the system prompt as a separate memory to produce token-level adherence scores. At inference, SyRuP reranks the base LM's top-k candidates by combining base logits with the learned reward signal and an optional contrastive signal capturing system-induced logit shifts. Experiments on system-prompt following benchmarks show that SyRuP consistently outperforms prompting and decoding-time baselines with moderate inference overhead. These results suggest that explicit token-level guidance is an effective and practical mechanism for reliable system-prompt following.

## 2. 论文提出的方法论

### 2.1 核心思想
- **SyRuP**（系统提示通过奖励引导预测进行遵循）：训练一个轻量级的交叉注意力奖励头，将系统提示视为独立的键值记忆（key-value memory），在解码时对每个候选令牌产生一个遵循分数，并与基础LM的logits以及一个可选的对比信号组合，对top-k候选令牌进行重排序。
- **关键设计**：保持系统提示的显式表征，而非将其合并到前缀序列中，从而实现对系统提示的定向评估。

### 2.2 关键技术细节

#### 交叉注意力奖励头
- 从冻结的基础LM中提取系统提示的隐藏状态 \(H(s)\)，作为键（K）和值（V）。
- 在每个解码步 \(t\)，将用户输入和已生成前缀的隐藏状态拼接得到上下文状态 \(H_{ctx,t}\)，作为查询（Q）。
- 通过交叉注意力计算输出 \(A_t\)，然后与 \(H_{ctx,t}\) 拼接后经两层MLP \(g_\phi\) 得到解码状态向量 \(z_t\)。
- 对于每个候选令牌 \(v\)，奖励分数 \(r_t(v) = z_t^\top e_v\)，其中 \(e_v\) 是令牌嵌入。

#### 训练
- 使用系统提示条件化的偏好对 \((s, x, y^+, y^-)\)，采用 Bradley-Terry 目标：
\[
\mathcal{L}_{RM} = -\mathbb{E}_{(s,x,y^+,y^-)} \log \sigma\left(\beta(R^+ - R^-)\right)
\]
其中 \(R\) 是序列级奖励（各令牌奖励平均）。
- 仅训练奖励头参数（交叉注意力投影矩阵和MLP），基础LM冻结。

#### 解码
- 限制在基础LM的top-k候选令牌（\(k=10\)）中进行重排序。
- 综合得分：
\[
y_t = \arg\max_{v \in C_t} \left[ \ell_t(v) + \lambda_r r_t(v) + \lambda_c \Delta_t(v) \right]
\]
其中 \(\ell_t\) 是基础LM logits，\(\Delta_t(v) = \ell_t(v) - \ell_t^{\text{neu}}(v)\) 是对比信号（系统提示 vs 中性提示的logits差），\(\lambda_r, \lambda_c\) 为权重。
- 当 \(\lambda_c = 0\) 时退化为纯奖励引导；\(\lambda_c > 0\) 时为混合模式。

### 2.3 算法流程（文字说明）
- **训练阶段**：对每个batch，冻结基础LM，计算系统提示隐藏态并缓存。对于每个偏好对中的选择响应和拒绝响应，逐令牌计算交叉注意力奖励头输出，累加得序列奖励，然后用Bradley-Terry损失更新奖励头参数。
- **解码阶段**：预先计算并缓存系统提示的键值对。对于每个解码步，由基础LM生成top-k候选令牌及其logits，同时通过交叉注意力奖励头计算每个候选令牌的奖励分数，并可选地计算对比信号，最后按加权和选择最优令牌。

1. **SyRuP在域内系统提示遵循上显著优于所有基线**：在15个模型-任务组合上均取得最佳平均分，相对于最强基线平均提升约3.5%-5.6%（不同模型）。

5. **推理开销适中**：纯奖励引导仅增加4%延迟，混合模式增加约118%，但仍远低于ARGS、DeAL等方法的数倍开销；峰值内存几乎不变。

## 7. 优点

- **轻量级、冻结基础LM**：仅训练一个小的奖励头（交叉注意力+MLP），无需更新大型模型，适合快速部署。
- **显式令牌级遵循评估**：通过交叉注意力机制直接衡量每个候选令牌与系统提示的匹配程度，比隐式方法更可控。
- **灵活的混合解码**：可灵活组合奖励信号和对比信号，并可通过调整权重平衡遵循度与流畅度。
- **优秀的泛化能力**：训练于偏好数据集，能在可验证指令基准（IFEval）上表现出竞争力，表明学习到的信号具有一定通用性。
- **良好的实证效果**：在多个模型和任务上稳定提升，且定性示例显示生成质量更高、更符合系统提示要求。

## 8. 不足与局限

1. **推理开销**：混合模式需要额外前向传播计算对比信号，延迟增加约2.18倍，虽优于其他解码基线，但对实时应用仍有限制（尤其在长输出场景）。
2. **过度引导风险**：若奖励权重过高，可能牺牲流畅性或任务相关性；虽然top-k限制缓解了问题，但缺乏自适应调节机制。
3. **依赖高质量偏好数据**：需要与目标系统提示分布匹配的偏好对来训练奖励头，跨领域泛化能力可能因训练数据偏差而受限。
4. **未测试更大模型**：实验最大到8B参数，对于更大模型（如70B）的性能和稳定性尚未验证。
5. **未考虑多轮对话中的系统提示更新**：当前假设系统提示在整个生成中固定，但实际多轮交互中可能动态变化，需进一步适配。
6. **安全考量**：改进系统提示遵循可能使模型更严格地执行潜在有害或不合理的系统指令，需配合安全监控方案。
