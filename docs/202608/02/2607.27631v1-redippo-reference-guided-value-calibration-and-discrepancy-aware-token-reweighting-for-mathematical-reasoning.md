## 摘要
强化学习已成为增强大型语言模型数学推理能力的有效范式。在现有的策略优化方法中，近端策略优化（PPO）因其学习到的评论家原则上可以提供令牌级别的信用分配而特别具有吸引力。然而，在以长推理轨迹和稀疏结果奖励为特征的数学推理任务中，可靠的令牌级别信用分配仍然具有挑战性。标准的评论家往往无法准确评估中间推理状态，导致优势估计噪声大和策略更新次优。在本文中，我们提出了ReDiPPO，一种用于数学推理的参考引导和差异感知的PPO框架。ReDiPPO引入了一个参考引导的评论家，该评论家使用参考答案作为训练时的特权信号，以提供更准确的价值估计。同时，它保留了一个标准评论家，并量化了标准价值估计与参考引导价值估计之间的令牌级参考-标准差异。该差异作为困难推理状态的指示器，并用于在PPO优化期间重新加权相应的令牌级优势。在多个数学推理基准上的大量实验表明，ReDiPPO提高了价值估计的准确性，并在最终推理性能上持续优于强策略优化基线，包括PPO、DAPO和GSPO。我们的代码可在https://github.com/cii030/ReDiPPO上获得。

## Abstract
Reinforcement learning has emerged as an effective paradigm for enhancing the mathematical reasoning capabilities of large language models. Among existing policy optimization methods, Proximal Policy Optimization (PPO) remains particularly appealing because its learned critic can, in principle, provide token-level credit assignment. However, in mathematical reasoning tasks characterized by long reasoning horizons and sparse outcome rewards, reliable token-level credit assignment remains challenging. The standard critic often fails to accurately evaluate intermediate reasoning states, resulting in noisy advantage estimates and suboptimal policy updates. In this paper, we propose ReDiPPO, a Reference-guided and Discrepancy-aware PPO framework for mathematical reasoning. ReDiPPO introduces a reference-guided critic that uses reference answers as training-time privileged signals to provide more accurate value estimation. Meanwhile, it retains a standard critic and quantifies the token-level reference-standard discrepancy between the standard value estimate and the reference-guided value estimate. This discrepancy serves as an indicator of difficult reasoning states and is used to reweight the corresponding token-level advantages during PPO optimization. Extensive experiments on diverse mathematical reasoning benchmarks demonstrate that ReDiPPO improves value-estimation accuracy and consistently outperforms strong policy optimization baselines, including PPO, DAPO, and GSPO, in final reasoning performance. Our code is available on https://github.com/cii030/ReDiPPO.

## 1. 核心问题与研究动机

- **研究背景**：在数学推理任务中，强化学习（RL）已成为提升大语言模型（LLM）推理能力的有效范式，其中 RLVR（Reinforcement Learning with Verifiable Rewards）通过自动验证器比较最终答案与参考答案来提供结果奖励。现有的方法主要分为两派：
  - **Critic-free 方法**（如 GRPO、DAPO、GSPO）：无需训练价值模型，构建响应级优势分数再广播到所有 token，简单有效，但无法区分同一响应内不同推理状态的优劣。
  - **Critic-based 方法**（如 PPO、VAPO、VC-PPO）：通过学习价值函数提供 token 级信用分配，语义上更精细，但在长推理轨迹和稀疏终局奖励条件下，**标准 critic 难以准确评估中间推理状态**，产生噪声较大的优势估计，导致策略更新次优。
- **核心问题**：在数学推理场景下，局部看似合理的步骤仍可能最终出错，而未完成但前景良好的推导可能看似不确定——标准 critic 仅凭 prompt 和部分响应预测最终正确性，本质上是一种"盲估"。这种价值估计偏差会直接影响 token 级优势的方向和量级，是 PPO 在长链推理中效果不稳定的核心症结。
- **关键观察（不对称性）**：在现有 PPO-based RLVR 系统中，**参考答案决定了终局奖励，却无法被负责 token 级信用分配的 critic 所使用**。这构成了一个天然可用但被忽视的监督信息源。

## 2. 方法论：ReDiPPO 框架

### 2.1 整体设计思想

ReDiPPO 采用**双 critic 结构**，将参考答案作为**训练时的特权信息**仅仅提供给 critic（policy 保持纯 prompt 接口），从而：
- 用参考引导的 critic 提供更准确的 token 级价值基线；
- 利用两个 critic 的价值差异识别"困难推理状态"，对其进行重新加权。

### 2.2 参考引导的价值校准（Reference-Guided Value Calibration）

- **标准 critic**（面向无参考条件）：接收原始上下文，对给定的部分状态 $s_{i,t} = (x_i, y_{i,<t})$ 预测：
  $$v^{\text{std}}_{i,t} = V^{\text{std}}_\phi(s_{i,t})$$
- **参考引导的 critic**（面向训练时的特权条件）：接收答案增强后的上下文（模板：*"The ground truth answer is {answer}."*），预测：
  $$v^{\text{ref}}_{i,t} = V^{\text{ref}}_\psi(s_{i,t}, z_i)$$
- **价值学习**：两个 critic 共享同一回归目标（验证器返回的 $G_i$），因此差异完全来自信息条件的不同，而非目标不同。均使用 PPO 风格的带裁剪的价值损失函数。
- **优势计算**：由于奖励仅在终局给出且 $\gamma = \lambda = 1$，参考引导的优势为：
  $$\hat{A}^{\text{ref}}_{i,t} = G_i - v^{\text{ref}}_{i,t}$$
- 注意：这里只用 $v^{\text{ref}}$ 作为 actor 基线；$v^{\text{std}}$ 仅作为对比，用于差异感知重加权。

### 2.3 差异感知的 Token 重加权（Discrepancy-Aware Token Reweighting）

- **参考-标准差异**定义：
  $$e_{i,t} = v^{\text{ref}}_{i,t} - v^{\text{std}}_{i,t}$$
  差异越大，说明参考答案对价值判断的影响越大；论文由此推断该 token 状态的评估对参考盲 critic 越"困难"。
- **归一化**：在批次有效 token 位置集合上减去均值、除以标准差，转换为以 1 为中心的权重：
  $$\omega_{i,t} = 1 + (e_{i,t} - \mu_e)/(\sigma_e + \epsilon_e)$$
- **裁剪**：$w_{i,t} = \text{clip}(\omega_{i,t}, w_{\min}, w_{\max})$，默认取 $[0.5, 2.0]$。以 1 为中心保留普通参考引导 PPO 作为默认更新，裁剪防止高差异位置主导优化。
- **最终优势**：
  $$\tilde{A}_{i,t} = \text{Whiten}_m(w_{i,t} \hat{A}^{\text{ref}}_{i,t})$$
  即先将差异权重乘以参考引导优势，再进行所有有效 token 位置的掩码白化（去均值除标准差）。
- 在 actor 优化时，critic 预测、差异权重和优势均为 detach 状态，不会反向传播至 critic。

### 2.4 优化目标

$$\mathcal{L}_{\text{ReDiPPO}}(\theta) = \mathbb{E}_{(i,t)\in M}\left[\min(\rho_{i,t}\tilde{A}_{i,t}, \overline{\rho}_{i,t}\tilde{A}_{i,t})\right]$$

即保留标准 PPO 裁剪型替代目标，但将优势替换为加权后的 $\tilde{A}$。

## 6. 主要结论与发现

- **主结果**：ReDiPPO 在 **3 个骨干 × 6 个基准**上的平均准确率均优于所有基线：
  - Qwen3-4B-Instruct：平均分 56.03（最佳基线 GSPO 54.46）
  - Qwen3-4B-Thinking：平均分 73.90（最佳基线 GSPO 73.15）
  - OLMo3-7B-Instruct-DPO：平均分 41.13（最佳基线 DAPO 40.47）
  - 较 vanilla PPO 提升 **1.19–2.37 个百分点**
- **消融结论**：参考引导价值校准与差异感知重加权均可独立带来增益，且二者互补；默认裁剪范围 $[0.5, 2.0]$ 取得最优准确率并避免无裁剪引起的响应长度膨胀。
- **差异分析结论**：
  - **响应级**：按平均差异分组的响应中，从最低到最高差异五分位，平均响应长度从 1,808 token 上升到 4,946 token（2.74 倍），准确率从 87.25% 下降到 53.81%——差异是可解释的**困难度指示器**。
  - **位置级**：参考引导的增益随响应推进逐渐增大；在最终 bin 中，EV 从标准 critic 的 0.191 提升到 0.548（Instruct）和从 0.213 到 0.798（Thinking）——说明参考信息在响应后期尤为关键，支持 token 级的重加权而非整段打分。
  - **特权信息形式**：简洁参考答案在最后的 20% 响应位置表现更优（56 个检查点中 50 个胜出），且下游准确率更高（59.58 vs 58.46 avg@16），但完整参考解法在中段（20–80%）路径选择上更好——表明需要路径多样的特权信号可作未来工作。

## 7. 方法亮点与贡献

- **特权信息利用方式新颖**：参考答案作为训练时特权信号提供给 critic 而不污染 policy，同时保持推理时的标准接口不变，是"免费"的信息增强。
- **差异即信号的思想巧妙**：两个 critic 的目标相同、仅信息条件不同，因此差值干净地度量"参考信息对评估的影响"，可作为可靠的困难-状态指示器，无需任何显式的过程性标注。
- **在 PPO 框架内的最小侵入**：保留标准 PPO 的裁剪目标、价值函数结构、GAE 风格优势形式，只替换价值函数的信息条件和加权方式，兼容性强，易集成到已有系统。
- **开箱即用的通用性**：在指令微调与推理模型两种类型的骨干上都有效，说明方法不依赖特定模型架构。
- **训练/推理解耦开销**：双 critic 仅训练时存在，推理阶段不增加任何计算成本。

## 8. 不足与局限

- **适用边界**：需要使用参考答案作为特权信号，仅适用于存在唯一可规则验证答案的领域（如整数答案数学题）；对于开放生成、自由回答、存在多种等价表达的场景，方法需要适配；论文在结论中也坦承这一点是开放问题。
- **训练数据局限性**：仅使用整数答案的 DeepMath 子集和 DAPO-17K，未覆盖需要更长链条、更多步骤或非整数答案的题目。
- **消融覆盖不完整**：
  - 裁剪范围消融只在 Qwen3-4B-Instruct 上运行，未在其余骨干交叉验证。
  - 特权信息形式（答案 vs 解法）也仅在单骨干单次运行上进行，且论文明确指出"生成的单一参考解法不能代表有效推理路径的多样性，可能使 critic 偏向特定路径"，该结论的统计稳健性和通用性有待检验。
- **额外的训练开销**：双 critic 使训练时间较 PPO 增加约 16–24%（Instruct: +440s/步，Thinking: +1,544s/步），对超大规模模型的长训练周期可能不具经济性。
- **差异权重的启发式定义**：使用 $(e - \mu)/\sigma$ 的线性归一化加裁剪，缺少对更复杂权重函数（非线性、自适应的层间权重）的探索。
- **公平性细节**：主要基线对比中，GSPO 的裁剪范围与 PPO/DAPO 不同（0.0003/0.0004），但这些是各方法的最优设置，属于合理做法；未报告逐 benchmark 的方差或显著性检验，部分结果差距较小（如 OLMo 骨干上 ReDiPPO 与 DAPO 平均分差仅 0.66），需要考虑随机性影响。
