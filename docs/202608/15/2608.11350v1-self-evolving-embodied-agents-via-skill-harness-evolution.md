## 摘要
具身智能体越来越多地被构建为围绕基础模型的系统，其性能不仅取决于模型权重，还取决于模型周围的技能、上下文、动作接口和执行工装。虽然监督微调和强化学习可以使智能体适应新环境，但它们需要额外的数据、奖励和训练过程；与此同时，许多免训练的代码中心方法依赖于可编程的机器人API，这些API在固定接口设置中可能不可用。我们提出SHAPER，一个用于免训练具身适应的自演化框架，它保持模型参数冻结，并通过目标环境回滚来演化可复用的技能和上下文代码工装，从而改进非参数化智能体系统。在SHAPER中，同一个冻结模型既可以作为规划器也可以作为优化器，无需参数更新即可完善其外部技能和上下文代码工装。我们在VLABench和ESI-Bench上评估SHAPER，涵盖具有不同低级动作接口的具身智能体，并与纯执行、监督微调以及测试时缩放基线（如无验证器选择和投票）进行比较。我们的结果表明，当模型训练昂贵、不可用或不必要时，技能与工装优化是一条实现自进化具身智能体的实用途径。

## Abstract
Embodied agents are increasingly built as systems around foundation models, where performance depends not only on model weights but also on the skills, context, action interfaces, and execution harness surrounding the model. While supervised fine-tuning and reinforcement learning can adapt agents to new environments, they require additional data, rewards, and training runs; meanwhile, many train-free code-centric approaches rely on programmable robot APIs that may be unavailable in fixed-interface settings. We propose SHAPER, a self-evolving framework for train-free embodied adaptation that keeps model parameters frozen and improves the non-parametric agent system by evolving reusable skills and a context-code harness through target-environment rollouts. In SHAPER, the same frozen model can serve as both planner and optimizer, refining its external skills and context-code harness without parameter updates. We evaluate SHAPER on VLABench and ESI-Bench, covering embodied agents with different low-level action interfaces, and compare against pure execution, supervised fine-tuning, and test-time-scaling baselines such as verifier-free selection and voting. Our results suggest that skill-and-harness optimization is a practical route to self-evolving embodied agents when model training is expensive, unavailable, or undesirable.

## 2. 论文提出的方法论

### 2.1 核心思想
- **冻结参数，演化外部组件**：将一个具身智能体分解为四个部分：
  - VLM 规划器 $M_\theta$（冻结）
  - 执行器 $A_\phi$（冻结，可以是 VLA 模型或环境动作 API 封装）
  - 可复用技能 $s$（可优化，文本形式的程序性指导）
  - 上下文代码工装 $h$（可优化，Python 函数如 `build_context`，决定如何选择和格式化轨迹历史）
- **同一模型双重角色**：同一个冻结 VLM 权重，在交互时充当规划器，在演化时通过不同提示词充当"神器优化器"（artifact optimizer），无需更新任何参数。

### 2.2 问题形式化
- 智能体运行过程：
  - $y_t \sim M_\theta(\cdot | g, o_t, s, h(\tau_{<t}))$，其中 $y_t$ 为推理和接口级命令
  - $a_t = A_\phi(y_t, o_t)$，执行器映射为具体动作
  - $\theta, \phi$ 冻结；$s, h$ 被优化
- 优化目标：$J(s, h) = \mathbb{E}_{g \sim D}[R(\tau^{(s,h)}(g))]$，即最大化任务级奖励/成功信号的期望

### 2.3 技术流程（三阶段循环）
- **滚动引导的文本诊断（Rollout-Guided Textual Diagnosis）**：
  - 层级式诊断避免优化器直接处理大量多模态轨迹
  - **Round-level judger**：逐轮比较规划器响应/动作与执行前后的观察图像，生成局部评判（如子目标错误、无进展、执行器不匹配）
  - **Episode summarizer**：将非视觉元数据（命令、执行长度、运行时错误）与轮次评判和最终结果压缩为简洁的文本摘要
  - **Textual gradient**：批内摘要 + 聚合执行统计形成文本梯度 $\Gamma(c)$，暴露重复循环、指令漂移、上下文有害等跨轮模式
- **两阶段技能-工装演化（Two-Stage Skill-Harness Evolution）**：
  1. **技能演化**：固定种子工装 $h_0$，优化技能 $s$
  2. **工装演化**：固定演化后的技能 $s^\star$，优化工装 $h$
  - 每次迭代：优化器提出候选 → 沙箱验证（必须定义所需 context 函数，禁止 import、文件 I/O、动态执行，限时）→ 验证集评估 → 波束搜索保留 Top-K
  - 参数：4 轮波束搜索，宽度 3，分支因子 2，小批量 4 条 rollout

- **技能-工装演化有效提升冻结智能体性能**：VLABench 上 SHAPER 达到 34.50%（Seed 28.25%，Direct VLA 23.25%，SFT 24.00%）；ESI-Bench 上 SHAPER 达 49.8% 微平均/42.9% 宏平均（Seed 为 32.5%/31.2%）。

- **分布偏移下收益更大**：C3（任务形式从语义理解转为常识推理）增益最大（+10.0 点），C2 +6.0、C4 +6.5，而 C1 仅 +2.5，表明演化出的技能在跨任务形式迁移时最有价值。

- **工装演化改变信息保留策略是关键增益来源**：在镜面反射任务中，从"最近 5 帧"到"稀疏证据感知记忆+确定性裁剪"带来 20%→60% 的提升。

## 7. 优点

- **免训练且实用**：完全冻结模型参数，仅通过 rollout 反馈演化文本技能和代码工装，在模型权重不可访问或训练不经济时依然适用。
- **同一模型双重角色**：规划器和优化器共享同一 VLM 权重，通过不同提示词切换角色，无需额外优化器模型。
- **系统级视角**：同时优化技能（规划器如何推理/决策）和工装（哪些上下文呈递给规划器），比单独优化任一组件更全面，且消融表明两者互补。
- **文本梯度机制高效**：通过层级式诊断（round-level judgers → episode summarizer → textual gradient）将多模态长轨迹压缩为可操作的文本反馈，避免优化器处理大量视觉上下文，计算开销低（每环境演化不到 $3 的 API 等价成本）。
- **可解释性强**：演化产出的技能和工装是可直接阅读的文本/代码，案例研究清晰展示了演化前后的行为差异（如 VLABench 中命令重复→命令切换；ESI-Bench 中反射证据丢失→证据保留）。
- **跨接口验证**：在两种不同低级动作接口（VLA 执行器、环境动作 API）上验证，增强了结论的泛化性。

## 8. 不足与局限

- **实验覆盖范围有限**：

缺少对两阶段演化顺序（先技能后工装 vs. 先工装后技能）的消融实验，也缺少多随机种子的重复运行报告，因此无法评估演化流程对初始技能/工装配置的敏感性。

## 9. 总结

SHAPER 提出了一种全新的免训练具身适应范式：将智能体建模为“冻结模型 + 可演化外部组件”的系统，通过文本梯度在两阶段流程中交替演化可复用技能与上下文代码工装，在完全不更新模型参数的前提下显著提升了规划器在 VLABench 和 ESI-Bench 上的表现。该方法成本极低（每环境演化不足 $3）、过程可解释，并展示了分布偏移下更强的增益，为无法访问权重或训练资源受限的场景提供了一条实用路径。不过，其实验覆盖范围（模拟环境、单一规划器、小样本统计）仍有明显局限，缺少真实机器人验证与跨模型/跨具身泛化研究。总体而言，非参数化系统优化是具身智能适配的一个有前景的方向，值得进一步探索。
