## 摘要
技能进化通过随时间推移的反馈来改进智能体技能，失败轨迹通常通过揭示不完整或误导性行为提供信息性信号。然而，现有方法主要依赖单一轨迹，早期推理错误可能传播到后续步骤，削弱可用于技能精炼的反馈。因此，改进技能需要反复的滚动、诊断和更新周期，产生大量令牌成本。为应对这一挑战，我们提出Branch2Skill，一个将单一推理树转化为密集监督以实现技能进化的高效框架。对于每个任务或问题，Branch2Skill在固定预算下执行蒙特卡洛树搜索以获取多样化推理轨迹，然后比较精英路径与共享相同前缀的兄弟替代方案，提取关于保留、修订或避免哪些推理模式的逐步证据。最后，Branch2Skill将多步证据提炼为可复用的更新，使一个推理树能够提供跨多个推理步骤的监督，减少重复滚动-更新周期的需求。在涵盖推理和智能体任务的六个基准上，Branch2Skill持续改进任务性能并提升技能进化效率。例如，以GPT 5.5为目标模型，Branch2Skill比SkillOpt少使用73.2%的令牌，同时实现更优性能。这些结果表明，推理树不仅能支持更有效的轨迹搜索，还能为更高效的技能改进提供更丰富的监督。代码将发布。

## Abstract
Skill evolution improves agent skills through feedback over time, with failed trajectories often providing informative signals by revealing incomplete or misleading behaviors. However, existing methods mainly rely on single trajectories, where early reasoning errors can propagate through subsequent steps and weaken the feedback available for skill refinement. Consequently, improving skills requires repeated cycles of rollout, diagnosis, and update, incurring substantial token costs. To address this challenge, we introduce Branch2Skill, an efficient framework that transforms a single reasoning tree into dense supervision for skill evolution. For each task or problem, Branch2Skill performs Monte Carlo tree search under a fixed budget to obtain diverse reasoning trajectories, then compares an elite path with sibling alternatives sharing the same prefixes to extract step-wise evidence about which reasoning patterns to retain, revise, or avoid. Finally, Branch2Skill distills multi-step evidence into reusable updates, allowing one reasoning tree to provide supervision across multiple reasoning steps and reducing the need for repeated rollout-update cycles. Across six benchmarks covering reasoning and agentic tasks, Branch2Skill consistently improves task performance while enhancing skill evolution efficiency. For example, with GPT 5.5 as the target model, Branch2Skill uses 73.2% fewer tokens than SkillOpt, while achieving superior performance. These results demonstrate that reasoning trees can support not only more effective trajectory search, but also richer supervision for more efficient skill improvement. Code will be published.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：大语言模型（LLM）智能体需要在持续交互中积累经验、改进能力，但直接更新模型参数成本高昂，因此研究者采用“外部化”可复用工件（如自然语言技能、经验库、可执行程序）的方法，让冻结的模型通过反思和经验记忆复用有效流程。
- **核心问题**：从执行轨迹中提取可操作的技能更新信号非常困难。现有方法（如 SkillOpt、SkillAdaptor、SkillCAT 等）主要依赖**单条轨迹**的反馈。单次 rollout 只暴露模型推理分布中的一条路径，一旦早期决策出错，后续步骤会继承错误前提，导致整条轨迹只能提供少量、甚至误导性的更新信号；想要获得更多失败信号，就必须反复采样、诊断、更新，造成**稀疏监督和高 token 开销**。
- **关键洞察**：蒙特卡洛树搜索（MCTS）能通过探索同一前缀下的多种后续分支，提供更丰富的反馈来源。**兄弟节点共享相同的前缀，仅在当前决策处分歧**，因此其下游结果能提供局部化的、关于具体决策质量的证据。这种比较由树结构自然产生，无需额外错误归因模型。
- **整体含义**：推理树不仅能用于测试时搜索更优解，还能被转化为**密集、可定位、可复用的技能进化监督信号**，从而打破“一次 rollout 只能得到一个更新信号”的瓶颈，显著降低技能进化成本。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想
- **BRANCH2SKILL** 将单个推理树转换为多层次的“局部对比证据”：在精英路径上，针对每一个选中的推理步骤，与其**共享父节点**的兄弟候选步骤进行对比，根据下游结果判断应保留（retain）、修正（revise）还是避免（avoid）某种推理模式。
- 一个推理树可同时暴露多个匹配推理上下文下的失败模式，而不是像单轨迹方法那样只能给出一条诊断。

### 2.2 推理树构建（Stepwise reasoning tree construction）
- 每个训练问题生成一棵独立的推理树。
- 根节点表示空推理路径（包含问题与当前技能）。
- 非根节点包含一个推理步骤或环境动作，而非完整解。
- 关键超参数：最大深度 \(D_{max}\)、子节点数 \(C\)、迭代预算 \(I\)、探索系数 \(c_{puct}\)。
- **节点选择使用 PUCT 公式**：
  \[
  PUCT(u,v)=Q(v)+c_{puct}P(v|u)\frac{\sqrt{\max(1,N(u))}}{1+N(v)}
  \]
  其中 \(Q(v)\) 是节点 v 的回传平均分，\(N(\cdot)\) 是访问次数，\(P(v|u)\) 是先验概率。
- 目标模型为每个子节点生成一个“进度分数”（scalar progress score），表示该前缀是否可能导向正确完成，然后回传到根，更新路径上所有节点的统计量。
- 搜索终止后，若剩余深度或预算不足，目标模型会**补全未终结的前缀**，为所有分支提供可比较的终结结果。

### 2.3 共享前缀证据提取（Shared prefix evidence extraction）
- 从树中保留一条代表性路径（精英路径）：
  - 优先选择成功的终结路径；若无成功路径，则选择得分最高的失败路径。
  - 路径中每个深度 \(d\) 的节点记为 \(S^{i^*_d}_d\)。
- 与每个选中节点同父的兄弟节点集合为：
  \[
  B_d = \{ S^j_d \mid pa(S^j_d)=pa(S^{i^*_d}_d), j \ne i^*_d \}
  \]
- 选中节点与兄弟节点共享同一前缀，仅在深度 \(d\) 处的决策不同，因此下游结果差异可归因于该深度决策。
- 每条证据包含：共享前缀、选中步骤、少量评估过的兄弟节点、它们的下游结果、紧凑搜索统计量；**不向技能模型发送整棵树**。

### 2.4 技能修订与验证（Skill revision and validation）
- 当前技能 \(K_t\) 固定；将本次更新步中所有树的证据合并送给**技能模型（optimizer）**，它一次返回一个完整候选技能，而非零散建议。
- 三种修订操作：
  - **APPEND**：添加缺失的规则、条件或前提。
  - **REPLACE**：修正与证据冲突的动作、对象、条件或适用范围。
  - **DELETE**：删除误导性、冗余或与失败分支反复关联的指导。
- 验证门控（validation gate）：
  \[
  K_{t+1} = \begin{cases}
  \hat{K}_{t+1}, & g(\hat{K}_{t+1}; V) \succeq g(K_t; V) \\
  K_t, & \text{otherwise}
  \end{cases}
  \]
  其中 \(\succeq\) 表示所有指定验证指标不下降。
- 候选技能在固定验证集上使用**直接推理（无树搜索）**评估；不下降才接受，否则回滚到旧技能；保留验证性能最强的 checkpoint 作为最终评估结果。

## 6. 主要结论与发现

- **效率与性能双赢**：以 GPT-5.5 为目标模型，Branch2Skill 使用 **73.2% 更少**的进化 token（141.3M vs 526.7M），同时将聚合测试增益从 SkillOpt 的 117.8 提升到 128.7（+9.3%），每百万 token 增益从 0.224 提升到 0.911（**4.07 倍**）。

- **技能可迁移**：冻结的技能可以跨目标模型和跨数据集迁移，表明学到的是可复用流程而非记忆样例格式。
