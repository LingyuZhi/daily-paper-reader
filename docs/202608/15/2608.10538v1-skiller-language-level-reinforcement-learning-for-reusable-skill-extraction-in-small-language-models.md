## 摘要
智能体技能是一种将程序性知识与领域专业知识进行标准化封装的形式，在智能体框架系统中充当关键机制，持续约束语言模型的行为空间，以实现可重复、高质量的任务执行。然而，由于强大的闭源模型推理成本高昂，当前流行的智能体框架（如Codex和OpenClaw）在部署这些技能以完成实际任务时仍显得过于昂贵。可在消费级GPU上部署的开源模型能力迅速增强，为利用基于技能的行为约束大幅降低成本提供了极具吸引力的机会。尽管如此，专门为这类紧凑模型自动生成有效技能仍是一项重大的实际挑战。为此，我们提出SKILLER，一种自然语言驱动的强化学习框架，旨在为小模型自动生成执行器特定的技能。该框架以强模型作为智能体和评论家，将小模型智能体系统视为环境，并完全通过自然语言传播所有强化学习信号。使用Qwen3.5-9B和Qwen3.5-4B在五个相关基准上的广泛实验评估表明，SKILLER优于三种开源和一种闭源技能生成或进化方法，在9B模型上取得了4.3至20.4个百分点的绝对提升，在4B模型上取得了1.8至13.3个百分点的提升，同时在SkillsBench的单技能任务上与强闭源模型的表现相当。项目代码可在https://github.com/DANG-ai/SKILLER获取。

## Abstract
Agent skills represent a standardized format for packaging procedural knowledge and domain expertise, serving within agent harness systems as an essential mechanism to continually constrain a language model's behavior space for repeatable, high-quality task execution. However, because strong closed-source models entail high inference costs, current popular agent harnesses, such as Codex and OpenClaw, remain prohibitively expensive when deploying these skills to accomplish real-world tasks. The rapid capability enhancement of open-source models deployable on consumer-grade GPUs presents a compelling opportunity to drastically reduce these costs by leveraging skill-based behavioral constraints. Nevertheless, automatically generating effective skills tailored specifically for such compact models remains a significant practical challenge. To address this, we propose SKILLER, a natural-language-driven reinforcement learning framework designed to automatically generate executor-specific skills for small models, which employs a strong model as the actor and critic, treats the small-model agent system as the environment, and propagates all reinforcement learning signals entirely via natural language. Extensive experimental evaluations across five relevant benchmarks using Qwen3.5-9B and Qwen3.5-4B demonstrate that SKILLER outperforms three open-source and one closed-source skill generation or evolution methods, achieving absolute gains ranging from 4.3 to 20.4 percentage points for the 9B model and 1.8 to 13.3 points for the 4B model, while remarkably matching the performance of strong closed-source models on single-skill tasks in SkillsBench. The project is available at https://github.com/DANG-ai/SKILLER.

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 论文提出：SKILLER 框架
- 一种**自然语言驱动的强化学习框架**，将文本技能本身视为可优化的策略（policy），而非更新神经网络权重。
- 强模型（如 GPT-5.4）充当**演员（Actor）和评论家（Critic）**；目标小模型智能体循环（agent loop）充当**环境（Environment）**。
- 所有强化学习信号（状态、诊断奖励、策略更新动作）**完全通过结构化自然语言传播**。

#### 问题形式化
- 目标：对于小模型 π、任务实例 x，寻找技能 K 最大化期望奖励：
  $$K^\star_x = \arg\max_{K \in \mathcal{K}} J_x(K), \quad J_x(K) = \mathbb{E}_{(τ,r,v) \sim p_{E,π}(·|x,K)}[r]$$
- 环境转换将技能和任务映射到轨迹、奖励与诊断信号：
  $$(τ_i, r_i, v_i) = E(x, K_i; π)$$

#### 核心流程（如图 2 所示）
1. **环境（Environment）：** 封装基准的工具接口、工作空间和官方验证器，环绕紧凑模型 π，记录交互轨迹 τᵢ，返回标量奖励 rᵢ 与验证器诊断 vᵢ。
2. **状态与奖励（State & Reward）：** 构建结构化状态四元组 sᵢ = (x, τᵢ, τ*, vᵢ)，其中 x 为任务指令，τᵢ 为当前轨迹，τ* 为成功参考轨迹（仅优化阶段可见，不提供给执行器），vᵢ 为验证器诊断。
3. **评论家（Critic）：** 前沿模型分析当前状态、奖励和历史记忆，生成**自然语言技能修改建议 gᵢ**；对比当前轨迹与参考轨迹，定位最早因果错误，区分缺失程序指导、工具滥用、输出契约违反等，形成证据支持的局部修复方案。
4. **回放记忆（Replay Memory）：** 存储失败签名与验证器诊断、评论家摘要历史、已接受编辑及其结果，防止重复失败并保护有效行为。
5. **演员（Actor）：** 根据评论家建议执行**有界编辑操作**（Insert/Replace/Create/Delete），生成技能更新 Δᵢ；可合成确定性的任务局部辅助脚本，将复杂程序逻辑外置于自然语言之外。
6. 迭代执行上述循环 I 次，并支持批量优化与技能共享。

#### 关键设计
- **渐进式技能披露机制：** 防止小模型被冗长上下文压垮。
- **有界编辑而非整体重写：** 每次更新不超过 30 行、优先高杠杆编辑，保护有效内容。
- **快照回滚机制：** 若后续更新导致性能退化，自动恢复到最近一次通过的快照。
- **无梯度更新：** 所有反馈通过自然语言而非反向传播传递，计算开销集中在技能构造阶段。

### 6. 主要结论与发现

- SKILLER 在**所有五个基准、两个模型规模**上取得了最先进的整体性能，相比最佳基线：Qwen3.5-9B 提升 4.3~20.4 个百分点，Qwen3.5-4B 提升 1.8~13.3 个百分点。
- **SWE-Skills-Bench 与 SkillsBench 上优势最为突出**（9B 分别达 82.80% 与 73.91%），证明自然语言强化学习在严格工具序列和输出契约的任务中修复机械性错误方面效果显著。
- **Qwen3.5-4B + SKILLER 在 SWE-Skills-Bench 上超过 Qwen3.5-9B + 各类人工/自动/闭源技能**，表明针对执行器的专属技能优化比单纯扩大参数规模更有效——这是一个重要发现。
- **零样本测试**表明 SKILLER 学到的技能具备真实的迁移能力，而非过拟合到生成实例的表面特征。
- **结构分析**显示 SKILLER 生成的技能具有低的 TF-IDF 相似度（高度特化）与高的辅助脚本/代码行数（程序性逻辑外置），与小模型有限的上下文窗口高度契合。
- **成本-性能分析**表明：SKILLER 在中等生成成本（$8.95）下取得最高平均分（62.86），性能远超成本最低的 AutoSkill（48.02）和成本最高的 SkillX（52.60），验证了"有界编辑 + 精确执行反馈"的高投资回报率。
- 技能演进过程显示，SKILLER 能系统地逐步添加输入接地、任务局部辅助、自验证等约束，将通用流程转化为可执行、可纠错的特化技能。

### 7. 优点

4. **计算高效：** 所有前沿模型计算集中在离线技能构造阶段，部署期只使用低成本的紧凑模型推理。
5. **实验结果扎实：** 多基准、多模型、零样本验证、消融分析、学习动态、结构分析和成本分析构成了较完整的研究闭环。
6. **辅助脚本机制巧妙：** 将复杂程序性逻辑从自然语言中剥离到确定性代码中，显著减轻小模型的认知负担。
7. **回滚与记忆机制：** 快照回滚防止更新破坏已有性能，回放记忆避免重复犯错，具有工程实用性。

### 8. 不足与局限

1. **对前沿模型的依赖：** SKILLER 的生成质量依赖于 GPT-5.4 级别的闭源强模型作为演员/评论家；若无法访问这类模型，框架不可用。这在一定程度上限制了其完全开源部署的独立性。
2. **技能生成成本未完全透明：** 虽然报告了 token 与美元成本，但**未将小模型的推理验证成本计入总成本**（论文明确排除），实际端到端成本可能更高。
3. **模型泛化范围有限：** 实验仅使用 Qwen3.5-9B/4B，未覆盖更广的开源小模型（如 Gemma 4、Llama 3 小模型等），方法的跨架构通用性尚未验证。
4. **基准选择存在偏差：** SkillsBench 仅取子集（26/233），SWE-Skills-Bench 仅保留技能影响明显的任务；论文声明了这一点，但这些选择可能放大了技能干预的效果。
5. **消融范围有限：** 消融实验仅使用 Qwen3.5-9B 执行器，且运行次数较少，统计显著性未做检验。
6. **可能的环境过拟合风险：** 技能是为特定执行器+特定 OpenCode 框架联合优化的，更换 agent harness 或工具接口后，技能可能失效或需要重新优化。
7. **参考轨迹依赖：** 框架需要提供成功的参考轨迹 τ* 作为优化信号，这在真实世界中并非总是可得；论文未充分讨论参考轨迹不可用或质量不佳时的应对策略。
