## 摘要
LLM智能体通过将程序性知识积累为技能，日益适应重复性任务。这些技能是轻量级、可复用的文本制品，无需权重更新即可加载到智能体的上下文中。近期方法通过迭代任务执行、失败诊断和轨迹引导的文本空间更新来细化技能。然而，现有框架缺乏显式的诊断—结果反馈，并将删除视为通用编辑操作，而非整合积累知识的专门机制。我们提出SkillProx，一种受近端梯度启发的正向—反向框架，将闭环诊断进化与效用感知的近端细化相结合。受平衡任务损失与技能复杂性的复合目标驱动，前向阶段在同一任务批次上重新执行诊断驱动的编辑，回滚回归，并将测量结果馈入后续诊断。反向阶段将所得技能分解为可审计的知识单元，使用冻结的留一效用审计估计其贡献，并应用验证门控的整合、降级或移除。在多种骨干LLM的分布内和分布外基准上的实验表明，SkillProx相比最强的基于梯度的基线，平均准确率提高了3.0个百分点。组件消融研究证明了闭环诊断与近端细化的互补效应。

## Abstract
LLM agents increasingly adapt to recurring tasks by accumulating procedural knowledge in skills. These skills are lightweight, reusable textual artifacts that are loaded into the agent's context without weight updates. Recent methods refine skills through iterative task execution, failure diagnosis, and trajectory-guided text-space updates. However, existing frameworks lack explicit diagnosis--outcome feedback and treat deletion as a generic edit operation rather than a dedicated mechanism for consolidating accumulated knowledge. We introduce SkillProx, a proximal-gradient-inspired forward--backward framework that couples closed-loop diagnostic evolution with utility-aware proximal refinement. Motivated by a composite objective balancing task loss and skill complexity, the forward stage re-executes diagnosis-driven edits on the same task batch, rolls back regressions, and feeds measured outcomes into subsequent diagnoses. The backward stage decomposes the resulting skill into auditable knowledge units, estimates their contributions using a frozen leave-one-out utility audit, and applies validation-gated consolidation, demotion, or removal. Experiments on in-distribution and out-of-distribution benchmarks across multiple backbone LLMs show that SkillProx improves average accuracy by 3.0 percentage points over the strongest gradient-based baseline. Component ablations demonstrate the complementary effects of closed-loop diagnosis and proximal refinement.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：LLM 智能体在解决重复性任务时，越来越多地采用“技能”（skill）这一形式来外部化程序性知识。技能是轻量级、可复用的文本制品（如 `SKILL.md` 与参考文件），在推理时被加载进上下文，无需更新模型权重。
- **现有方法的两大局限**：
  1. **前向更新未经验证（Unverified forward updates）**：LLM 生成的诊断通常被直接当作有效的更新方向，更新被提交后不再重新执行验证，其实际效果既未被测量，也未反馈给后续诊断。即“开环”演化。
  2. **技能无节制增长（Unregulated skill growth）**：迭代打补丁会不断扩张技能内容，但没有显式机制重新评估已积累的知识。冗余指令、冲突启发式、被错误泛化的任务特定解决方案会堆积，甚至干扰有用知识。现有框架将“删除”视为一种普通编辑操作，而非专门的知识整合/收缩机制。
- **核心研究问题**：如何将“结果验证的前向诊断”与“结构感知的后向精炼”耦合，使技能的任务能力与其积累的结构共同演化？
- **总体含义**：本文提出 SkillProx，一个受**近端梯度下降（Proximal Gradient Descent, PGD）** 启发的**前向—后向框架**，将技能演化建模为“任务性能 + 技能复杂性”的复合优化问题，实现了技能文本在离散空间中的“自进化”，在多个基准上取得优于现有技能演化方法的性能。

## 2. 方法论

### 2.1 核心思想
将技能演化类比为连续优化中的 PGD：
- **前向步骤**（对应梯度下降）：通过“执行→诊断→打补丁→同批次重执行→接受/回滚”的闭环，验证更新是否有效，实现性能导向的更新。
- **后向步骤**（对应近端算子/正则化）：通过冻结的留一效用审计，将技能分解为知识单元，识别并移除/整合低效用或负效用内容，实现结构/复杂性控制。
- 文本技能是离散且不可微的，因此方法不直接优化复合目标，而仅保留 PGD 的“前向—后向职责划分”作为概念框架。

### 2.2 前向：闭环诊断演化（Closed-Loop Forward Update）
- 每个前向迭代 \(k\) 使用一个训练批次 \(B_k\)，当前技能 \(X_k\) 在 \(B_k\) 上执行。
- 诊断器根据失败轨迹、对比性成功轨迹、历史记录及上一次拒绝原因提出编辑方向；打补丁器（Patcher）从同一迭代起点生成候选技能 \(\tilde{X}^{(j)}_k\)。
- **同批次重执行**：候选技能在相同批次 \(B_k\) 上重新执行，满足以下门控条件才被接受：
  \[
  \text{Gate}_{fwd}(\tilde{X}^{(j)}_k) = \mathbf{1}[H_{B_k}(\tilde{X}^{(j)}_k) \ge H_{B_k}(X_k)] \times \mathbf{1}[C_{B_k}(\tilde{X}^{(j)}_k) \ge C_{B_k}(X_k)]
  \]
  其中 \(H\) 为硬准确率，\(C\) 为平均单元格准确率。
- **回滚与重试**：首个严格提高硬准确率的候选提前终止搜索；否则最多尝试 3 次，选择字典序最优者；若仍不满足门控，则保持技能不变。
- **反馈记忆**：被拒绝尝试的观测硬/单元格变化与尝试方向会注入下一轮诊断；接受/拒绝摘要形成跨迭代的语义历史。

### 2.3 后向：冻结效用审计与近端正则化（Prox）
- **知识单元分解**：将前向结果 \(X_f\) 解析为 \(n\) 个可审计单元（L2 章节与 L3 引用文件）。
- **冻结留一效用审计**：对每个单元 \(q_i\)，计算移除后的边际效用：
  \[
  u^{\text{hard}}_i = H_V(X_f) - H_V(\text{Ablate}(X_f, q_i)), \quad
  u^{\text{cell}}_i = C_V(X_f) - C_V(\text{Ablate}(X_f, q_i))
  \]
  负值表示移除该单元反而提升验证性能。
- **候选选择与排序**：选 \(u^{\text{cell}}_i < \tau\)（默认 \(\tau=-0.001\)），按单元格效用升序、硬效用次之排序。
- **验证门控收缩**：对每个候选，Shrinker 生成试编辑（试删、降级、整合），要求：
  - 结构有效；
  - 严格降低文本复杂度；
  - 在固定验证集 \(V\) 上满足硬准确率不下降（\(\delta_h=0\)）、单元格准确率下降不超过 0.02（\(\delta_c=0.02\)）；
  - 累积压缩比例不超过软阈值 \(\rho=0.10\)（软上限）。
- 只有通过所有门控的编辑才被提交；每个候选最多处理一次，算法有限终止。

### 2.4 与标准 PGD 的对应关系

| 组件 | 标准 PGD | SkillProx |
|---|---|---|
| 目标 | 复合任务损失 + 复杂度正则 | 两阶段任务优化与文本复杂度控制 |
| 前向方向 | 解析梯度 \(-\nabla f\) | 从轨迹推断的自然语言编辑方向 |
| 前向更新 | \(v_k = x_k - \eta\nabla f(x_k)\) | 诊断、打补丁、同批次重执行、拒绝反馈、回滚 |
| 后向步骤 | 求解近端子问题 | 冻结效用审计、语义收缩、结构检查、验证门控 |
| 收缩强度 | \(\eta\lambda\) | 由 \(\tau, \delta_h, \delta_c, \rho\) 分别控制 |

## 6. 主要结论与发现

- **SkillProx 有效提升技能质量**：在三个骨干 LLM 上，相对 Human Skill 初始技能，IID 准确率分别提升 0.7 pp（4B）、13.0 pp（27B）、17.8 pp（36B）。
- **优于强基线**：平均准确率比最强梯度基线（SkillGrad）高 3.0 个百分点；在 SpreadsheetBench 上，SkillProx 在所有三个骨干模型上均为最佳。
- **OOD 泛化良好**：SkillProx 在 WikiTQ 和 HiTab 上多数情况下取得第一或第二，而 SkillOpt 则严重过拟合域内风格，OOD 性能崩溃。
- **闭环诊断 + 近端收缩互补**：去掉闭环诊断使精度下降 1.5 pp，去掉 Prox 下降 2.5 pp；两者结合可获得最低方差（±0.5）。
- **技能长度与性能不相关**：更长技能并不等于更优；在 27B 上最终技能长度与 IID 精度负相关（r=-0.628，但剔除种子 8 后降为 -0.330）。
- **模型规模效应**：较小模型（4B）生成更多参考内容、需要更多写入调用，闭环门控和 Prox 对其起到了更强的“外部过滤”作用；较大模型（27B）本身更具选择性。
- **机制验证**：种子 8 案例显示，闭环演化拦截了 22 次尝试中的 8 次硬回归，并完全回滚一轮迭代；Prox 将一个错误泛化的任务特定模板整合为通用原则，使 OJ 硬准确率从 46% 提升至 54%。

## 7. 优点

- **概念新颖性**：将连续优化中的近端梯度下降思想移植到离散文本技能空间，提供了“前向验证 + 后向收缩”的统一框架。
- **闭环反馈机制**：突破开环演化范式，使用同批次重执行作为客观判据，让诊断过程根据真实结果演化，而非仅依赖语义合理性。
- **知识单元级可审计性**：留一效用审计使技能内部的知识贡献可解释、可度量，为删除/整合提供了量化依据。
- **验证门控设计**：审计只负责候选筛选，实际编辑仍需在活动技能上重新验证，避免“静态审计误删有用内容”。
- **实验扎实**：多骨干、多基准、多基线、消融、Pareto 分析、案例研究、技能长度分析等，证据链较为完整。
- **控制过拟合与冗余**：通过软压缩阈值和严格复杂度降低条件，明确抑制技能无限膨胀。
