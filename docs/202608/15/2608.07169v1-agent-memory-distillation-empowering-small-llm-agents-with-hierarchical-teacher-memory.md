## 摘要
记忆系统在提升智能体性能方面展现出潜力，但其在小语言模型上的潜力尚未得到充分探索，小语言模型难以自行生成足够多的成功轨迹。我们提出智能体记忆蒸馏（AMD），一种无需训练的框架，通过层次化记忆将结构化知识从大型教师智能体迁移到小型学生智能体。AMD从成功的教师轨迹中构建三种互补的记忆类型：工作流记忆编码任务级策略，子任务记忆提供中等粒度的具体行为示例，函数记忆捕获每个函数的调用约定和常见陷阱。工作流和子任务记忆在每个任务开始时主动注入，而函数记忆则在工具调用错误时被动检索。我们使用四个学生模型（4B-8B参数）和GPT-5-mini作为教师，在三个工具使用基准上评估了AMD，在AppWorld、BFCL V3和ToolSandbox上平均准确率分别提升了27.2个百分点、11.2个百分点和3.4个百分点，同时持续优于现有的基于记忆的基线。进一步分析表明，子任务记忆贡献最大，教师有效性取决于教师能力和学生兼容性，且4B规模的学生从AMD中获益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

## 1. 论文的核心问题与整体含义

- **研究动机**：记忆系统已被证明能显著提升大模型智能体的性能，但在小型语言模型（4B–8B）上潜力远未释放。小模型自身成功率低，难以生成足够多的成功轨迹，导致其记忆库中充斥着失败经验，记忆利用效果有限。
- **关键障碍**：直接迁移教师记忆时，教师与学生之间的“能力鸿沟”会阻碍学生理解与应用高层策略。例如教师建议“先登录再播放音乐”，但学生可能不知道如何完成登录。
- **核心贡献**：提出 **Agent Memory Distillation (AMD)**，一种**无需训练**的框架，通过**层次化记忆**将教师智能体的结构化知识迁移到小型学生智能体，使小模型能够理解并利用教师经验，显著提升工具使用任务中的准确率。

## 2. 方法论

- **核心思想**：从教师成功轨迹中构建三类粒度互补的记忆，分别对应任务规划、子任务执行和函数调用三个层次，以适应小模型有限的理解和指令跟随能力。
- **三类记忆**：
  - **工作流记忆 (Workflow Memory)**：自然语言描述的任务级策略，包括关键工具、前置条件、决策规则、验证提示和常见失败模式；具体值替换为占位符（如 `<ID>`、`<EMAIL>`）。
  - **子任务记忆 (Subtask Memory)**：将轨迹分割成语义连贯的子任务片段（如“登录”、“分页获取请求”），每个片段包含标签、描述和可执行代码/调用示例，为中间粒度提供具体行为参考。
  - **函数记忆 (Function Memory)**：针对单个函数的调用约定、参数 schema、成功示例和常见错误，索引方式为函数名。
- **注入与检索机制**：
  - **主动注入**：任务开始时，工作流记忆基于任务指令检索 top-1 并加入系统提示；子任务记忆由学生先将任务指令分解为最多 6 个子任务标签，每个标签检索 top-1 片段并去重后注入。
  - **反应式注入**：当工具调用报错时，提取失败函数名，在函数记忆中查找对应记录，按当前任务相似度排序后作为提示附加到错误消息中，指导错误恢复。
- **算法流程**（Algorithm 1）：
  1. 检索并注入工作流记忆；
  2. 学生分解子任务，检索并注入子任务记忆；
  3. 循环执行：检测到错误时检索函数记忆；生成工具调用；执行并记录结果；直至任务完成或达到最大步数。
- **训练无关**：无需更新模型参数，只依赖预训练文本嵌入模型进行向量检索。

## 6. 主要结论与发现

- AMD 在三项基准上平均准确率较零样本分别提升 **27.2%p、11.2%p、3.4%p**，并在所有模型 × 基准组合上优于所有基线。
- **子任务记忆贡献最大**：在工作流基础上添加子任务记忆带来最显著的增量（在 AppWorld 上最高 +25.0%p）。
- AMD 使小模型能达到甚至超过教师水平：如 Gemma4-E4B 在 AppWorld 达 54.17%（教师 50.00%），Qwen3-8B 平均精度 40.96% 超过教师 38.39%。
- AMD 同时降低学生交互步数，使轨迹更接近教师效率。
- **4B 规模学生受益最大**：绝对精度随模型增大而提高，但相对增益在 4B 处达到峰值（+34.52%p）。
- 教师效果受“教师准确率”和“师生兼容性”共同影响；强教师不总带来最佳迁移（如 GPT-5-mini 对 Qwen3-4B 优于更强的 DeepSeek V4 Pro）。
- 检索 k=1 时最优，增加记忆数量反而降低小模型性能；高层知识适合自然语言，低层执行知识适合具体代码。

## 7. 优点

- **无需训练**：直接迁移记忆，避免昂贵微调，易于部署到任意小模型。
- **层次化设计**：工作流/子任务/函数三级粒度分别解决规划、执行、纠错需求，有效弥合能力鸿沟。
- **主动 + 反应式注入**：关键知识前置注入，错误时按需检索，兼顾上下文长度与针对性。
- **深入的分析**：包括组件消融、教师/学生规模影响、检索数量、表示格式等，并配有详细案例展示三类记忆的级联作用。
- **鲁棒性验证**：使用跨子集评估和重复运行标准差，排除“记忆来自同一任务”的干扰，增强结论可信度。

## 8. 不足与局限

- **场景覆盖有限**：仅在文本工具调用基准（Python API、结构化函数）上评估，未验证多模态环境、开放式代码生成等更复杂的智能体设置。
- **记忆静态化**：记忆在推理时冻结，无法纳入学生自身的新经验，也难以适应教师演示与实际任务之间的分布偏移。
- **依赖教师兼容性**：教师越强不一定学生提升越大；如何自动选择最合适的教师仍是开放问题。
- **个别模型负效应**：如 LLaMA3.1-8B 在 AppWorld 上加入函数记忆后性能下降（30.36%→27.38%），说明弱指令跟随模型可能被额外上下文干扰。
- **小模型容量限制**：检索更多记忆反而会引入噪声，恢复机制较脆弱，需要仔细调参（k、阈值等）。
