## 摘要
外部自然语言技能为大语言模型（LLM）智能体提供了可复用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将所提供的指导转化为恰当的动作。然而，专门用于提升这种技能利用能力的方法仍未得到充分探索。在实践中，基于技能的智能体通常以任务级奖励为核心的强化学习目标进行训练，这提供的监督有限，且难以捕捉策略在利用所提供技能方面的细微差异。我们提出了BCSD（双向上下文自蒸馏），一个将自蒸馏与强化学习相结合的训练框架，以使LLM智能体更有效地利用外部技能。与依赖单一特权上下文的先前自蒸馏方法不同，BCSD从两个互补的技能上下文视角评估每条轨迹。增强视角引入更高级别的元技能指导，而缩减视角则剪除一般性指导以突出任务特定技能。它们互补的令牌级信号被合并以重新缩放RL优势。在ALFWorld和WebShop上的实验表明，BCSD在多种模型规模下实现了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强与缩减上下文视角的互补贡献。代码将发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

### 一、核心问题与研究动机

- **背景**：外部自然语言技能为 LLM 智能体提供可复用、可编辑的程序性知识，使其能够在长程任务中避免从零开始求解。现有研究主要沿两个方向展开：
  1. **技能生成与进化**（如 SkillEvolver、SkillAudit），侧重提升外部技能本身的质量，但未关注智能体能否可靠使用这些技能；
  2. **技能内化**（如 Skill-SD、SDAR），将技能知识蒸馏进模型参数，虽降低推理端依赖，但牺牲了技能的显式性、可编辑性和可迁移性。
- **核心问题**：如何训练智能体更好地**利用**以外部上下文形式提供的技能，而非将技能内化进参数？这一问题尚未被专门研究。
- **现有训练的不足**：基于技能的智能体通常以任务级奖励作为唯一监督信号，在长程交互中奖励稀疏且粒度粗糙，无法区分哪些决策真正由技能指导所驱动，难以捕捉策略对技能利用的细微差异。
- **单一特权上下文的局限**：近期 on-policy self-distillation（OPSD）方法通过单一特权上下文生成 token 级教师信号，但存在信息泄漏、优化不稳定、以及教师-学生差距可能聚焦于上下文引起的风格性偏移或捷径 token 而非任务相关 token 等问题，单一信号不够可靠。

### 二、方法论——BCSD

#### 核心思想

BCSD（Bidirectional Context Self-Distillation）同时从**增强**与**精简**两个互补的上下文视角获取 token 级信号，将其融合后用于重缩放 GRPO 优势，从而在不逆转轨迹奖励决定的更新方向的前提下，为策略提供更精细的技能利用监督。核心原则是：**训练和推理期间均保留外部技能作为显式上下文**。

#### 问题建模与基础符号

- 任务形式化为部分可观测决策过程，轨迹 τ = (o₁, a₁, …, o_H, a_H)，完成后获得结果奖励 R(τ)。
- 采用层次化 SkillBank 设置，基础上下文为 C₀ = (Q, G, S_c)，其中 Q 为查询，G 为通用技能，S_c 为检索到的任务特定技能。
- 在基础上下文下采样 K 条策略轨迹 {τᵢ}，按 GRPO 计算轨迹级优势：A_GRPOⁱ = (rᵢ − μᵣ)/(σᵣ + ε)。

#### Meta-Skill 提取与刷新

- **定义**：Meta-Skill M_c 是对当前策略在应用技能 S_c 时有效与无效方式的高层文本总结，策略相关，仅在训练时作为特权上下文提供给教师，不进入学生上下文，推理时不使用。
- **初始化**：预收集查询对应的成功与失败轨迹集，使用冻结的外部 LLM 对比两组证据，生成初始 M_c⁽⁰⁾。
- **刷新**：每经过一个验证窗口，用当前窗口新收集的轨迹更新：M_c⁽ᵏ⁺¹⁾ = ExtractLLM(S_c, M_c⁽ᵏ⁾, E₊⁽ᵏ⁾, E₋⁽ᵏ⁾)，然后重置证据缓冲。刷新使元技能与策略的演化保持一致。

#### 双向上下文构建

- **增强视图**：C₁ = (Q, G, S_c, M_c)，在基础上下文上追加 Meta-Skill，提供高层“如何应用技能”的策略相关指导。
- **精简视图**：C₂ = (Q, G_p, S_c)，其中 G_p = PruneLLM(G)，由外部 LLM 在训练前一次性完成，保留通用技能的核心程序性指导，删除冗余内容，突出任务特定技能 S_c 的作用。
- 增强与精简构成两个方向：一个增加信息，一个减少干扰。

#### Gap 加权优势重缩放

- 对每条在 C₀ 下采样的轨迹，保持响应 token 序列不变，用同一策略分别在 C₁ 和 C₂ 下重新评分，得到两个 token 级对数概率差：
  - Δᵃᵘᵍᵢ,ₜ = log π_θ(yᵢ,ₜ | C₁, yᵢ,<ₜ) − log π_θ(yᵢ,ₜ | C₀, yᵢ,<ₜ)
  - Δᵖʳᵘᵢ,ₜ = log π_θ(yᵢ,ₜ | C₂, yᵢ,<ₜ) − log π_θ(yᵢ,ₜ | C₀, yᵢ,<ₜ)
- 加权融合：Δᵢ,ₜ = α·Δᵃᵘᵍᵢ,ₜ + (1−α)·Δᵖʳᵘᵢ,ₜ（实验中 α=0.9）。
- 优势重缩放权重：wᵢ,ₜ = clip(exp(sign(A_GRPOⁱ)·Δᵢ,ₜ), 1−c, 1+c)；最终 token 优势：A_BCSDⁱ,ₜ = A_GRPOⁱ · [(1−λₙ) + λₙ·wᵢ,ₜ]。
- **关键设计点**：
  - 只改变优势的**大小/幅度**，不改变由轨迹奖励决定的更新**方向**；
  - λₙ 随训练步数从 λ₀ 线性衰减至零——早期提供密集的上下文指导，后期逐步回归环境奖励主导；
  - 自蒸馏信号通过优势重缩放融入训练，而非单独的损失项。

#### 策略优化目标

- 采用标准 clipped GRPO 目标，将原轨迹级优势替换为 A_BCSDⁱ,ₜ：
  L_BCSD(θ) = −Eᵢ,ₜ[min(ρᵢ,ₜ(θ)·A_BCSDⁱ,ₜ, clip(ρᵢ,ₜ(θ), 1−ε, 1+ε)·A_BCSDⁱ,ₜ)] + β·L_KL
- 算法整体流程：预训练构建 G_p 和初始化 M_c → 每步采样 K 条轨迹并计算 GRPO 优势 → 在三个上下文中重新评分 → 计算双向 gap 和重缩放优势 → 更新策略 → 定期刷新 Meta-Skill。

### 六、主要结论与发现

- BCSD 在 ALFWorld 和 WebShop 上跨三种模型规模均取得最优或接近最优的聚合性能。例如 Qwen2.5-3B 上 ALFWorld 成功率超出最强基线 5.4 个百分点，WebShop 成功率超出 9.4 个百分点。
- 增强视图（Meta-Skill）和精简视图（Pruned-Skill）提供的 token 级信号**互补而非冗余**——二者符号一致率仅约 50%，融合后对争议 token 采取更保守的折中。
- Meta-Skill 的定期**刷新**至关重要：固定 Meta-Skill 会因策略行为演化而过时，导致 WebShop 成功率显著下降（从 66.4 降至 50.0）。
- λₙ 的**衰减调度**是关键超参数：常数权重使策略长期依赖特权信号，干扰后期奖励驱动的优化。
- **技能利用机制验证**：移除 S_c 后 BCSD 成功率下降幅度大于 Skill_GRPO*，说明 BCSD 确实将“如何使用技能”的经验内化到策略中，而将“任务完成知识”保留在外部技能中——实现了利用能力与知识存储的解耦。

### 七、方法优点

- **问题定位准确**：将“提升外部技能利用率”从“技能生成/进化”和“技能内化”中独立出来，填补了研究空白。
- **双向上下文设计新颖**：不同于单一特权上下文的 OPSD，同时引入“增加高层指导”和“删减冗余信息”两个方向，提供了互补且可相互校验的 token 级信号，降低了单一来源教师信号的不可靠风险。
- **与 RL 的融合方式简洁有效**：通过 gap 加权重缩放优势而非新增损失项，不改变 GRPO 的优化方向，实现了自蒸馏与强化学习的无缝结合。λₙ 衰减设计合理衔接前期密集指导与后期奖励主导。
- **训练/推理一致性**：训练和推理均保留外部技能作为显式上下文，不增加推理成本，技能保持可编辑、可审计、可迁移。
- **对技能利用行为的可解释验证**：通过移除 S_c 的对照实验，直接证明策略依赖于外部技能而非参数记忆，机制验证有说服力。

### 八、不足与局限

- **基准覆盖有限**：仅评估了 ALFWorld 和 WebShop 两个文本交互基准，缺乏更复杂场景（如真实网页、多模态环境、多智能体协作）的验证，外部技能利用能力的泛化性尚不明确。
- **消融实验的模型覆盖面不足**：组件消融、超参数分析等仅在 Qwen2.5-3B 上完成，未在 7B 和 1.7B 模型上验证结论的一致性和稳健性。
- **未披露训练成本**：未报告 GPU 型号、数量、训练耗时等资源信息，影响可复现性和实际部署的参考价值。
- **超参数敏感性问题**：α=0.9（Meta-Skill 主导）与 λ₀=0.1 的组合需要仔细调优；文中显示 (0.5, 0.5) 的权重配置训练不稳定，说明方法对双视图权重的选择有一定敏感性，是否在不同任务上需要重新调节尚不清楚。
