## 摘要
使用可验证奖励的强化学习（RLVR）为训练多轮工具使用智能体提供了验证器有界的性能上限，但其轨迹级别的信用分配将每轮异质结果混入单一奖励信号。在线策略蒸馏提供密集的逐token监督，但要么受教师模型限制，要么容易发生梯度集中崩溃。我们引入了CrEST，一种层次化信用分配框架，它保留RL的验证器有界上限，同时整合来自特权自我教师的密集token级信号。CrEST在两个层级上解析信用：轮次分割的验证优势解决轮间稀释，而熵门控的自我教师调节细化轮内token贡献。在BFCL V3和WildToolBench上的实验表明，CrEST在两种模型规模下始终优于RL和蒸馏基线，在长轨迹和严格会话级指标上提升最大。我们的工作表明，教师模型在策略优化中的角色可以从决定更新方向简化为调节更新幅度，从而在不牺牲验证器有界上限的情况下解锁密集信用分配。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) offers a verifier-bounded performance ceiling for training multi-turn tool-use agents, yet its trajectory-level credit assignment conflates heterogeneous per-turn outcomes into a single reward signal. On-policy distillation provides dense per-token supervision but is either teacher-bounded or prone to gradient concentration collapse. We introduce $\textbf{CrEST}$, a hierarchical credit assignment framework that retains RL's verifier-bounded ceiling while incorporating dense token-level signals from a privileged self-teacher. $\textbf{CrEST}$ resolves credit at two levels: turn-segmented verified advantages address inter-turn dilution, while entropy-gated self-teacher modulation refines intra-turn token contributions. Experiments on BFCL V3 and WildToolBench show that $\textbf{CrEST}$ consistently outperforms both RL and distillation baselines across two model scales, with the largest gains on long-trajectory and strict session-level metrics. Our work demonstrates that the teacher's role in policy optimization can be reduced from determining update directions to modulating update magnitudes, unlocking dense credit assignment without sacrificing the verifier-bounded ceiling.

## 论文详细总结

### 1. 核心问题与整体含义

- **研究背景**：大语言模型正从单纯的问答系统演化为能够进行多轮、多步交互的自主智能体。这类场景中，智能体需要处理包含多个用户请求的会话，每个请求又需要多步工具调用与观察。为训练这类智能体，基于可验证奖励的强化学习（RLVR）已成为主流范式，其性能上限由验证器（verifier）的奖励质量决定。
- **核心问题**：标准 RLVR 采用轨迹级奖励广播，即整个轨迹的所有 token 共享一个奖励信号。在单轮场景中这仅是噪声，但在多轮会话中，不同轮次可能独立成功或失败，却被一个总奖励混淆，导致信用分配不适定——失败的轮次可能被错误强化，成功的轮次也可能被错误抑制。同时，在线策略蒸馏（OPD/OPSD）虽能提供密集的 token 级信号，但存在教师模型上限（teacher-bounded）或梯度集中崩溃（gradient concentration collapse）的问题。
- **研究问题**：能否设计一种训练方法，既保留 RL 的验证器有界性能上限，又能提供 token 级密集信号，解决多轮多步智能体训练中的层次化信用分配挑战？

### 2. 方法论：CREST 框架

- **核心思想**：将每个 token 的优势函数分解为两个层次——轮次级（inter-turn）与 token 级（intra-turn），由验证器决定更新方向，而由特权自教师（privileged self-teacher）只调节更新幅度。其核心口号是“教其量级，而非方向”（Teach the Magnitude, Not the Direction）。
- **统一目标**：采用标准在线策略梯度目标，但每个 token 的优势 \( A_t \) 被结构化分解为：
  \[
  A_t = A^{[t]}_{\text{turn}} \cdot \phi_t
  \]
  其中 \( A^{[t]}_{\text{turn}} \) 是轮次分割的验证奖励优势，负责指明该 token 所在轮次的更新方向；\( \phi_t \) 是幅度调制因子，负责细化轮内 token 的相对重要性。
- **轮次级信用分配**：在一个 GRPO 组内，对每个轮次独立计算组内相对优势：
  \[
  A^{(i)}_k = \frac{R^{(i)}_k - \text{mean}(\{R^{(j)}_k\})}{\text{std}(\{R^{(j)}_k\}) + \epsilon}
  \]
  这样，一个失败的轮次无论同一轨迹中其他轮次是否成功，都会获得负优势。
- **Token 级信用分配**：
  - 使用同一模型但以真实结果为特权上下文构成自教师 \( \pi_T \)，计算教师与学生 log 概率的归一化差异 \( \Delta_t \)。
  - 将 \( \Delta_t \) 与验证器方向相乘并取指数，经 clip 得到 token 权重 \( w_t \)。
  - \( \phi_t = 1 + \lambda^{\text{eff}}_t (w_t - 1) \)，其中 \( \lambda^{\text{eff}}_t \) 由方向门控和熵门控组合而成。
- **稳定化机制**：
  - **方向门**：当教师信号与验证器方向不一致时，完全抑制教师信号，保证最终梯度方向总是由验证器决定。
  - **熵门**：使用 token 的 surprisal（负对数概率）作为不确定性代理，经 Z-score 归一化和 sigmoid 映射后，对低熵格式化 token 降低调制强度，对高熵内容 token 增强调制强度，从而避免梯度集中到少数格式化 token 上。
- **形式化保证**：
  - P1（方向保持）：对所有 token，\( \text{sign}(A_t) = \text{sign}(A^{[t]}_{\text{turn}}) \)。
  - P2（有界扰动）：教师引起的梯度扰动有绝对上界，默认参数下每个 token 优势系数最多被放大 8.4%。
  - P3（符号一致放大）：当方向门开启时，\( \phi_t \ge 1 \)，教师只能沿验证器批准方向放大梯度，不能反向。
- **超参数**：仅有一个可调主超参数 \( \lambda \)（调制强度，默认 0.3），其他（温度、裁剪界、熵门范围）均为固定设计值。

### 3. 实验设计

- **Benchmark 与数据集**：
  - **BFCL V3**（Berkeley Function-Calling Leaderboard V3）：使用 100 个固定多轮 Base 样本训练，400 个不重叠样本评估（Base、Missing Functions、Missing Parameters、Long-Context 各 100 个）。
  - **WildToolBench**：包含 256 个多轮会话，128 个训练、128 个评估，同时评测任务级准确率（Task Accuracy）和会话级准确率（Session Accuracy）。
- **基础模型**：Qwen3-4B-Instruct 与 Qwen3-8B（thinking 模型），均为实际部署常用规模。
- **对比方法**：
  - RL 类：GRPO（轨迹级）、MT-GRPO（智能体步骤级）、EnvTuning（细粒度过程奖励聚合为轨迹级）。
  - 蒸馏类：OPD（需同系列同 tokenizer 的外部教师，4B 用 Qwen3-235B-A22B-Instruct，8B 用 Qwen3-32B）、OPSD（自蒸馏，固定教师 + per-token KL 裁剪稳定）。
- **实验设置**：所有方法共用相同在线采样基础设施、组大小 G=16、学习率计划。CREST 仅调 \( \lambda=0.3 \)，固定 \( \epsilon=0.28, \tau=2.0, \rho=0.5 \)。每个方法使用单一训练种子，评估用三次温度为 \( 10^{-6} \) 的解码衡量解码一致性，而非独立训练重复。

### 6. 主要结论与发现

- CREST 在 BFCL V3 和 WildToolBench 上，以 Qwen3-4B 和 Qwen3-8B 为底座，一致超越所有 RL 与蒸馏基线。BFCL 平均最高提升 +29.88（4B），WildToolBench 会话准确率最高提升 +4.69（4B）。
- 在长轨迹（Long Context）与严格会话级指标（Session Accuracy）上提升最大，说明轮次级信用分割确实解决了信号稀释问题。
- RL 方法整体优于蒸馏方法；OPSD 即使有特权教师仍受限于教师上限，且梯度高度集中（top-5% token 占约 77% 梯度），验证了教师上限与梯度崩溃的存在。
- 方向门保证验证器决定方向，熵门防止梯度集中崩溃，二者缺一不可；去掉任意门控性能均显著下降到接近 GRPO 水平。
- 核心发现：教师并不需要决定更新方向，只需调节更新幅度，就能在保持验证器有界上限的同时获得密集信用分配。

### 7. 优点

- **问题定义清晰**：将多轮多步智能体训练中的信用分配问题形式化为两个层次，并给出梯度几何分析。
- **方法设计优雅**：在标准策略梯度目标中植入结构化优势分解，无需改变训练框架，实现简单。
- **严格的形式保证**：给出方向保持、扰动有界、符号一致放大的数学证明，可信度高。
