## 摘要
基于学习的记忆系统在自进化LLM智能体中面临两个紧密耦合的挑战。首先，轨迹索引效用随交互历史增长，从而将有限的反馈分散到不断扩展的状态空间中。其次，由于轨迹级别的奖励被联合分配给共同检索的记忆，不相关的经验可能收到误导性的效用更新，进而陷入记忆-奖励陷阱。为解决这些挑战，我们引入了降阶记忆强化学习（RoMeRL），该方法通过按结果极性和记忆动态分解的固定维度每任务记忆状态来表示不断增长的轨迹索引效用空间。RoMeRL通过一组固定的语义坐标整合新经验，其内容随时间更新或被替换，从而将反馈集中在有界的效用支撑上。理论上，我们证明了这种降阶参数化增加了每个效用坐标接收的平均反馈，并刻画了在通用坐标转移模型下错误坐标的稳态占用。实证上，在ALFWorld和LifelongAgentBench上，RoMeRL提高了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，并将LLM调用次数减少了21.1%。这些结果表明，降阶效用状态在限制持续奖励污染的同时，支持了高效的自进化智能体记忆。代码可在 https://github.com/YOUNG-fnxm/RoMeRL 获取。

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. Code is available at: https://github.com/YOUNG-fnxm/RoMeRL

# RoMeRL 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：LLM 智能体本质上是无状态的，无法跨交互积累和复用经验。智能体记忆（Agent Memory）通过存储和检索历史经验来弥补这一缺陷，早期方法依赖手工工作流（反思、摘要、规则筛选），近年来的学习型方法则通过下游任务结果来优化记忆的生成、检索与效用，使记忆系统在不更新底层 LLM 参数的情况下“自进化”。
- **核心问题**：现有端到端记忆优化方法通常为每条存储的轨迹分配独立的效用（utility），并基于下游任务奖励进行更新。这种**轨迹索引（trajectory-indexed）**的效用表征存在两个紧密耦合的问题：
  1. **反馈分散/维度膨胀**：随着交互历史增长，可学习的记忆效用状态维度 Nt 不断增加，而反馈预算（任务数 T、每轨迹更新上限 k）有限，导致大多数记忆效用处于“冷启动”状态，反馈密度极低；
  2. **记忆-奖励陷阱（Memory-Reward Trap, MRT）**：轨迹级奖励是联合分配给共同检索到的多条记忆的。当一条弱相关、有噪声或过时的记忆出现在一次成功轨迹中时，共享的轨迹奖励会为其带来正向效用更新，即使它对成功没有因果关系。探索越多、检索覆盖面越广，这种错误归因的风险就越大，形成“探索-污染”两难。
- **核心研究问题**：如何在**不扩大暴露于错误奖励传播的效用支撑**的前提下，提高记忆反馈的覆盖率？
- **关键洞察**：问题根源在于“轨迹索引”的参数化方式本身——每条新经验都会引入一个新的效用变量。与其在持续膨胀的效用空间中更激进地探索，不如**改变强化学习所作用的效用状态**，将其替换为固定维度的低阶状态。

## 2. 方法论：RoMeRL

### 2.1 核心思想

RoMeRL 用**固定维度的按任务记忆状态**替代随轨迹数增长的高维效用空间。该状态由两个二元因素分解：

- **结果极性（Outcome Polarity）**：O = {+, −}，即成功证据与失败证据；
- **记忆动态（Memory Dynamics）**：D = {C, A}，即巩固型（consolidated，保留全局精选证据）与适应型（adaptive，跟踪当前状态或关键转换）。

其笛卡尔积构成一个 **2×2 = 4 的固定语义坐标集合**：

> Ifact = O × D，|Ifact| = 4

每个任务 g 的可变长度历史 Dg,t 通过映射 Φ 投影为固定维度的状态：

> Zg,t = Φ(Dg,t) = [z+,C, z+,A; z−,C, z−,A]

坐标的**语义身份固定不变**，但其**内容可随新经验的到来而更新或被替换**——因此每次更新不会增加持久化的效用变量。

### 2.2 四个语义坐标的具体定义

1. **PCC（Positive Consolidated Coordinate，正向巩固坐标）**：在全局成功轨迹中保留**效率最高**的一条（ℓi 最小）。当发现更高效的成功轨迹时替换当前代表，并继承当前 PCC 效用作为暖启动。
2. **PAC（Positive Adaptive Coordinate，正向适应坐标）**：记录从失败到成功的关键转换——保留首次失败之后**最早出现的一条成功轨迹**（按时间戳），捕捉“首次跨过失败-成功边界”的恢复模式。
3. **NCC（Negative Consolidated Coordinate，负向巩固坐标）**：保留**积累了正向下游效用证据**的失败经验。只有当某条失败轨迹的效用超过负向初始化阈值 Q−init 时才有资格被巩固，且只保留效用最高的那条。
4. **NAC（Negative Adaptive Coordinate，负向适应坐标）**：跟踪当前失败状态，保留**最近的一条失败轨迹**。每条新失败都会替换旧内容，使坐标对近期错误保持敏感，而不会让每条失败轨迹都成为持久效用变量。

### 2.3 检索与效用更新

- **检索**：所有非空坐标构成活跃检索支撑 Ag,t（|Ag,t| ≤ 4），检索分数结合语义相似度与学习效用：
  > score(m) = (1 − ωQ)·cos(e(x), e(m)) + ωQ·Q(m)

  取Top-k条记忆放入上下文。
- **效用更新**：沿用标准 Q 更新规则。若被检索到的坐标 m 在检索集合 St 中，则：
  > Q_{t+1} = Q_t + α·I[m ∈ St]·(rt − Q_t)

- **暖启动**：新代表继承当前坐标的效用值，后续任务结果逐步将其适应当前内容，如此避免冷启动。

### 2.4 理论分析要点

| 定理/命题 | 核心内容 |
|---|---|
| **定理 1（Gap–方差分解）** | 对记忆 mi，估计其边际效用时的误差分解为：观测归因偏差 a²ᵢ 与方差项 σ²ᵢ/nᵢ 之和。**增加检索次数只降低方差项，无法消除任务基线 v⁰ᵢ 和归因偏差 aᵢ**。 |
| **定理 2（充分反馈预算）** | 在全池估计设定下，要保证所有 Nt 条记忆的效用估计误差不超过 ε，所需反馈预算为 F_T = O(Nt/ε²·log(Nt/δ))，轨迹预算为 T = O(Nt/(kε²)·log(Nt/δ))。**反馈需求随记忆数量线性（含对数因子）增长**。 |
| **定理 3（反馈集中）** | 在维度为 d 的效用状态下，每个坐标平均获得 kT/d 条反馈。轨迹索引（维度 Nt）与因子化（维度 4）的反馈密度满足：**n̄_fact = (Nt/4)·n̄_full**，平均效用估计方差从 O(σ²Nt/(kT)) 降为 O(4σ²/(kT))。 |
| **命题 1（错误坐标稳态占用）** | 在通用坐标转移模型下（干净→错误转移概率 ≤ γ，错误→干净转移概率 ≥ λ > 0），稳态错误坐标占比 ≤ γ/(γ+λ)，活跃坐标中错误期望数 ≤ d·γ/(γ+λ)。当 d·γ/(γ+λ) < Nt·ρ_full 时，降阶状态的持久污染暴露低于全池。 |

**核心结论**：降阶状态既能集中有限反馈，又能从结构性上限制持久错误奖励污染的暴露面。

## 6. 主要结论与发现

1. **性能提升**：RoMeRL 在 8 个任务类别上的整体平均成功率达到 **0.862**，优于最强基线 MemRL（0.830），提升 3.2 个百分点。
2. **反馈利用显著改善**：Cold-Q 比率从 MemRL 的 44.9% 降至 **9.0%**（降低 80.0%），反馈密度从 4.96 提升至 **29.93**（约 **6.0 倍**）。
3. **效率大幅提升**：平均记忆规模从 45K 降至 **7K**（减少 84.4%），LLM 调用次数从 570K 降至 **450K**（减少 21.1%）。
4. **MRT 鲁棒性**：在压力测试中，RoMeRL 将正向噪声更新限制在 **2.4** 次、最终噪声比降至 **0.15%**（MemRL+UCB 分别为 7.2 次和 1.20%），同时取得最高成功率 82.0%。
5. **跨模型迁移有效**：冻结的记忆状态迁移到不同 LLM 骨干后均带来分数提升和步骤数下降——说明低阶语义坐标承载了可迁移的程序性知识。
6. **Q 值更具信息量**：RoMeRL 的 Q 值与记忆来源的点二列相关从基线的 r=0.493 提升至 **r=0.673**；仅 5.0% 的记忆停留在初始 Q=0.5（基线为 47.8%）。其高 Q 值区间保留约 19.9% 的失败衍生记忆，说明 Q 值不只是二元成功/失败标签的代理，能捕捉更丰富的可复用信息。
7. **坐标角色互补**：NCC 的移除同时降低 SR 与 CSR（巩固型负向证据对稳态表现和累计覆盖率都重要）；PAC 的移除主要降低最终 SR（适应型正向转换信号对复现解决方案有价值）。

## 7. 优点

- **问题刻画精准**：通过定义观测效用 vs 边际效用、引入 MRT 的形式化定义，清晰区分了“统计不确定性”与“归因偏差”两类不同的错误来源，并证明了额外反馈无法消除后者——这为方法设计提供了坚实的理论动机。
- **理论-实验闭环**：四个定理/命题从反馈预算下界、方差集中、稳态错误占用三个角度论证了降阶状态的优势，实验数据（6 倍反馈密度、80% Cold-Q 下降）与理论预测一致。
- **结构优雅、有解释力**：2×2 因子化是“结果极性 × 记忆动态”的最小完备分解；每个坐标有明确的语义角色，案例研究展示了四个坐标如何在实际任务中发挥不同功能（稳定复现、失败警告、诊断复用、恢复模式）。
- **效率与性能兼得**：在较少记忆和较少 LLM 调用的情况下获得更好任务性能，证明降阶并非简单丢弃信息，而是更精准地保留高价值经验。
- **务实且可复现**：不更新 LLM 参数，采用在线 Q 更新机制，附录提供了完整的提示词模板、超参数设置和数据划分细节。

## 8. 不足与局限

- **因果归因仍未完全解决**：论文承认 RoMeRL 仍然基于结果级奖励（outcome-level rewards），被检索的多个坐标之间共享同一轨迹奖励，因此**没有彻底解决因果信用分配问题**；MRT 只是被结构性抑制而非消除。
- **理论假设较强**：定理依赖条件独立采样、平稳原始收益目标等假设；命题 1 中的转移概率 γ、λ 在实际中需要成对反事实 rollout 或等价归因才能估计，**难以直接验证**。
- **实验范围有限**：仅覆盖 ALFWorld 和 LAB 的 OS、DB 任务；未涉及开放域长时程任务（如网页操作、多智能体协作），也未验证更长交互周期（>10 epochs）下的表现。
- **未披露统计显著性**：没有报告多次运行的标准差或显著性检验，单次 10-epoch 结果的可靠性存疑。
- **基线公平性存疑**：MemRL 的超参数是否经过同等程度的调优未做说明；MemRL+UCB 的探索系数可能未达最优。
- **跨模型迁移实验规模较小**：仅测试了 2 个目标模型 × 2 个任务，且未分析迁移失败或负迁移的潜在情况。
- **资源消耗报告缺失**：未报告 GPU/API 的实际成本与时间开销，只报告了相对调用次数，外部复现时难以精确比较能耗。
