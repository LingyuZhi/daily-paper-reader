## 摘要
强化学习（RL）后训练提升了大语言模型的推理能力，但自回归展开生成仍然是主要的效率瓶颈。推测解码可以加速生成，但在RL期间应用它却很困难，因为目标策略持续演化：静态提议者会过时，而频繁更新起草者则增加大量开销。我们提出了SpecRoll，一种推测性展开引擎，它在适应两个时间尺度的同时，保持目标模型的采样分布。轻量级的未来token头生成并行提议，而我们提出的Reflex模块则利用延迟的验证器反馈，在不进行反向传播的情况下，执行有界的、轨迹局部的隐藏状态修正。一个互补的慢路径仅在检测到持续退化时才更新头部参数。SpecRoll将这些机制与并发感知的稀疏树验证和精确的目标验证相结合，保持目标展开分布和GRPO目标不变。在从1.5B到14B的五个模型和三个数学推理数据集上，SpecRoll相比于vanilla GRPO实现了1.26-2.15倍的生成加速和1.21-2.04倍的端到端加速。在所有15个匹配设置中，它在生成时间和端到端时间上也优于FastGRPO，平均成对端到端增益为1.18倍。受控消融实验表明，快慢适应路径提供了互补的优势。我们的源代码可在 https://anonymous.4open.science/r/SpecRoll-26062006 获取。

## Abstract
Reinforcement learning (RL) post-training improves the reasoning capabilities of large language models, but autoregressive rollout generation remains a major efficiency bottleneck. Speculative decoding can accelerate generation, yet applying it during RL is difficult because the target policy continually evolves: static proposers become stale, while frequent drafter updates add substantial overhead. We introduce SpecRoll, a speculative rollout engine that preserves the target model's sampling distribution while adapting at two timescales. Lightweight future-token heads generate parallel proposals, while our proposed Reflex module uses delayed verifier feedback to perform bounded, trajectory-local hidden-state corrections without backpropagation. A complementary slow path updates the head parameters only when sustained degradation is detected. SpecRoll combines these mechanisms with concurrency-aware sparse-tree verification and exact target verification, leaving the target rollout distribution and GRPO objective unchanged. Across five models ranging from 1.5B to 14B and three mathematical reasoning datasets, SpecRoll achieves 1.26-2.15x generation speedup and 1.21-2.04x end-to-end speedup over vanilla GRPO. It also outperforms FastGRPO in both generation and end-to-end time across all 15 matched settings, with an average pairwise end-to-end gain of 1.18x. Controlled ablations show that the fast and slow adaptation paths provide complementary benefits. Our source code is available at https://anonymous.4open.science/r/SpecRoll-26062006.

## 论文核心问题与整体含义

**研究动机：**
- 强化学习（RL）后训练（尤其是带可验证奖励的 GRPO）能显著提升大语言模型的数学推理能力，但自回归 rollout 生成是主要效率瓶颈。
- 推测解码（Speculative Decoding）可加速生成，但在 RL 场景中难以直接应用，原因有二：
  1. **策略持续演化**：目标策略不断更新，静态 proposer 会迅速过时；
  2. **树验证效率问题**：rollout 并发度随响应完成而下降，固定验证树在不同阶段效率不匹配。
- 现有方案 FastGRPO 通过在线训练独立 EAGLE 式 drafter 解决上述问题，但其需要额外的反向计算、优化器状态和同步开销，且无法区分**瞬时局部失配**与**持续策略漂移**。

**论文核心思想：**
- 观察到延迟的验证器错误在轨迹内相邻位置仍具有预测性，由此设计了一个双时间尺度适应机制：
  - **快路径（Reflex）**：无反向传播的轨迹局部隐藏状态校正，处理瞬时失配；
  - **慢路径**：仅在检测到持续退化时更新 proposal 头部参数，处理跨轨迹的持久漂移。
- 整个框架在保持目标采样分布和 GRPO 目标不变的前提下，实现插拔式 rollout 加速。

## 方法论

### 3.1 问题形式化

SpecRoll 将推测引擎优化目标定义为：在目标分布约束下，最大化接受进度与计算成本之比：

```
max E[At] / Cost(E)  subject to X ~ πθs
```

其中 At 为验证轮次 t 的接受进度，πθs 为当前策略。

### 3.2 并发感知的精确 Rollout 引擎

- **轻量未来词头**：基于 MEDUSA 风格，3 个 horizon 头部从目标隐藏状态预测 t+2、t+3、t+4 位置的 token：
  ```
  zt,h = gφh(ht) + ht,  qt,h = softmax(W zt,h)
  ```
  复用目标词表投影 W，无需独立自回归 drafter 和 KV cache。
- **并发感知稀疏树**：每个响应分配动态节点预算：
  ```
  Nt = clip(⌊Cpeak / Bt⌋, Nmin, Nmax)
  ```
  其中 Bt 为未完成响应数，Cpeak 为硬件验证能力。树预算随并发度下降而增大，充分利用硬件。
- **精确目标验证**：采用节点级拒绝采样与 target-residual fallback，保证采样分布与普通自回归采样逐 token 等价（附录 B 定理 B.1 严格证明）。

### 3.3 验证器引导的提议误差分析

将提议-目标失配分解为两个互补的误差来源：

- **分布误差（ddist）**：p(C)·TV(pC, qC)，衡量保留候选集合内概率质量分配不当；
- **覆盖误差（dcov）**：p(C*K) - p(C)，衡量目标重要 token 被遗漏。

两者之和精确等于 budget 匹配的目标上限与保守接受代理之间的差距（公式 11）。

### 3.4 Reflex：轨迹局部即时校正

- **验证反馈方向**：
  - 分布反馈：`rdist = W⊤S(pS - qS)`，将保留 token 的 logits 推向目标；
  - 覆盖反馈：`rcov = Σy∈O pS(y)(Wy - Wb*)`，将遗漏 token 相对选择边界提升。
- **轨迹局部记忆**：指数移动平均更新每个轨迹-水平对，一致误差相互强化，不一致方向相互抵消。
- **可靠性门控**：基于延迟对齐统计（余弦相似度的均值与标准差），计算保守可靠性分数 `dRel = ā - zδ·s/√n`，仅当置信下界为正时才激活校正。
- **有界隐藏状态修正**：
  ```
  Δzi,t,h = 1[dRel > 0] · αi,t,h · RMS(zi,t,h) · ui,h
  ```
  校正幅度与当前状态量级成比例且受限，无额外目标前向/反向传播。

### 3.5 漂移触发的持久参数合并

- 每个 horizon 头部维护有界 reservoir 的成熟验证记录；
- 仅在连续三个监控窗口检测到持久退化（TV 超过基线 + 接受率下降或候选遗憾上升）时才触发辅助更新；
- 辅助损失包含稀疏支持上的 KL 蒸馏、真实 token 负对数似然和邻近项约束；
- 更新开销被限制在 rollout 时间的 1.8% 以内。

## 优点

1. **创新的双时间尺度设计**：将验证器反馈拆分为无梯度的轨迹局部记忆与选择性触发的持久学习器，精确定位瞬时失配与持久漂移的不同处理需求；
2. **严格的理论支撑**：从逐点代理梯度表示、延迟记忆跟踪误差界到接受概率转移定理，构建了完整的理论分析框架；
3. **保持分布完整性**：精确目标验证保证采样分布与 GRPO 目标完全不变，是安全的插拔式加速；
4. **轻量高效**：无需独立自回归 drafter 和 KV cache，仅 3 个未来词头 + 冻结词表投影；辅助更新开销被严格限制在 1.8% 以内；

## 不足与局限

### 实验覆盖
- 模型规模仅到 14B，未验证更大模型（如 70B+）上的表现；
- 仅覆盖数学推理三个数据集，未涉及代码生成、多语言推理等更广泛任务；
- 所有实验使用单一硬件（NVIDIA B200）和单卡设置，跨平台可迁移性未知；
- 训练仅一个 epoch，未验证长时间训练下的稳定性。

### 潜在偏差风险
- 同一 ShareGPT 预训练数据的提议器初始化可能对结果有未量化影响；

### 应用限制
- 并发感知树预算依赖硬件 profiling（Cpeak 校准），不同部署环境需重新调参；
- Reflex 可靠性门控依赖延迟反馈的预测性假设，在响应过短或轨迹快速切换时可能收益有限；
- 方法核心针对 GRPO（无价值模型），对其他 RL 后训练范式（如 PPO）的适用性未验证。
