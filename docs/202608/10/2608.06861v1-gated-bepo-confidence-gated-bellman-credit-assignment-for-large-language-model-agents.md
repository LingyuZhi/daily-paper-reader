## 摘要
在长时程环境中训练大语言模型智能体需要将稀疏的最终结果归因到各个动作上。现有的无评论家方法将轨迹级奖励均匀地传播到各步骤，而近期的方法通过匹配重复状态构建步骤级分组，并在每组内比较动作。前者无法区分失败轨迹中的有用动作与成功轨迹中的无效动作。后者依赖于直接从单个轨迹结果中得出的步骤信用，并与回合级信用进行固定权重融合。我们提出Gated-BEPO，它从经验推演图中推导步骤级信用。对于每个推演组，Gated-BEPO构建一个经验图，并通过均值备份贝尔曼不动点来估计节点值，该不动点反映了当前策略的经验动作分布。然后，我们使用广义优势估计沿每条采样轨迹累积这些时间差分残差，得到步骤级贝尔曼优势，从而捕获即时和下游效应。为了自适应融合回合级和步骤级信用，置信度门控仅在具有多个观测后继的状态下引入贝尔曼信用，否则使用回合级信用。在WebShop、ALFWorld和视觉推箱子上的实验表明，在语言和视觉语言模型上均获得了一致的改进，而诊断性消融实验支持了贝尔曼不动点价值估计的有效性，并表明步骤级信用应被选择性地而非均匀地纳入最终优势。

## Abstract
Training large language model agents in long-horizon environments requires assigning credit from sparse terminal outcomes to individual actions. Existing critic-free methods propagate trajectory-level rewards uniformly across steps, while recent approaches construct step-level groups by matching repeated states and compare actions within each group. The former cannot distinguish useful actions in failed trajectories from ineffective actions in successful ones. The latter rely on step credit derived directly from individual trajectory outcomes and fixed-weight fusion with episode-level credit. We propose Gated-BEPO, which derives step-level credit from empirical rollout graphs. For each rollout group, Gated-BEPO constructs an empirical graph and estimates node values through a mean-backup Bellman fixed point that reflects the empirical action distribution of the current policy. We then accumulate these temporal-difference residuals along each sampled trajectory using generalized advantage estimation, yielding step-level Bellman advantages that capture both immediate and downstream effects. To adaptively fuse episode- and step-level credit, a confidence gate incorporates Bellman credit only at states with multiple observed successors and otherwise uses episode-level credit. Experiments on WebShop, ALFWorld, and visual Sokoban show consistent improvements across language and vision-language models, while diagnostic ablations support the effectiveness of Bellman fixed-point value estimation and show that step-level credit should be incorporated selectively rather than uniformly into the final advantage.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）越来越多地被用作交互式智能体，在网页导航、具身环境操作和多步规划等长时程任务中执行动作。这类任务中，智能体往往要经过许多步交互才能观察到稀疏的最终任务结果，因此**信用分配**（credit assignment）成为训练的核心问题——早期动作是否有效，可能只在很久之后才显现。
- **核心问题**：在无评论家（critic-free）的强化学习框架下，如何从**稀疏的终端奖励**中为每个单步动作分配合理的信用？
- **现有方法的不足**：
  - 传统 critic-free 方法（如 GRPO）将整条轨迹的回报**均匀分配到每一步**，无法区分"失败轨迹中的有效动作"与"成功轨迹中的无效动作"，导致学习慢且最终性能受限。
  - 近年来的步骤级方法（GiGPO、HGPO、GAGPO、GraphGPO）虽然通过匹配重复状态构建步骤级分组，但存在以下问题：
    - 步骤信用直接从单条轨迹结果派生，未显式建模共享的下游转移结构；
    - 固定权重融合回合级信用与步骤级信用，缺乏依据局部证据的适应性；
    - GraphGPO 的图最短路径距离评分在**感知混叠**（perceptual aliasing，相同观测对应不同隐状态）下很脆弱。
- **整体含义**：本文提出一种无需 critic、无需人工步骤标注的步骤级信用分配方法，通过经验 rollout 图上的 Bellman 不动点估计与置信度门控的混合机制，在保留回合级全局信号的同时，选择性地引入可靠的步骤级信号，从而提升 LLM 智能体在长时程任务中的学习效率与最终性能。

## 2. 方法论：核心思想与技术细节

### 2.1 核心思想

对每个任务实例的 rollout 组（K=8 条轨迹）：
1. 将相同观测合并为共享状态，构建**经验状态转移图**（保留转移次数，即多重边）；
2. 用 **mean-backup Bellman 不动点**估计每个图节点的状态值，反映当前策略的经验动作分布下的期望回报；
3. 计算**时间差分残差**，并用 GAE 沿原始轨迹累积得到步骤级 Bellman 优势；
4. 通过**置信度门控**只在"有多个观测后继"的状态激活步骤级信用，否则仅使用回合级 group-relative 优势。

### 2.2 关键技术细节

**（1）经验图与 Bellman 不动点值估计**

- 对每个 rollout 组，将观测映射为状态，终点映射为成功/失败/截断的零值吸收状态。
- 定义状态 s 的出边多重集：
  \[
  E(s) = \{(r_i, s'_i) : s_i = s\}
  \]
- 均值 Bellman 备份：
  \[
  V^{(k+1)}(s) = \frac{1}{|E(s)|} \sum_{(r, s') \in E(s)} \left[ r + \gamma V^{(k)}(s') \right]
  \]
  当 γ < 1 时该算子在有限经验图上是收缩映射，存在唯一不动点。初始化使用 Monte-Carlo 回报，迭代至收敛或达到预算（默认 20 次，容差 1e-6）。

**（2）固定点 TD 残差与 GAE 传播**

- 每条记录 i 的 TD 残差：
  \[
  \delta_i = r_i + \gamma V(s'_i) - V(s_i)
  \]
- 在不动点处，同一状态所有残差之和为零，因此残差度量了**该边相对该状态经验平均的好坏**，是一种无需 critic 的状态中心局部优势信号。
- 沿轨迹用 GAE 累积：
  \[
  \hat{A}^{\text{FP}}_i = \delta_i + \gamma \lambda \hat{A}^{\text{FP}}_{\text{next}(i)}
  \]
  （默认 λ = 0.8；门控在 GAE 之后应用，使下游未支持状态的残差仍能向上游传播，保留延迟信用。）

**（3）置信度门控**

- 定义状态访问次数 n(s) 和不同后继数量 |Succ(s)|：
  \[
  \rho(s) = \begin{cases}
  1, & n(s) \ge n_{\min} \text{ 且 } |\text{Succ}(s)| \ge b_{\min} \\
  0, & \text{否则}
  \end{cases}
  \]
  默认 \( n_{\min} = b_{\min} = 2 \)，即要求至少两个不同后继——既隐含重复访问，又保证存在可比较的局部备选动作。

**（4）自适应信用混合**

- 混合优势：
  \[
  \hat{A}_i = \eta_i \hat{A}^{\text{out}}_i + w \rho(s_i) \hat{A}^{\text{FP}}_i
  \]
- 回合级优势 \(\hat{A}^{\text{out}}_i\) 为轨迹回报在 rollout 组内的 record 级 z-score 标准化；
- 门控关闭时，η = 1，完全依赖回合级优势；门控打开时，η = η_min（默认 0.5），保留一半回合级信用作为稳定全局信号，并激活步骤级信用；
- 步骤级优势在门控前先做组内标准化，默认权重 w = 1.5。

**（5）优化**

- 使用 PPO clipped 目标（ε = 0.2），将最终记录优势广播给对应响应中的所有有效 token。Gated-BEPO 只修改优势估计器，不改变其他训练框架。
