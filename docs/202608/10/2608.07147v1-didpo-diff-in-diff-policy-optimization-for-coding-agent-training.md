## 摘要
基于可验证奖励的强化学习（RLVR）已成为训练编码智能体的强大范式，其中编译和测试的执行反馈提供了客观验证。然而，与智能体任务不同，编码智能体面临一个独特且更细粒度的信用分配挑战：在每一步中，编码动作同时将不同的更改打包到代码版本的不同区域，这使得独立更改的贡献难以区分。现有的RLVR方法大多利用结果奖励或步骤级奖励，这未能深入代码差异，使得编码动作的独特属性在训练中不可见。在本文中，我们提出了差分中差分策略优化（DiDPO），一种无评论家的RL方法，直接从代码差异的结构中构建细粒度信用单元。DiDPO将多轮编码交互组织为多个“思考-动作”步骤，并在采样的轨迹中发现代码差异。然后，它通过聚合由我们的“可分组性分数”从每个完整差异中分离出的高度相似的子差异来选择锚点，该分数提供了在锚点的语义范围与其可能形成的组群规模之间实现最优平衡的切分方案。最后，这些锚点形成优势组，并将差异级优势投影回单个响应令牌。在长周期编码和推理基准上的实验表明，DiDPO显著优于强智能体强化学习基线。在Qwen2.5-7B-Coder上，DiDPO超越可比方法超过10%，并缩小了与更大模型的差距，为编码智能体训练中的细粒度信用分配提供了一个原则性框架。我们还在开源了verl-code，一个支持多种RL方法和编码基准的智能体RL代码库。

## Abstract
Reinforcement learning with Verifiable Reward (RLVR) has emerged as a powerful paradigm for training coding agents, where the execution feedback from compilation and tests provides objective verification. However, unlike agent tasks, coding agents face a unique and finer-grained credit assignment challenge: at each step, coding actions simultaneously pack varying changes into different regions of a code version, which makes the contribution of independent change indistinguishable. Existing RLVR methods mostly leverage the outcome reward or step-level reward, which fails to dive into a code diff and makes unique properties of coding actions invisible to training. In this paper, we propose Diff-in-Diff Policy Optimization (DiDPO), a critic-free RL method that constructs fine-grained credit units directly from the structure of code diffs. DiDPO organizes multi-turn coding interactions into multiple thought--action steps and discovers code diffs across sampled trajectories. It then selects anchors by aggregating highly similar sub-diffs split from each whole diff by our ``groupability score'', which provides the splitting schema that optimally balances the semantic scope of anchors and the group mass they may form. Finally these anchors form advantage groups and project the diff-level advantage back to individual response tokens. Experiments on long-horizon coding and reasoning benchmarks show that DiDPO significantly outperforms strong agentic RL baselines. On Qwen2.5-7B-Coder, DiDPO exceeds comparable methods by over 10\% and narrows the gap with far larger models, offering a principled framework for fine-grained credit assignment in coding agent training. We also open-source verl-code, an agentic rl codebase that supports various RL methods and coding benchmarks.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：可验证奖励强化学习（RLVR）已成为训练编码智能体的重要范式。编译、测试等执行反馈提供了客观的验证信号，使策略优化不依赖人工标注或奖励模型。
- **核心挑战**：编码智能体在每一步动作中，往往同时修改代码版本中**多个不同区域**，产生包含多个功能子差异（sub-diff）的完整代码差异（diff）。传统 RLVR 方法仅使用结果级奖励或步骤级奖励，**无法区分单个动作内部不同修改的独立贡献**，导致信用分配（credit assignment）粗糙。
- **三个关键观察**：
  1. 编码动作与代码片段捆绑，任务难度越高、工程规模越大，编辑越长且区域交错；
  2. 一个 diff 可能包含多个功能不同的子 diff，将其整体视为一个决策单元会掩盖真正的改进来源；
  3. 代码受严格语法和执行结果约束，细小错误可能影响长轨迹，因此需要特别细粒度的信用信号。
- **研究问题**：如何为代码 diff 构建动态、更细粒度的信用单元，从而更有效地将智能体 RL 应用于编码任务？

## 2. 方法论：DiDPO 核心思想与关键技术

### 2.1 总体思路
- DiDPO 是一个**无评论家（critic-free）** 的强化学习方法，直接从代码 diff 的结构中构造细粒度信用单元。
- 保留轨迹级组相对优势（group-relative advantage），同时“向内看”，分析每个代码生成动作内部的子结构。
- 通过跨 rollouts 匹配高度相似的子 diff，将其作为“锚点”（anchors），形成优势组，并将 diff 级优势投影到具体 token 上。

### 2.2 主要流程与公式

#### (1) 轨迹级优势（Trajectory-level Advantage）
- 对同一任务提示采样的 N 条轨迹，计算归一化组相对优势：
  \[
  A_E(\tau^{(i)}) = \frac{R^{(i)} - \frac{1}{N}\sum_j R^{(j)}}{\text{std}(\{R^{(j)}\})}
  \]
- 该信号监督整个编码过程的整体成功程度。

#### (2) Diff 可分割性
- 收集所有轨迹、所有步骤的 diff，组成集合 \( \mathcal{S} \)。
- 为每个 diff 附加元数据：规范化文本、响应 token 跨度、动作类型（add/del/none）、所属任务实例。
- 以整 diff 为单位进行分组时，部分重叠的 diff 无法有效匹配，导致组群小且噪声大；因此需要进一步分解为子 diff。

#### (3) 动态子 diff 锚点选择
- 枚举每个 diff 的连续子 diff 候选集 \( \mathcal{I}(s) \)。
- 对跨 rollouts 的子 diff 计算相似度矩阵，仅匹配相同编辑类型且相似度 ≥ 阈值 η 的子 diff。
- 将匹配的子 diff 聚合成锚点 \( c \)，定义**可分组性分数（Groupability Score, GS）**：
  \[
  GS(c) = \left(1 - e^{-\bar{L}(c)}\right)\left(1 - e^{-(n(c)-1)}\right)
  \]
  其中 \( \bar{L}(c) \) 为锚点平均语义规模，\( n(c) \) 为组内出现次数。该分数在“锚点足够大以承载功能意义”和“组群足够大以保证统计可靠性”之间权衡。
- 由于多个高分锚点可能共享相同子 diff，需要选择一组最优锚点，最大化覆盖的 GS 总和：
  \[
  C^\star = \arg\max_{|C|\le K} \sum_{s\in \mathcal{I}(\mathcal{S})} \max_{c\in C} \mathbf{1}[s \in O(c)] GS(c)
  \]
- 该问题是基数约束的次模最大化，使用贪心算法求解（可保证 \(1-1/e\) 近似，见 Nemhauser 定理）。

#### (4) Diff 级优势计算
- 锚点决定了 diff 的切分和分组。同一锚点覆盖的子 diff 构成优势组 \( G(C^\star) \)。
- 组内计算局部组相对优势：
  \[
  A_D(a_{t,m}^{(i)}) = \frac{R_t^{(i)} - \text{avg}(\{R_t^{(j)} | (a_{t,m}^{(j)}, R_t^{(j)}) \in G\})}{\text{Fnorm}(\{R_t^{(j)} | \ldots\})}
  \]

#### (5) 最终策略优化目标
- 将轨迹级优势与 diff 级优势加权合并，投影到 token 级：
  \[
  \hat{A}_{i,l} = A_E(\tau^{(i)}) + \lambda \cdot A_D(a_l^{(i)})
  \]
- 使用标准 PPO 裁剪目标：
  \[
  J = \mathbb{E}_{x,i,l} \left[ \min\left(\rho_{i,l}\hat{A}_{i,l}, \text{clip}(\rho_{i,l}, 1-\epsilon, 1+\epsilon)\hat{A}_{i,l}\right)\right]
  \]

### 2.3 理论基础
- **定理 1**：当组内子 diff 与锚点的对应误差 ≤ ε 时，锚点匹配相对于精确匹配造成的局部信用偏差为 \( O(L\epsilon) \)，其中 L 为局部奖励函数的 Lipschitz 常数。
- **定理 2**：若步骤回报分解为 \( R^{(i)} = r(s_i) + \xi_i \)，其中非因果噪声方差为 \( \sigma_\xi^2 \)，则 DiDPO 局部优势估计器的均方误差满足：
  \[
  MSE(\hat{A}_D^i) \le O(L^2\epsilon^2) + O(\sigma_\xi^2/m)
  \]
  而整轨迹广播估计器保留了 \( O(\sigma_\xi^2) \) 的噪声污染。因此，锚点质量控制偏差，跨 rollouts 支持控制方差。

## 6. 主要结论与发现

- DiDPO 在 Qwen2.5-Coder-7B 上平均得分 48.4%（APPS 等 8 个基准平均），比最强基线 GiGPO 高 4.2 分，比 GRPO 高 5.6 分；在 Qwen3.5-4B 上平均 58.6%，比 GiGPO 高 4.9 分。

- 理论分析证明锚点质量与组规模分别控制局部信用的偏差和方差，为方法提供了统计保证。

## 7. 优点

- **细粒度信用分配**：首次从代码 diff 的内部结构构建信用单元，解决了编码智能体动作中多子修改难以归因的问题。
- **无需额外评论家或额外 rollout**：所有锚点和组从原始采样轨迹中获得，训练开销仅增加约 2.3%。
- **动态且可解释**：锚点随训练演化，自动从碎片化匹配过渡到功能块匹配；可分组性分数提供了清晰的语义权衡。
- **理论支撑**：给出偏差-方差分解定理，说明锚点对齐精度和组规模对局部信用质量的影响，提升了方法的可信度。
- **工程贡献**：开源 verl-code 代码库，支持多种 RL 方法和编码基准，便于复现与扩展。
- **实验设计严谨**：多重消融、敏感性分析、时间开销分析以及训练动态可视化，全面验证了各设计决策的必要性。

## 8. 不足与局限

- **基准覆盖局限**：主要面向竞争编程和算法题，未在真实仓库级任务（如 SWE-bench）上验证；长周期真实软件工程中 diff 的复杂度和功能耦合可能更高，DiDPO 的有效性需要进一步证明。
- **对相似度匹配的依赖**：子 diff 匹配依赖词法/嵌入相似度阈值 η，对语义等价但表述差异大的修改可能失效；尽管理论分析允许一定误差，但实践中高噪声场景下性能可能下降。
- **超参数敏感**：λ、η、GS 中的尺度参数等需要调优，论文虽给出灵敏度分析，但最优 λ=1.2 可能随任务分布变化而迁移性有限。
