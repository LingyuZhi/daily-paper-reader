## 摘要
多轮智能体强化学习中的信用分配在两个层面运作：将轨迹级别的信用分配给动作，并将每个动作的信用分配到其令牌上。在本文中，我们引入了FACTOR，它将这两个决策分开。FACTOR使用检查点校准的TD残差来分配每个动作的信用，这些信用可伸缩为轨迹优势，并使用反馈条件下的师生似然差距将每个信用分配到已实现的动作令牌上。逐动作归一化保留了动作平均系数，并防止了令牌级别的符号翻转。我们将这种构造与动作均值缩减相结合，消除了动作的标量替代权重对其令牌长度的隐含依赖。在行为策略下且在进行裁剪之前，每个动作的内部动作均值替代值等于其TD信用。FACTOR在ALFWorld、WebShop和ScienceWorld上持续优于竞争基线，每个环境-种子的比较都倾向于FACTOR，最大的提升出现在最长视野环境中。相同的超参数无需重新调整即可迁移到更大的骨干网络和不同的模型家族。消融研究确定TD动作信用是改进的主要驱动因素，而事后令牌分配贡献了互补的增益。

## Abstract
Credit assignment in multi-turn agent reinforcement learning operates at two levels: assigning trajectory-level credit to actions and distributing each action's credit across its tokens. In this paper, we introduce FACTOR, which separates these decisions. FACTOR uses checkpoint-calibrated TD residuals to assign per-action credits that telescope to the trajectory advantage, and feedback-conditioned teacher-student likelihood gaps to allocate each credit across the realized action tokens. Per-action normalization preserves the action-average coefficient and prevents token-level sign flips. We pair this construction with an action-mean reduction, removing the implicit dependence of an action's scalar surrogate weight on its token length. At the behavior policy and before clipping, each action's inner action-mean surrogate equals its TD credit. FACTOR consistently improves over competitive baselines across ALFWorld, WebShop, and ScienceWorld, with every environment-seed comparison favoring FACTOR and the largest gains emerging on the longest-horizon environment. The same hyperparameters transfer without retuning to a larger backbone and to a different model family. Ablations identify TD action credit as the dominant driver of the improvement, with hindsight token allocation contributing complementary gains.

## 1. 核心问题与整体含义

### 研究动机
- 大语言模型（LLM）智能体通过执行**一系列可执行动作**来解决长视野交互任务（如具身指令跟随、网页导航）。
- 强化学习（RL）是训练此类智能体的主流范式，但监督信号通常是**单一稀疏的终端结果**，而策略优化却必须更新**每一个输出 token**——这种粒度不匹配迫使多轮更新必须回答两个不同的问题：
  1. **时间信用分配**（Temporal Credit Assignment）：每条被执行的**动作**应获得多少情节级信号？
  2. **动作内分配**（Intra-Action Allocation）：一个动作的信用应如何分配到实现它的**各个 token** 上？
- 标准轨迹级目标（如 GRPO）将单个轨迹优势广播到每个回合和每个 token，同时回避了这两个问题。

### 现有方法的缺陷
- 现有工作大多**孤立**地研究这两个问题，留下了一个未解决的**耦合**：
  - **时间信用方法**（如 Feng 2025; Tan 2026; Tao 2026; He 2026a）精确化了每个动作应获得多少信用，但止步于生成动作级标量。
  - **token 调制方法**（如 Hübotter 2026; Yang 2026; Li 2026b; Fang 2026a）精化了信用落在哪里，但将传入的动作级信用视为固定值。
- 论文以 **SERL** 为具体例子说明了耦合问题：其教师乘数未约束为在动作内平均为 1，导致**动作平均系数随教师置信度漂移**；再加上全局 token 均值归约下动作的替代贡献随 token 数量缩放，产生了**长度耦合**——两个信用相同的动作可能仅仅因为响应长度不同而以非常不同的量级进入训练。

### 核心含义
- 论文主张将动作信用与 token 分配视为两个分离的对象，通过**显式的守恒接口**连接——先确定一个动作应获得多少信用（与 token 数量、教师置信度无关），再决定如何将该固定预算分配到 token 上，且后者**永不修改前者**。

## 2. 方法论

### 2.1 总体框架
FACTOR 将 token 系数分解为 **C_t,j = A⋆_t · ω_t,j**：
- **TAC**（TD Action Credit，TD 动作信用）确定动作信用 A⋆_t；
- **HTA**（Hindsight Token Allocation，事后 token 分配）为 token 的相对责任打分；
- **APM**（Per-Action Mean Preservation，逐动作均值保留）将分数转换为**非负、均值 1** 的分配 ω_t,j；
- 配以**动作均值 PPO 代理损失**，使 token 分配在损失层面也无法改变动作级标量信用。

### 2.2 TAC：TD 动作信用
- 用**检查点校准的 TD 残差**将轨迹优势分解到每个动作：
  - δ_μ_t = r_t + V^μ(x_{t+1}) − V^μ(x_t)，γ=1
- **命题 1**：在确定性奖励和转移下，δ_μ_t = A^μ(x_t, a_t)；随机情形下 E[δ_μ_t | x_t, a_t] = A^μ(x_t, a_t)。
- 实践中引入**边界调整势函数**：
  - V̄_φ(x_i,0) = b_i，V̄_φ(x_i,t) = V̄_φ(x_i,t)（0<t<T），V̄_φ(x_i,T) = 0
  - 从而 **A⋆_i,t = r_i,t + V̄_φ(x_i,t+1) − V̄_φ(x_i,t)**，满足**望远镜恒等式**：Σ_t A⋆_i,t = G_i − b_i = Aseq_i
- 该恒等式与中间值头精度无关。
- 值头通过从已实现轨迹中恢复稀疏中间状态、在冻结行为策略下采样短推理续采来训练。

### 2.3 HTA：Hindsight Token Allocation
- 使用教师事后似然差 Δ_t,j = log π_T(y_t,j | x_t, Φ_t, y_t,<j) − log π_θ(y_t,j | x_t, y_t,<j)
- 结果对齐分数：**s_t,j = sgn(A⋆_t) · clip(Δ_t,j, −d, d)**
- 正向信用动作的 token（Δ 高者）获得更多正信用；负向信用动作的 token（Δ 低者）承担更多负信用。

### 2.4 APM：Per-Action Mean Preservation
- 归一化分配：**ρ_t,j = (1−η_k)·(1/L_t) + η_k·softmax_j(s_t,j / τ)**
- 保证 Σ_j ρ_t,j = 1 且 ρ_t,j ≥ 0（非负性防止符号翻转）。
- 实际使用的乘数 ω_t,j = L_t·ρ_t,j，使 **C_t,j = ω_t,j·A⋆_t**。
- 均值保留直接成立：(1/L_t)·Σ_j C_t,j = A⋆_t。

### 2.5 动作均值损失（Action-Mean Loss）
- FACTOR 使用动作均值 PPO 代理损失：
  - L_act_RL = −(1/Σ_i T_i)·Σ_{i,t} (1/L_i,t)·Σ_j min(q_i,t,j·C_i,t,j, clip_ε(q_i,t,j)·C_i,t,j)
- **关键性质**：在行为策略点（q=1），每个动作的内部均值恰好等于其 TAC 信用：
  - (1/L_i,t)·Σ_j C_i,t,j = A⋆_i,t
- 非动作 token 使用独立的 token 均值分支，系数用 A_seq。
- 总损失：**L = L_act_RL + L_non-act_RL + λ_k·L_SERL_act**
- 所有信用系数均以 stop-gradient 常量进入损失。

## 6. 主要结论与发现

### 6.1 性能提升
- FACTOR 相对 SERL-Repro 的提升：**ALFWorld +2.2 pp、WebShop +2.4 pp、ScienceWorld +4.2 pp**（Qwen2.5-7B，动作均值归约）。
- 所有 9 个环境×种子对比均支持 FACTOR；FACTOR 的跨种子标准差在三个基准上均更低。
- 最大增益出现在**最长视野环境**（ScienceWorld），验证了长视野下精确动作信用分配的价值。
- 训练过程曲线同样占优（晚期归一化奖励 0.56 vs. SERL 0.45 vs. SERL-Extended 0.47），增益不局限于单一检查点。

### 6.2 消融结论
- **TAC（TD 动作信用）是改进的主要驱动力**：移除后平均损失 2.5 pp（各环境 2.1/1.9/3.5 pp）。
- **HTA（事后 token 分配）提供互补增益**：在 WebShop（−1.6 pp）和 ScienceWorld（−2.1 pp）显著，在 ALFWorld 近乎中性（+0.2 pp），说明 token 集中在长任务上更有价值。
- **APM 归一化必要**：改为批全局归一化或使用 SERL 的未归一化 ψ 均带来性能下降。
- TokenShuffled 与 CreditShuffled 均造成退化，表明 token 位置与动作级排序都携带有效信号。
- 计算匹配的 SERL-Extended（188 步）仍低于 FACTOR（差 1.6–3.6 pp），排除计算量解释。

### 6.3 跨骨干迁移
- **Qwen2.5-14B**：+0.8/+0.9/+2.7 pp（ALF/WS/SciW）。
- **Llama-3.1-8B**：+2.1/+1.9/+2.9 pp。
- 超参数完全冻结迁移，无需重调；ScienceWorld 在两种骨干上均为最大增益环境。

### 6.4 机制证据
- **动作信用失真**：SERL 的动作平均乘数偏离 1 的中位数为 6.7%，28% 动作超过 10%；FACTOR 全部动作低于 4×10⁻⁷。
- **TD 信用校准**：84.2% 符号一致率（早期 76.8% → 晚期 89.2%）。
- **Token 扰动**：正向信用动作替换高 ρ token 比替换低 ρ token 多降低 13.7 pp 回报；负向信用动作对应多提升 7.9 pp；惊奇匹配后效应仍显著（−10.2 pp, AUC 0.62）。

## 7. 优点

1. **问题洞察深刻**：识别出"损失归约本身也是动作到 token 信用接口的一部分"这一此前未被明确指出的耦合问题。
2. **分解设计的优雅性**：将"多少"（动作信用）与"在哪里"（token 分配）分离，通过显式守恒接口连接，产生精确的数学性质（每动作预裁剪替代值恰等于其 TD 信用）。
3. **理论性质清晰**：望远镜恒等式保证信用分解精确收敛回轨迹优势，且与值头精度无关；均值保留有构造性保证。
4. **轻量且侵入性小**：仅修改可执行动作的 token 系数，保留 SERL 的辅助蒸馏损失；无需架构修改（教师与学生共享权重，仅输入构造不同）。
5. **实验严谨全面**：多种子、多基准、多骨干、2×2 因子设计、计算量匹配对照、统计检验（层次 bootstrap）、敏感性扫描、机制诊断齐备。
6. **可迁移性验证充分**：超参数零调迁移到更大骨干和不同模型家族（Qwen→Llama）。
7. **诚实处理局限**：明确说明 MC 与值估计均有噪声、扰动实验的语义混杂无法完全消除、3 种子 bootstrap 覆盖仅近似。

---

## 8. 不足与局限

### 8.1 方法层面的限制（论文自述）
- **需要可恢复状态**（restorable

- **可恢复状态**（restorable state）：HTA 依赖从轨迹中恢复中间状态来构造后续视图，因此方法自身天然不适用于不可恢复状态（如纯文本聊天等无环境状态的环境）；这限制了其适用范围。
- **需要中等级别的教师性能**：教师分配基于学生策略下跨续采的后视似然差，若教师过弱或与学生的分布差距过大，信号可能不稳定；实验均在开放权重模型（Qwen/Llama）上验证，未覆盖更弱或更极端的模型。
- **超参数数量偏多**：TAC 需要检查点数量 B、续采数 M、裁剪窗口 d、温度 τ、混合系数 η₀、值头预热步数等一组超参数，尽管敏感性扫描表明结果对多数超参数不敏感，但完全自动化的配置仍有难度。
- **值头训练策略有待完善**：论文使用冻结行为策略下采样短推理续采来训练中间值头，但该做法的理论保证与最优采样策略未深入讨论。

### 8.2 实验层面的限制（论文自述与客观观察）
- **统计功效有限**：主实验仅 3 个种子，分层 bootstrap 的覆盖率只是近似，且种子为聚类单元时区间较宽；论文坦承了这一不足。
- **扰动实验存在语义混杂**：替换高 ρ token 可能同时替换了高惊奇度 token，尽管作者用惊奇匹配对照缓解，但无法完全消除语义层面的混淆。
- **环境覆盖面有限**：三个基准均属于"有可恢复状态、有明确成功信号"的具身/网页/科学推理场景，未涉及开放式对话、代码生成等更通用的 RL 场景。
- **值头校准的评估不充分**：对中间值头的精度本身缺少系统评估（如与 Monte Carlo 估计的误差分布），仅有符号一致率与系数偏差等间接证据。

## 9. 与其他工作的关系

### 9.1 与前序信用分配工作的定位
- **时间维度的延续**：GRPO 完全不做时间信用分配；SERL 通过教师逐动作乘数进行粗略的动作级调制；FACTOR 的 TAC 将动作信用精确化为 TD 残差，并保留望远镜恒等式。
- **token 维度的延续**：已有 token 调制方法（如强调高似然 token 的启发式）将动作级信用视为固定输入；FACTOR 的 HTA 则将动作信用视为固定预算来做分配，从而两侧解耦。
- **与 2×2 因子设计的对照**：SERL + action-mean 在实际实验中仍劣于 FACTOR + action-mean，说明平均保留本身不足以修复 SERL 的长度耦合，还需要 TAC 的信用精度。

### 9.2 技术上的可替代解读
- 从形式上看，FACTOR 等价于在 GRPO 框架基础上额外构造了**逐动作、与总响应长度无关的常数系数**，再配合**动作内部均值归一化**——这使其与 **PPO 的 advantage 归一化**精神一致，但归一化单元从"整条轨迹/批次"细化到了"单个动作"。
- 与 **GAE/λ-return** 的关系：TAC 使用 γ=1 的 TD 残差，相当于 λ=0 的 GAE；论文在附录中对比了 n-step/GAE/MC 估计器并报告 TD 残差在长视野、稀疏奖励设定下综合最优，说明简单性在此类环境中反而是优势。

---

## 10. 复现要点

- **核心公式链**：轨迹优势 → 每动作 TD 残差（A⋆）→ 教师后视似然差（Δ）→ softmax 归一化（ρ）→ 均值保留乘数（ω）→ 动作均值 PPO 损失。
- **需要完整实现的模块**：
  1. 冻结行为的短推理续采以构造中间状态；
  2. 中间值头（与策略共享骨干或者独立 head）；
  3. 教师分配在第 11–49 步激活；
  4. 动作 token 与非动作 token 分离的损失分支。
- **值得注意的细节**：
  - 所有信用系数以 stop-gradient 常量进入损失（不反传通过系数构造路径）；
  - 检查点校准的边界势函数 V̄(x_t,0)=b、V̄(x_t,T)=0 是保证望远镜恒等式成立的关键；
  - SERL 辅助蒸馏损失 λ_k·L_SERL_act 保留，只是系数改为 FACTOR 的动作系数；
  - 训练与评测的任务划分经过去重审计（零碰撞）。
- **计算量**：主实验约 864 个 8-GPU 节点时，整套论文约 1,190 个 8-GPU 节点时（≈9,520 个单 A100 时）。

---

## 11. 一句话总结

FACTOR 通过将"每个动作获得多少信用"与"信用如何落到 token"解耦，并用逐动作均值保留作为守恒接口，在多种子、多基准、多骨干的严格受控实验下取得了对 SERL 的一致且稳健的改进，尤其受益于长视野任务。

## 12. 核心图解（文字版）

```
轨迹优势 G_i − b_i
        │
        ▼
┌─────────────────┐
│  TAC（TD 动作信用）│   A⋆_t = r_t + V̄(x_{t+1}) − V̄(x_t)
└─────────────────┘   Σ_t A⋆_t = G_i − b_i（望远镜恒等式）
        │ 动作信用（标量，与 token 数无关）
        ▼
┌─────────────────┐
│  HTA（事后 token 分配）│   Δ_t,j = log π_T(y_t,j|·) − log π_θ(y_t,j|·)
└─────────────────┘   s_t,j = sgn(A⋆_t)·clip(Δ_t,j, −d, d)
        │ 相对责任分数
        ▼
┌─────────────────┐
│  APM（逐动作均值保留）│   ρ_t,j = (1−η)/L + η·softmax(s/τ)
└─────────────────┘   ω_t,j = L·ρ_t,j  →  (1/L)Σ_j ω_t,j = 1
        │ 非负、均值 1 的乘数
        ▼
┌──────────────────────────────┐
│  动作均值 PPO 代理损失             │
│  (1/L)Σ_j min(q·C, clip(q)·C)  │
│  C_t,j = A⋆_t · ω_t,j           │
└──────────────────────────────┘
```
