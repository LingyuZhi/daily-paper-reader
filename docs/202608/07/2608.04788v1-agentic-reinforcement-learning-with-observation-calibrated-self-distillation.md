## 摘要
大型语言模型智能体通常通过强化学习进行训练，使用稀疏的轨迹级奖励，这种奖励对单个词元应更新的强度提供了有限的指导。策略内自蒸馏（OPSD）通过在一个特权回放视角下对生成的词元重新打分，以获得密集的词元级监督，从而解决了这一问题。然而，我们发现了一个混杂问题：由此产生的支持可能既反映了回放视角中包含的特权信息，也反映了由回放脚手架引起的分数偏移，这使得难以将支持专门归因于该信息。当未来的环境观测作为特权信息时，这个问题尤其明显，因为回放这些观测需要重建一个扩展的脚手架，而该脚手架本身会扰动词元分数。为了解决这种混杂，我们提出了观测校准自蒸馏（OCSD），它对比两个结构匹配的回放视角：完整视角和观测消融视角，两者仅在是否存在实际未来观测上不同，从而导出一个观测残差，该残差对回放脚手架共享的分数变化进行折扣。然后OCSD应用这个残差来调节高不确定性步骤处的词元级GRPO更新，同时保留轨迹级更新方向。在ALFWorld、WebShop和Search-QA上，跨三个Qwen3模型规模的实验表明，OCSD持续优于强基线。诊断分析进一步证实，校准后的残差与局部环境反馈对齐得更好。我们的代码已公开在 https://github.com/yiy1x/OCSD。

## Abstract
Large language model agents are commonly trained through reinforcement learning with sparse trajectory-level rewards, which offer limited guidance on how strongly individual tokens should be updated. On-Policy Self-Distillation (OPSD) addresses this by re-scoring generated tokens under a privileged replay view to obtain dense, token-level supervision. However, we identify a confounding issue: the resulting support may reflect both the privileged information contained in the replay view and score shifts induced by the replay scaffold, making it difficult to attribute the support specifically to that information. This issue is especially pronounced when future environment observations serve as privileged information, since replaying them requires reconstructing an extended scaffold that itself perturbs token scores. To resolve this confounding, we propose Observation-Calibrated Self-Distillation (OCSD), which contrasts two structurally matched replay views, Full and Observation-Ablated, differing only in whether the actual future observation is present, to derive an observation residual that discounts score changes shared by the replay scaffold. OCSD then applies this residual to modulate token-level GRPO updates at high-uncertainty steps, while preserving the trajectory-level update direction. Experiments on ALFWorld, WebShop, and Search-QA across three Qwen3 model scales show that OCSD consistently outperforms strong baselines. Diagnostic analyses further confirm that the calibrated residual aligns better with local environment feedback. Our code is publicly available at https://github.com/yiy1x/OCSD.

## 1. 核心问题与整体含义
- **研究动机**：大语言模型智能体在长程交互任务中常使用强化学习（如 GRPO）训练，但稀疏的轨迹级奖励无法提供每个 token 的细粒度更新指导。
- **现有方法不足**：On-Policy Self-Distillation（OPSD）通过特权重放视图对生成 token 重新打分来获得密集监督，但其“支持信号”混杂了两种来源：真正的特权信息与重放脚手架（如格式、未来动作模板）造成的分数偏移，难以区分。
- **关键场景**：当特权信息为未来环境观测时，重放需要重建扩展上下文，进一步加重混杂，导致 token 级监督被污染。
- **整体含义**：需要解耦混杂因素，获得纯净、可归因于未来观测的 token 级监督信号，以提升智能体强化学习的样本效率与最终性能。

## 2. 方法论
- **核心思想**：构造两个结构完全匹配的重放视图——Full 视图与 Observation-Ablated 视图，二者仅在未来观测是否存在上有差别；通过对比二者对同一 token 的打分，得到“观测残差”，从而消除重放脚手架共享的分数变化。
- **关键步骤**：
  - Full 视图：包含实际未来观测，以及未来动作的“自然化” schema（保留动作意图和结构，但将实体/位置/查询等替换为粗略语义角色）。
  - Observation-Ablated 视图：将未来观测替换为固定短语 `Observation: not provided`，其余结构保持一致。
  - 计算 token 支持：δF = log πF(y|...) - log πS(y|...)，δA = log πA(y|...) - log πS(y|...)；
  - 观测残差：e = δF - δA（学生项相消）；
  - 有界信号：q = tanh(e/2) ∈ [-1,1]；
  - NLL 引导的步骤选择：按每步平均 token 负对数似然排序，在每个轨迹内选择 top-ρ 高不确定性步骤；
  - 集成 GRPO：保持轨迹级优势方向，仅调整 token 更新强度：
    - bA_OCSD = bA · [1 + β · sgn(bA) · q]；
  - 最后使用标准 GRPO surrogate，但将轨迹优势替换为校准后的 token 优势。

## 6. 主要结论与发现
- OCSD 在 ALFWorld、WebShop、Search-QA 上一致超越 GRPO 和其他基线，且 OOD 泛化最好。
- 直接使用 Full 重放支持（OPSD、GRPO+OPSD）增益不稳定，甚至低于纯 GRPO。
- 观测残差比 Full 支持与局部环境反馈更一致（AUROC 0.707 vs 0.654）。
- 将未来观测替换为其他轨迹的观测后，残差的判别能力降至接近随机（AUROC 接近 0.5），说明其信息来自真实的“动作-观测”对应，而非任意额外文本。

## 7. 优点
- 方法简洁，不引入额外模仿目标或重放动作生成，易于嵌入现有 GRPO 管线。
- 计算开销极小（<2%），适合大规模智能体 RL 训练。
- 提供了深入的诊断分析（词级偏好、功能角色、AUROC、观测交换），不仅报告最终分数，还验证了信号的可解释性。
- 在三种模型规模上取得一致性提升，表明方法具有较强的稳定性和可扩展性。

## 8. 不足与局限
- 只在 Qwen3 系列上验证，未覆盖更多开源/闭源模型。
