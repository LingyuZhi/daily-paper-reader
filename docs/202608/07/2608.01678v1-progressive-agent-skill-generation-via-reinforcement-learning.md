## 摘要
现有的技能生成方法很大程度上依赖于启发式或流水线式的整合，这些方法必须针对不同的证据来源进行专门设计。相比之下，基于学习的方法提供了一种更统一的方式，可以跨异构来源建模技能生成。然而，基于学习的技能生成仍然具有挑战性，因为技能缺乏基于相关性或正确性的自然监督信号；其价值很大程度上只能通过它们是否改善了智能体在下游任务中的表现来确定。为了解决这一挑战，我们提出了 Skill-α，一种用于渐进式生成高质量智能体技能的强化学习方法。具体来说，我们将技能生成表述为一个顺序编辑过程，将技能构建分解为可单独评估的编辑，并引入了一种新的回滚奖励，通过比较锚定查询下原始技能和编辑后技能的下游执行情况来评估每次编辑。大量实验表明，在文档到技能和经验到技能两种设置中，Skill-α 生成的技能比基于启发式或流水线的方法更有效。在主要的 GPT-4o worker 下，Skill-α 将平均下游成功率比最强的技能生成基线提高了 CL-Bench 上的 3.3 个点和 tau2-bench 上的 6.7 个点。进一步的消融研究验证了回滚奖励和渐进式生成的重要性。

## Abstract
Existing skill generation methods largely rely on heuristics or pipeline-style consolidation, which must be specially designed for different evidence sources. In contrast, learning-based approaches offer a more unified way to model skill generation across heterogeneous sources. However, learning-based skill generation remains challenging because skills lack a natural supervision signal based on relevance or correctness; their value can largely be determined only by whether they improve the behavior of the agent on downstream tasks. To address this challenge, we propose Skill-$α$, a reinforcement learning method for progressively generating high-quality agent skills. Specifically, we formulate skill generation as a sequential editing process that decomposes skill construction into individually evaluable edits, and introduce a novel rollback reward that evaluates each edit by comparing downstream execution under the original and edited skills on an anchored query. Extensive experiments show that Skill-$α$ generates more effective skills than methods based on heuristics or pipelines in both document-to-skill and experience-to-skill settings. Under the main GPT-4o worker, Skill-$α$ improves average downstream success rates over the strongest skill-generation baseline by 3.3 points on CL-Bench and 6.7 points on tau2-bench. Further ablations validate the importance of rollback reward and progressive generation.

- **现状与痛点**：
  - 现有技能生成方法多为启发式、提示工程或流水线式整合（如 Ctx2Skill、Trace2Skill、ExpeL 等），需要针对不同证据源（文档 vs 经验）分别设计，缺乏统一的学习框架。

  - 因此，**执行落地（execution-grounded）的信用分配**是学习的核心障碍：一个编辑可能短小精炼却显著改进 worker 行为，而一个流畅的文本可能冗余、过度具体或具有误导性。
- **整体意义**：论文提出将技能生成建模为序贯编辑决策问题，并用强化学习训练一个统一的技能编辑策略，从而将文档到技能与经验到技能两种设置统一在一个学习框架下，改善技能生成的质量与泛化能力。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- **技能生成 = 渐进式编辑过程**：将技能构建分解为一系列局部编辑决策（CREATE、UPDATE、MERGE、PRUNE、NOOP），每个编辑都能被独立评估。
- **回滚奖励（Rollback Reward）**：对每个编辑动作，在同一个“锚定查询”（anchored query）上分别用原始技能和编辑后技能驱动固定 worker 执行，通过基准特定的验证器比较两者结果，从而把下游执行反馈归因到单个编辑。

### 关键公式与流程

1. **技能生成形式化**：
   - 给定经验证据序列 \(x_{1:T}\) 和初始技能 \(z_0\)，编辑策略 \(\pi_\phi\) 在每一步采样编辑动作 \(A_t\)，并更新技能：
     \[
     A_t \sim \pi_\phi(\cdot \mid z_{t-1}, x_t), \quad z_t = \text{Edit}(z_{t-1}, A_t)
     \]
   - 理想目标是最小化固定 worker 在目标任务上的行为分布与教师分布的 KL 散度（式 2），但因教师分布不可得，需用间接奖励近似。

2. **动作空间**：
   - CREATE：添加缺失规则/流程；
   - UPDATE：修改不完整或不准确的规则；
   - MERGE：合并重叠内容；
   - PRUNE：删除有害/过度具体/冗余内容；
   - NOOP：不改动技能。

3. **回滚奖励（式 5）**：
   - 对候选动作 \(A^{(i)}_t\)，令控制分支得分为 \(r^{\text{ctrl}}_t\)，编辑后分支得分为 \(r^{\text{edit}}_{t,i}\)：
     \[
     R_{\text{rb}}(A^{(i)}_t) =
     \begin{cases}
     1, & A^{(i)}_t \neq \text{NOOP} \text{ 且 } r^{\text{edit}}_{t,i} > r^{\text{ctrl}}_t\\
     1, & A^{(i)}_t = \text{NOOP} \text{ 且没有其他有效编辑得分超过控制分支}\\
     0, & \text{otherwise}
     \end{cases}
     \]
   - 该奖励通过 GRPO（Group Relative Policy Optimization）进行训练，目标是让策略学会执行能带来真实下游改进的编辑。

4. **训练实现要点**：
   - 策略模型初始化为指令微调的 Qwen3-8B；
   - 先用 DeepSeek-V4-Pro 合成的监督数据做 SFT 热身（共 6,481 条示例，涵盖五个动作，格式为 think + action）；
   - 再用 GRPO 优化（固定 worker 为 GPT-4o），群大小 G=8；
   - 证据处理：文档长文本切为有序片段；轨迹经验压缩为标准序列（每组最多 4 条轨迹、每条最多 8 步、每步 3000 字符，提示长度上限 8192 token）。

### 理论支撑（附录 A）
- 回滚奖励的期望等价于“编辑后技能对控制技能的验证器胜率”；
- 在验证器具有候选无关的误报/漏报率假设下，期望回滚奖励严格保持理想偏好排序；
- 在二元成功验证器下，期望奖励正比于编辑技能的绝对成功率（乘系数 \(1-\beta_0\)）；
- NOOP 奖励是组级回退机制，而非编辑质量的估计。

## 6. 主要结论与发现

- **主结果**：
  - 在 GPT-4o worker 下，Skill-α 在 CL-Bench 平均成功率较最强基线提升 3.3 点，在 tau2-bench 提升 6.7 点。
  - 在文档到技能设置中，CL-Bench 上的优势主要体现在 Procedural Task Execution（4.30→9.68），在 OOD 类别上也最好或接近最好。
  - 在经验到技能设置中，SpreadsheetBench 从 18.00 提升到 27.50，tau2-bench Airline 从 40.00 提升到 65.00，Telecom 从 12.50 提升到 22.50。
  - 在 Claude-Sonnet-4.5 跨 worker 评估中，Skill-α 仍然最佳或并列最佳，说明学到了可复用的任务知识而非 worker 专用提示捷径。
- **消融与机制**：
  - 去掉 RL 后性能大幅下降（CL-Bench 10.38→3.46），说明训练本身必要；
  - 去掉回滚奖励后性能接近 SFT only，说明回滚奖励是关键训练信号；
  - 去掉 MERGE/PRUNE 后 tau2-bench 明显恶化，说明技能维护需要显式合并与删除；
  - 去掉 NOOP 仍有较不错的表现，但完整模型仍有持续优势，说明 NOOP 作为校准动作是有益的。
- **证据敏感性**：
  - 对证据顺序较稳健（source/shuffled/reverse 差异不大），但 shuffle 在 tau2 上略降，说明局部连续性有帮助；
  - 对证据粒度更敏感：batch=4 最优，batch=1 或 8 都明显退化，表明“适度证据批量”是关键。

## 7. 优点

- **统一框架**：首次将文档-技能与经验-技能两类任务统一为单一“渐进式编辑决策”学习问题，克服了流水线方法对不同证据源需要专门设计的局限。
- **回滚奖励设计精巧**：通过在锚定查询上对比编辑前后技能的下游执行效果，实现了局部编辑的信用分配，避免了直接奖励整条轨迹无法区分“是编辑带来的提升还是 worker 本身能力”的问题。
- **可操作动作空间**：CREATE/UPDATE/MERGE/PRUNE/NOOP 直观且可解释，支持技能的添加、修正、合并、删除和保持，使训练策略行为多样且可控。
- **训练与推理分离**：训练时用固定 worker（GPT-4o）获取奖励，推理时技能可迁移到其他 worker（Claude-Sonnet-4.5），支持跨模型复用。
- **实证充分**：多基准、多基线、双 worker 骨干、消融、训练动态和证据分析齐备，且报告了详细超参与实现细节，可复现性较好。
- **理论支撑**：附录给出了回滚奖励在验证器校准和二元成功指标下的排序保持性质，为设计提供形式化解释。

## 8. 不足与局限

- **验证器/奖励接口依赖基准**：回滚奖励需要使用基准特定的验证器（如 CL-Bench 的 GPT-5.5 rubric 判断器、SpreadsheetBench/tau2-bench 的环境反馈）。迁移到新环境需要重新设计评估协议。
- **技能表示简单**：目前仅为文本（SKILL.md 风格），不支持更丰富的结构化、多模态或可执行技能表示，限制了在复杂实际系统中的应用。
- **理论结果有限**：附录给出的只是局部编辑在锚定查询上的排序保持，不保证多次编辑累积后整体技能一定改进；单个 rollback 比较是单次二元信号，噪声较大。
- **算力与训练细节不透明**：未说明 GPU 型号和总训练时长，难以评估训练成本。
- **实验统计不足**：没有报告方差或多次运行的平均值，单次结果可能掩盖不同方法和随机种子之间的波动；证据顺序/批量的交叉影响未系统探索。
- **跨 worker 评估范围有限**：只测试了 Claude-Sonnet-4.5 作为消费端，未覆盖其他主流模型或开源模型，泛化结论仍需更大范围的验证。
