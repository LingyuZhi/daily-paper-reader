## 摘要
智能体强化学习使LLM智能体能够通过交互进行学习，但稀疏的轨迹级奖励仅能指示成功与否，而无法识别哪些中间决策应获得奖励。训练专用的特权技能可以通过允许相同的冻结策略快照在条件于任务匹配的程序性技能下，对来自无技能轨迹的固定token进行重新评分，从而提供更密集的监督。然而，现有方法并未联合校准跨交互步骤的教师分数，未将教师置信度与实际回报相关联，也未将所得信号整合到原生奖励到优势的构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），一个为多轮语言智能体构建回报关联的token级信用的框架。ADRS在每个步骤内对特权token分数进行中心化和归一化，通过基于组内置信度-回报关联的回报关联教师价值优势（TVA）门控对其进行调节，并将门控后的token信号纳入原生RL信用构建中。这些组件共同决定了教师偏好什么、该偏好何时与回报相关，以及它如何进入原生强化学习信用路径，同时保持轨迹生成和推理不依赖技能。最后，在三个交互基准上的实验表明，ADRS在长时程任务上持续提升性能，且收益在RL骨干网络、数据减少设置、未见任务和扩展训练中均保持稳定。为便于匿名评审，我们的代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. For anonymous review, our code is available at the following the link: https://github.com/gitrxh/ADRS-arxiv

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：语言模型智能体（LLM Agent）在证据搜索、具身导航、网页交互等任务上进展显著，但智能体强化学习（Agentic RL）通常只提供**稀疏的最终结果奖励**（trajectory-level terminal reward），仅能区分轨迹成败，无法为中间的关键动作（如某次查询、某个动作）分配信用。即使 GRPO、GiGPO 这类免评论家（critic-free）的组相对方法，也面临 token 级时间信用分配（temporal credit assignment）困难。
- **现有方案**：利用自然语言技能（skills）提供过程监督，通过训练专用的特权（privileged）自蒸馏设置，让同一冻结策略快照在任务匹配技能条件下对无技能轨迹的 token 重新评分。代表人物/方法包括 OPSD、GRPO+OPSD、Skill-SD、RLSD、SDAR 等，但它们仍存在三大共性问题：
  1. **分数校准**：原始教师 log-probability 在不同交互步骤之间存在偏移和尺度差异，缺乏跨步骤可比性；
  2. **可靠性估计**：教师高置信度不等于对回报有用（语言流畅性 ≠ 任务成功），需要将教师置信度与实际回报关联；
  3. **信用整合**：现有蒸馏目标大多作为独立辅助损失，绕过了原生 RL 的 reward-to-advantage 计算路径，导致 token 更新与 GRPO/GiGPO 的组相对优势不对齐。
- **核心意义**：论文提出 ADRS（Agentic Reinforcement Learning with Self-Distilled Reward Shaping），将训练专用的程序性技能转化为**与回报关联的 token 级奖励**，并通过原生奖励-优势-策略路径注入学习，在保持 rollout 与推理无技能（skill-free）的同时显著提升长时程任务的性能，为稀疏奖励下的多轮语言智能体提供了一整套信用塑形方案。

## 2. 论文提出的方法论

**总体思想**：ADRS 是一个位于「轨迹收集」与「策略优化」之间的信用构建层，包含三个并行/串行协作的模块，对应解决三大挑战。

**模块一：步骤内相对特权评分（Within-Step Relative Privileged Scoring）**
- 行为策略快照 \(\pi_{\theta_b}\) 先无技能采样 K 条轨迹；随后同一冻结快照在普通上下文与特权技能上下文(`ρ(x) ⊕ h`)下对同一批 token 分别计算 log-probability。
- 将每个交互步骤内的原始教师分数做**中心化**：\(q_{s,j} = \ell^T_{s,j} - b_s\)（\(b_s\) 为步骤内平均 log-prob），再除以共享的步骤尺度 \(\sigma_q\)：\(\hat{q}_{s,j} = q_{s,j}/(\sigma_q + \epsilon)\)。
- 效果：每个步骤内 token 的 \(\hat{q}\) 之和为零（零和结构），消除步骤间偏移和尺度漂移，保留相对偏好；正分表示该 token 获得高于步骤平均的特权支持。

**模块二：回报关联的 TVA 可靠性门控（Return-Associated TVA Reliability Gate）**
- 不假设教师永远可靠，而是估计**教师置信度与回报的相关性**，产出一个组级标量门控 \(m\)。
- 计算单元（unit）平均置信度 \(\bar{\ell}^T_u\) 与 soft 高置信权重 \(\alpha_u = \sigma((\bar{\ell}^T_u - \bar{\ell}^T_{\text{batch}})/T)\)；
- 在高置信与低置信两侧分别计算加权回报均值 \(\mu^+_g\) 与 \(\mu^-_g\)，差值 \(d_g = \mu^+_g - \mu^-_g\)，经可选正缩放后过 sigmoid：\(m_u = \sigma(\tau \tilde{d}_{g(u)})\)；
- **支持两种粒度**：L2（完成级，按同 prompt 的轨迹组）与 L3（步骤级，按 GiGPO 的重复锚定状态，用 return-to-go），对应 GRPO 与 GiGPO 的组结构。
- **Proposition 1** 证明 \(d_g\) 的符号与组内置信度-回报的经验协方差一致，使门控具有统计意义。

**模块三：教师引导的逐 token 优势调制（Teacher-Guided Per-Token Advantage Modulation）**
- 教师奖励 \(r^T_{s,j} = \eta m_{s,j} \hat{q}_{s,j}\)，塑形奖励 \(\tilde{r} = r^{\text{base}} + r^T\)；
- **两条路径**：
  - 轨迹路径：\(\tilde{r}\) 进入 GRPO/GiGPO 原生优势计算，由于教师奖励在步骤内零和，轨迹总分与原生基底一致，保留环境定义的轨迹方向；
  - token 路径：将保存的 \(r^T\) 在 prompt 组内白化（标准化）得到 \(Z^T\)，作为逐 token 调制量；
  - 最终优势 \(A^{\text{ADRS}} = A^{\text{traj}} + \eta Z^T\)，实现轨迹方向 + token 重分配的耦合。
- **Proposition 2** 证明步骤内零和表示（sampled-chain）及对轨迹顺序的保持；
- **Proposition 3** 证明在行为策略点上，ADRS 的梯度与「带采样 token 辅助系数」的本地梯度一阶等价，表明它等价于将教师信号注入原生信用路径。
- 训练流程：rollout → 双上下文重评分 → 零和校准 → TVA 门控 → 优势融合 → 标准 clipped actor 更新（式 12），特权文本仅用于事后重评分，推理完全无技能。

## 6. 主要结论与发现

- ADRS 在三个 benchmark 上均达到最高性能：Qwen2.5-3B 上 ALFWorld 94.5%、Search 45.0%、WebShop 87.5/76.6，相对最强基线分别提升 10.1、0.4、2.5/8.6 个点；
- 收益跨模型家族/尺度稳定（Qwen2.5-3B/7B、Qwen3-1.7B），且**不依赖推理时技能**；
- 300 步训练中优势持续（ALFWorld 最终 96.1% vs GRPO 86.7%；WebShop 最终 84.4% vs GRPO 78.9%）；ADRS 比 SDAR 加速约 1.9 倍达到 70% 成功率；
- 在 GiGPO 骨干上 ADRS 仍有效（82.8 → 89.8 @150 步），TVA 门控贡献额外的 2.3–2.4 个点；
- token 诊断显示 ADRS 将更新对比度集中于 action/object token（第 150 步 action 与 style 的幅度比达到 95.3），而非均匀分散到全部响应 token；
- 数据效率：ADRS 使用 60% 的 ALFWorld 数据即可超过 GRPO 全量数据的成功率（78.1% vs 75.0%）；
- 未见任务泛化：平均提升 11.9 个点，5/6 类任务提升；
- 最大步数增加时 ADRS 优势扩大（50 步时 94.5% vs SDAR 84.4%）。

## 7. 优点

- **方法设计优雅且可解释**：将三个实际困难（校准、可靠性、整合）拆解为三个可独立证明的模块；TVA 与协方差的数学联系（Proposition 1）使门控不再是启发式。
- **理论保障配套**：Proposition 2 给出步骤内零和保证（不扰动轨迹分数），Proposition 3 给出与辅助 token 更新的一阶等价性，使操作「有底」。
- **原生 RL 路径整合**：不引入额外辅助损失，而是把教师信号转化为奖励塑形，在优势估计前注入，与 GRPO/GiGPO 的既有 credit operator 兼容，是一种干净而实用的融合方式。
- **推理零开销**：特权技能只在训练阶段事后重评分使用，rollout 与 inference 完全 skill-free，可部署性高。
- **消融与验证全面**：覆盖骨干（GRPO/GiGPO）、归一化模式、门控开关、教师尺度、数据规模、未见任务、交互长度等多个维度，兼顾机制（token gap）与行为（训练曲线）。

## 8. 不足与局限

- **理论结果的局部性**：Proposition 2 只是「采样步骤上的代数表示」，非策略不变性；Proposition 3 只在行为策略点且无 clip 时成立；作者自己也声明不包含全词表 KL/JSD、非 detached 门控、多 epoch PPO 等情形。整体理论支撑较「薄」。
- **实验覆盖仍有盲区**：
  - 只选用 1.7B–7B 的 Qwen 模型，未覆盖更大模型（13B/70B）或闭源 API 模型；
  - Search 任务提升弱，论文对「长时程收益最好在何处」的解释不充分；
  - 未见任务分析仅基于 ALFWorld 一个环境；
  - token 机制诊断仅 4 条固定轨迹，样本量过小，第 300 步 action/object/style 的表现与 250 步不一致但未讨论原因；
  - 未报告多次随机种子，统计分析缺少显著性检验。
- **算力/成本披露不足**：没有 GPU 卡时数等基本成本信息，限制复现与用户评估。
- **公平性风险**：SDAR 对比虽然共享协议，但表 2 中各方法在三个模型上分别使用不同 \(\eta\)/归一化/熵系数，存在「环境特调」痕迹；同时存在置信度偏高的表述（如 Search 0.4 个点提升被称为「新 SOTA」），需要进一步验证。
- **工程复杂度**：需要额外的双上下文重评分、特权技能库构建（37+90 个技能，619 条记忆）、TVA 组结构设计与门控计算，实现和调参成本较高；当前实现中对每环境有独立的配置选择，用户迁移时需要重新调参。
