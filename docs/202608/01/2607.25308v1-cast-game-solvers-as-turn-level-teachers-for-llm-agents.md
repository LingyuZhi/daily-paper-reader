## 摘要
训练大型语言模型（LLMs）在长时程游戏中行动是迈向通用决策制定的一条有前景的路径，然而基于可验证奖励的强化学习（RLVR）依赖稀疏的最终奖励，这几乎无法揭示哪些决策决定了成功。更密集的过程信号可以提供缺失的回合级信用分配，但现有来源难以同时保持廉价和准确。我们观察到游戏求解器状态价值的变化可以揭示一个动作是否推动状态走向成功。基于这一见解，我们提出CAST（来自求解器教师的信用分配），它将这种价值变化转化为求解器优势，并将其作为回合级信号注入RLVR。我们进一步表明，在软最优求解器假设下，最大化求解器优势等价于从求解器进行在线蒸馏，只需要标量值而非教师logits。在Sokoban、Minesweeper和Rush Hour中，CAST在领域内和未见难度评估下均在所有游戏上优于所有训练的基线，并在ALFWorld和WebShop上实现了最高的平均零样本性能。我们的代码可在https://github.com/Wloner0809/CAST获取。

## Abstract
Training large language models (LLMs) to act in long-horizon games is a promising step toward generalist decision-making, yet reinforcement learning with verifiable rewards (RLVR) relies on sparse final rewards that reveal little about which decisions determine success. Denser process signals could supply this missing turn-level credit, but existing sources are hard to keep both cheap and accurate. We observe that changes in a game solver's state value reveal whether an action advances the state toward success. Building on this insight, we propose CAST (Credit Assignment from Solver Teachers), which converts these value changes into solver advantages and injects them into RLVR as turn-level signals. We further show that, under a soft-optimal solver assumption, maximizing the solver advantage is equivalent to on-policy distillation from the solver, requiring only scalar values rather than teacher logits. Across Sokoban, Minesweeper, and Rush Hour, CAST outperforms all trained baselines on every game under both in-domain and unseen-difficulty evaluation and achieves the highest average zero-shot performance on ALFWorld and WebShop. Our code is available at https://github.com/Wloner0809/CAST.

- 现有的密集过程信号来源要么计算昂贵（如 rollout 搜索），要么需要额外训练模型（如过程奖励模型），要么依赖跨轨迹可比状态（如 GiGPO），难以同时兼顾廉价与准确。
- 论文的核心观察是：**游戏求解器（solver）的状态价值变化可以揭示单步动作是否推动状态向目标靠拢**——若一个动作能显著降低求解器的“到目标剩余成本”，则它更可能是关键决策。
- 整体含义是提供一种既廉价又准确、可直接注入 RLVR 的回合级过程信号，从而把通用 LLM 训练成可靠的长视界决策智能体。

### 二、方法论

- **核心思想**：将游戏求解器视为“回合级教师”（turn-level teacher），利用其在 LLM 探索的每个状态上计算的价值变化，构造回合级的求解器优势信号，注入 RLVR 以补充稀疏的最终奖励。
- **状态价值的定义**：求解器赋予每个状态一个 cost-to-go \( N(s) \)（最小剩余工作量）。对 Sokoban 和 Rush Hour 是最少动作数，对 Minesweeper 是最少揭示次数；定义 \( V^{\pi_{Solver}}(s) = -N(s) \)。
- **求解器优势**：
  \[
  A^{\pi_{Solver}}(s_t, a_t) = -1 + N(s_t) - \mathbb{E}[N(s_{t+1})]
  \]
  并移位 +1 得到平移优势 \( \tilde{A} = N(s_t) - \mathbb{E}[N(s_{t+1})] \)，即“动作造成的 cost-to-go 下降量”：最优动作得 +1，无进展得 0，有害动作得负分。进入死状态时惩罚为 \( -N(s_t) \)。
- **信号塑形**：
  1. **asinh 变换**：\( g(x) = \text{asinh}(x) \)，对小值近线性、对大值对数压缩，且奇对称保持符号语义；
  2. **批量 RMS 归一化**：\( h(x) = g(x) / (\text{RMS}_B(g) + \epsilon) \)，消除跨游戏尺度差异；刻意不减去均值以保留 0 的“无进展”语义。
- **与 RLVR 结合**（以 DAPO 为骨干）：
  \[
  \hat{A}_{i,t} = \hat{A}^{\text{outcome}}_i + \alpha \cdot h(\tilde{A}^{\pi_{Solver}}_{i,t})
  \]
  即最终结果优势（轨迹级）加上求解器优势（回合级），广播到 token 级别参与 GRPO/DAPO 的剪切代理目标优化。
- **核心理论（Theorem 2.1）**：在软最优（soft-optimal）求解器假设下，求解器优势 \( A^{\pi_{Solver}} = \tau \log \pi_{Solver}(a|s) \) 恰好是教师的 log-preference；最大化该优势等价于优化
  \[
  J(\theta) = \mathbb{E}[V^{\pi_\theta}_{\text{task}}] - \beta\, \mathbb{E}_{s \sim d^{\pi_\theta}}[H(\pi_\theta, \pi_{Solver})]
  \]
  即**任务收益加上交叉熵蒸馏目标**——因此只需标量优势即可完成免 logits 的在线策略蒸馏（logit-free OPD）。
- 推导还表明学生可通过任务优势的指数倾斜超越求解器，且 asinh 压缩在极限步长上提供鲁棒化的自适应蒸馏系数（Corollary C.10）。
